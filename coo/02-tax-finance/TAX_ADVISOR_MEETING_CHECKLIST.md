# 세무사 상담 체크리스트

> HEALO 프로젝트 세무/재무 검토를 위한 세무사 미팅 준비 문서

## 1. 업종 분류

- [ ] 현재 사업자등록 업종/업태 확인 (의료관광 중개 vs IT 서비스)
- [ ] 외국인환자유치업 등록 시 업종 변경 필요 여부 확인
- [ ] 복수 업종 등록 가능 여부 및 세율 차이 확인
- [ ] 업종별 세제 혜택 (중소기업 특별세액감면 등) 적용 가능성

## 2. 부가가치세

- [ ] 플랫폼 수수료에 대한 부가세 과세/면세 여부 확인
- [ ] 해외 거주 환자에게 서비스 제공 시 영세율 적용 가능 여부
- [ ] 의료 관련 서비스의 부가세 면세 범위 확인
- [ ] 해외 결제 (Stripe 등) 수수료의 부가세 처리 방법
- [ ] 부가세 신고 주기 및 예정신고 대상 여부 확인

## 3. 종합소득세 / 법인세

- [ ] 개인사업자 종합소득세 예상 세율 구간 확인
- [ ] 법인 전환 시점 판단 기준 (매출액, 소득액 기준)
- [ ] 법인 전환 시 세제 혜택 비교 (개인 vs 법인)
- [ ] 성실신고확인 대상 여부 및 기준 확인
- [ ] 기장 의무 (간편장부 vs 복식부기) 확인

## 4. 해외 소득

- [ ] 해외 환자로부터 받는 수수료의 소득 분류 확인
- [ ] 외화 수입 시 환율 적용 기준 확인
- [ ] 해외 매출에 대한 이중과세 방지 협약 적용 여부
- [ ] 해외 결제 플랫폼 (Stripe, PayPal) 정산 시 신고 방법
- [ ] 외국환거래법상 신고 의무 확인

## 5. 비용 처리

- [ ] 클라우드 서비스 비용 (Supabase, Vercel, AWS) 비용 처리 방법
- [ ] AI API 사용료 (OpenAI, Google AI) 비용 처리 방법
- [ ] 해외 SaaS 구독료의 원천징수 의무 확인
- [ ] 홈오피스 비용 처리 범위 (1인 사업자 기준)
- [ ] 마케팅/광고비 (Google Ads, Meta Ads) 비용 처리 방법
- [ ] 프리랜서 외주비 지급 시 원천징수 및 신고 방법

## 미팅 준비물
- [ ] 사업자등록증 사본
- [ ] 최근 매출/비용 내역 (통장 거래내역)
- [ ] 현재 사용 중인 SaaS/클라우드 서비스 목록 및 비용
- [ ] 향후 12개월 예상 매출/비용 계획
- [ ] 해외 결제 관련 계약서 또는 서비스 약관
