# 변호사 상담 체크리스트

> HEALO 프로젝트 법률 검토를 위한 변호사 미팅 준비 문서

## 1. 외국인환자유치업 등록

- [ ] 외국인환자유치업 등록 요건 확인 (보건복지부)
- [ ] 개인사업자로 등록 가능 여부 확인
- [ ] 등록 시 필요한 서류 목록 확인
- [ ] 등록 절차 및 소요 기간 확인
- [ ] 등록 없이 플랫폼 운영 시 법적 리스크 확인
- [ ] 유치업자와 중개업자의 법적 구분 확인

## 2. 의료광고 규제

- [ ] 의료법상 의료광고 범위 확인 (플랫폼이 해당되는지)
- [ ] 병원 정보 게시 시 의료광고 해당 여부 확인
- [ ] 가격 비교/순위 표시의 법적 허용 범위 확인
- [ ] 후기/리뷰 게시 관련 규제 확인
- [ ] 해외 타겟 광고 시 국내법 적용 범위 확인
- [ ] 위반 시 제재 수준 (벌금, 영업정지 등)

## 3. 개인사업자 책임 범위

- [ ] 의료 사고 발생 시 플랫폼 운영자 책임 범위 확인
- [ ] 면책 조항의 법적 유효성 확인
- [ ] 개인사업자 무한책임 리스크 및 법인 전환 필요성 검토
- [ ] 배상책임보험 가입 필요 여부 확인
- [ ] PL(제조물책임)보험 vs 전문직배상책임보험 적용 여부

## 4. 이용약관 검토

- [ ] 현재 이용약관 법적 유효성 검토 요청
- [ ] 필수 포함 조항 확인 (전자상거래법, 개인정보보호법)
- [ ] 분쟁 해결 조항 (관할 법원, 준거법) 설정
- [ ] 환불/취소 정책의 법적 적정성 확인
- [ ] 영문/일문 약관의 법적 효력 확인

## 5. 해외 환자 법적 이슈

- [ ] 해외 거주 환자와의 계약 시 준거법 확인
- [ ] 해외에서 결제 시 전자상거래법 적용 여부
- [ ] 의료 분쟁 시 국제 관할권 이슈 확인
- [ ] 해외 환자 개인정보 국외 이전 관련 법적 요건 (GDPR, APPI 등)
- [ ] 비자 관련 안내 시 법적 책임 범위 확인
