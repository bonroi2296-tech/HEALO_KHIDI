## 1. 평가항목 4개 ↔ HEALO 대응 매핑 (점수 전략)

평가위원이 보는 4가지. 각 항목에 "우리가 뭘 보여줄지"를 미리 정렬한다.

### ① 사업 목적 및 모델 (당초 계획 대비 목적 달성 + **비즈니스 모델** 구체성·타당성)
- HEALO 정체성: 카자흐스탄/러시아/CIS **암환자 → 한국 종양병원** 매칭 의료관광 + 원격협진 플랫폼.
- 보여줄 것: 통합 문의 퍼널(AI/휴먼/폼), 원격협진(LiveKit), 3-Tier RAG AI 상담, 6개 언어.
- BM: 원격진료 매출 + 원격진료 솔루션(매칭) 매출 구분 → 연도별 매출계획(양식 요구사항).
- **[PO 입력 필요]** 당초 사업계획서의 BM 대비 현재 변경점 / 매출 시나리오 숫자.

### ② 사업 추진 실적 (당초 계획 대비)
- 보여줄 것(개발·운영 실적): 통합 문의 퍼널 구축, 원격협진방, 어드민(상담·회원·RAG·AI품질) 등.
- **[PO 입력 필요]** 사업계획서상 월별 일정(4~8월) → 실제 달성. (아래 §4 월별 로그를 매월 채우면 자동 완성)

### ③ 향후 추진계획의 적절성 (실현 가능성)
- 9월~사업종료까지 로드맵. 현지 직원 QA, 실제 환자 유치 확대, 병원 제휴 확대 등.
- **[PO 입력 필요]** 사업 종료 시점 / 잔여 마일스톤.

### ④ 성과지표 달성 정도 및 우수성 ← **가장 중요 (여기가 점수 가른다)**
- 핵심 무기: **유치 전환 깔때기 대시보드가 성과지표를 자동 측정 중.**
- §2 성과지표 표 참조. "ICT 사업이 자기 ICT로 성과를 실시간 계량" = 강력한 스토리.
