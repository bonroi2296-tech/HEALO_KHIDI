## 0. 30초 요약 (바쁘면 이것만)

| 질문 | 답 |
|---|---|
| **K-ETA가 뭐야?** | 비자가 아니다. **비자 없이 올 수 있는 나라 사람이 비행기 타기 전에 온라인으로 미리 받는 「탑승 허가」**. 1만원, 3년 유효. 🔴 **여권 사진면 말고 「얼굴 사진」을 따로 올려야 한다**(100KB·700픽셀 — 여기서 제일 많이 막힘, §1-3). |
| **사증발급인정서는?** | 비자가 아니다. **한국에 있는 초청자(우리·병원)가 법무부에서 미리 "이 환자 비자 내줘도 된다"는 확인 번호를 받아두는 것.** 환자는 현지 대사관에서 그 번호만 적으면 심사 없이 비자를 받는다. |
| **우리 카자흐·러시아 환자는 뭐가 필요해?** | 카자흐 = 무사증 30일 + **K-ETA 필수**. 러시아 = 무사증 60일 + **K-ETA 필수**. 90일 넘거나 정식 의료관광이면 **C-3-3 비자**. 91일 이상 장기치료는 **G-1-10**. |
| **우리가 대행할 수 있어?** | **부분적으로 O.** ①우리가 **초청자로 직접** 사증발급인정서를 신청하는 것 = **가능**(우리 권한, 대행 아님). ②환자를 대신한 출입국 민원 **대행** = **불가**(변호사·행정사만). ③**K-ETA 유료 대행 = 절대 금지**(정부가 공식 대행기관을 지정한 적 없음, 사기 사이트 취급). |
| **그래서 우리 서비스는?** | "**비자 대행업**"이 아니라 "**초청기관으로서 비자가 나오게 만드는 것 + 무료 안내·서류 지원**". 이게 합법이고, 이게 실제로 환자에게 필요한 전부다. |

## 1. K-ETA (전자여행허가) — 쉬운 설명

### 뭔가
비자 없이 한국에 올 수 있는 나라 국민이, **비행기 타기 전에 온라인으로 개인·여행 정보를 미리 내고 받는 허가**다.
- 비자가 아니다. 비자를 대체하지도 않는다.
- 이게 없으면 **항공사가 탑승권을 안 준다.** (한국 도착 전에 막힌다)
- 승인받아도 **입국이 보장되는 건 아니다.** 최종 판단은 인천공항 입국심사관.

### 스펙 (2026-07 기준)
| 항목 | 내용 |
|---|---|
| 신청처 | **공식 사이트 www.k-eta.go.kr / 공식 앱 「K-ETA」 — 이 둘뿐** |
| 수수료 | **10,000원** (이 외 추가금 요구하면 사기) |
| 유효기간 | **3년** (여권 만료일이 더 빠르면 그날까지) |
| 신청 시점 | **반드시 항공기·선박 탑승 전까지.** 심사는 **통상 72시간 이내**(급행 없음) → 실무는 **최소 3일 전, 안전하게 1주 전** |
| 대상 | 무사증 입국 대상 **112개국/지역** 국민(사증면제협정 + 무사증입국허용) 중 한시 면제국이 아닌 사람 |
| 목적 제한 | 관광·친지방문·행사/회의 참가·상용(영리 목적 제외) |
| **업로드 파일** | 🔴 **안면사진(얼굴 사진) 별도 필수** + 여권 인적면 사진 — §1-3 참고 |
| 면제 대상 | 외교·관용여권 소지자, ABTC 카드 소지자, 승무원, 환승객, **17세 이하 / 65세 이상** |
| 한시 면제국 | 일본·미국 등 22개국은 **2026-12-31까지** K-ETA 없이 입국 — **우리 타겟(카자흐·러시아)은 해당 없음** |

### 🔴 사진 — K-ETA에서 가장 많이 막히는 지점

**여권 사진면만 있으면 되는 게 아니다. 「안면사진(얼굴 사진)」을 별도로 올려야 한다.**

| 구분 | 필수? | 규격 |
|---|---|---|
| **① 안면사진 (얼굴 사진)** | 🔴 **필수** | **JPG/JPEG** · **100KB 이하** · **가로·세로 700픽셀 이하** |
| **② 여권 인적면(사진면) 사진** | 법무부 안내 원문상 **선택사항** (JPG · 300KB 이하) — 다만 **실무상 올리는 게 표준** | 앱으로 찍으면 여권정보가 자동 입력됨 |

**안면사진 촬영 조건**
- **컬러** 사진, **정면 응시**, **눈 뜬 상태**
- **얼굴이 사진의 75% 이상** 차지
- **모자·스카프·선글라스 착용 금지** (※ 히잡 등 종교적 착용은 별도 FAQ 존재 — 필요 시 K-ETA 센터에 이메일 문의)
- 화려한 무늬 옷 피하기
- ✅ **여권 사진과 똑같을 필요 없다.** 새로 찍은 사진이어도 된다. (K-ETA 안내에 "6개월 이내 촬영" 같은 기한 조건은 **명시돼 있지 않다** — 그건 C-3-3 비자용 증명사진 조건이다. §6 참고)

> 🚨 **"파일 용량 초과" 에러가 뜨면 = 이 100KB / 700픽셀 제한 때문이다.**
> 법무부 FAQ에 **같은 증상이 별도 문항으로 실려 있을 만큼 흔하다.**
> ✅ **해결책: PC 대신 「K-ETA」 모바일 앱으로 신청하라.** 앱으로 얼굴을 찍으면 **용량·크기를 자동으로 맞춰준다.** 여권도 앱 카메라로 찍으면 인적사항이 자동 입력된다.
> → 환자가 사진에서 막히면 **"앱으로 하세요"가 정답**이다. 이걸 1번 안내로 쓰라.

### 우리 타겟 국가별 (⚠️ 여기가 실무의 전부)

→ 상담 시 **항상 `www.k-eta.go.kr` 링크를 직접 보내라.**

## 2. 사증발급인정서 (CCVI) — 쉬운 설명

### 뭔가
**비자 자체가 아니라, 비자를 빨리·확실하게 받게 해주는 사전 확인서**다.

일반 경로와 비교하면 이렇다:

```
[일반] 환자 → 현지 대사관에 서류 다 내고 처음부터 심사 → 느리고 불허 위험
[인정서] 우리/병원 → 한국 출입국에 미리 신청 → 「사증발급인정번호」 받음
        → 환자에게 번호 전달 → 환자는 대사관에서 여권 + 번호만 제출
        → 대사관은 특별한 사유 없으면 별도 심사 없이 발급 ✅
```

### 스펙
| 항목 | 내용 |
|---|---|
| 근거 | 출입국관리법 제9조 |
| 신청권자 | **입국하려는 외국인 본인 또는 국내 초청자** |
| 신청처 | 초청자 **주소지 관할 출입국·외국인청(사무소·출장소)** |
| 온라인 신청 | **비자포털 www.visa.go.kr** → 로그인 → 「사증발급인정서 신청」 → 체류자격 「의료관광」 선택 → 피초청자 정보 등록 → 첨부서류 업로드 |
| 결과 통지 | 원칙적으로 **이메일로 「사증발급인정번호」** 통지 (부득이한 경우만 인정서 실물 교부) |
| 유효기간 | 🔴 **3개월 · 1회 발급 한정** (기간 지나면 무효, 재신청) |
| 재외공관 처리 | 공관별 **4영업일 ~ 2주** (일부 공관 3~4주 공지) |

> ⚠️ **유효 3개월·1회용**이라는 게 실무의 함정이다. 치료 일정이 확정되지도 않았는데 미리 받아두면 만료되고, 다시 신청해야 한다. **입국일이 대략 잡힌 뒤에 신청**하는 게 맞다.

## 3. 의료관광 비자 두 종류

### C-3-3 (단기방문 — 의료관광) · 90일 이내
- 🔴 **보건복지부에 등록된 「외국인환자 유치기관」이 초청하는 경우에만 발급된다.** → 여기가 우리의 자격 근거.
- 대상: **환자 본인 + 동반가족(배우자·직계존비속) 또는 간병인 최대 2인**
- 수수료: 단수 **US$20** / 복수 **US$80** (1인당)
- 우수 유치기관 초청 건은 지정여행사 관광사증과 동일한 단축 처리

### G-1-10 (기타 — 치료요양) · 91일 이상
- 대상: **B-1(사증면제)·B-2(관광통과)·C-3로 입국한 뒤 검진 등을 통해 장기 치료·요양이 필요하다고 인정된 사람**, 그리고 동반 필요성이 인정되는 배우자 등 가족·간병인
- 체류기간 연장: 일반 **6개월** 범위 / **중증환자는 1년** 범위
- 연장 신청: 만료 **4개월 전부터 만료 당일까지** (전자민원은 만료 전일까지)

> ⚠️ **주의 — 이건 100% 보장이 아니다.** 원칙적으로 무사증(B-1/B-2) 입국자는 체류자격 변경이 제한된다. 치료요양(G-1-10)은 예외적으로 인정되는 대표 사례지만 **심사 재량**이다.
> → **장기치료가 예상되면 처음부터 C-3-3으로 들여오고, 국내에서 G-1-10으로 넘기는 경로를 관할 출입국에 사전 문의**하는 게 안전하다. (※ 이 문단은 실무 재량 영역이라 본 매뉴얼에서 단정하지 않는다 — 첫 장기 케이스 때 관할 출입국에 확인하고 결과를 여기에 기록할 것.)

## 4. 🔑 우리가 대행할 수 있나 — 세 갈래로 정확히

이 질문이 이 문서의 핵심이다. **"대행"이라는 한 단어에 법적으로 완전히 다른 3가지가 섞여 있다.**

### ✅ ① 초청자로서 직접 신청 — **가능. 이게 우리 권한이다.**
- 사증발급인정서는 **"외국인 본인 또는 국내 초청자"**가 신청한다. 우리가 초청자면 **자기 이름으로 내는 본인 민원**이지 남을 대신하는 "대행"이 아니다.
- 본로이는 **외국인환자 유치업 등록기관**: 등록번호 **A-2026-01-02-06761** (서울특별시장, 유효 2026-03-11 ~ 2029-03-10) + SGI 서울보증 배상책임보험 1억.
- 따라서 **C-3-3 초청 자격이 있다.**

> 💡 **다만 실무 권장은 "병원 명의 초청"이다.** 등록 유치의료기관(병원) 명의 초청장이 재외공관 신뢰도가 가장 높다(유치업자 단독보다 강함). 본로이는 **유치업자로 공동 표기**하는 게 현재 우리 방식이다.
> 초청 병원(코드 `inviterHospitals.ts`에 등록됨):
> - **면력한방병원** — 유치의료기관 등록 `M-2025-01-06-8596` (유효 ~2028-03-10)
> - **신촌면력한방병원** — 유치의료기관 등록 `M-2025-01-06-8783` (유효 ~2028-04-30)
> - ⏳ 성동점·광명점도 유치의료기관 등록 완료 → **등록증 정보(등록번호·대표자·유효기간) 입력 대기 중** (`docs/LAUNCH_GATES_PO.md` 참고)

### ❌ ② 환자를 대신한 출입국 민원 「대행」 — **불가.**
- 근거: **출입국관리법 제79조의2 + 「출입국민원 대행기관 관리지침」**(법무부고시)
- **출입국민원 대행기관이 될 수 있는 자**: **변호사, 행정사**, 변호사·행정사 인력을 갖춘 법인, 행정사합동사무소 — **끝.**
  (단, **기술행정사·외국어번역행정사는 제외**)
- 등록 절차: 관할 출입국·외국인청에 **대행기관 등록신청** (변호사 개업신고 서류 / 행정사 업무신고확인증 첨부)
- **유치업 등록증은 대행기관 자격이 아니다.** 유치업 등록(복지부·지자체 소관)과 출입국민원 대행기관 등록(법무부 소관)은 **완전히 다른 제도**다.
- 현황 조회: 하이코리아(hikorea.go.kr) → 정보조회 → 출입국민원 대행기관 현황

> **실무 결론**: 환자의 **체류자격 변경·연장 신청 같은 국내 출입국 민원을 우리가 대신 접수할 수는 없다.**
> 필요하면 **등록 행정사와 제휴**하고, 우리는 서류 준비·번역·동행까지만 한다.

### ❌ ③ K-ETA 유료 대행 — **하지 마라.**
- **정부는 K-ETA 공식 대행기관을 지정한 바 없다.** (외교부·재외공관 공지)
- 유료 대행 사이트는 전부 정부가 "주의" 공지한 유사 사이트다. 우리가 수수료를 받고 대행하면 **같은 부류로 취급된다.**
- ✅ **허용되는 것**: 공식 사이트는 **본인 포함 최대 30명 일괄 대리신청·결제**가 기능적으로 가능하다.
  → 우리는 **무료 지원**(화면 공유하며 입력 도와주기, 러시아어 안내, 사진 규격 확인, 결제 동행)까지만 한다.
- 🔴 **금지**: K-ETA에 별도 수수료를 붙여 상품화. 공식 1만원 외 추가 청구.

## 5. 그래서 환자가 오면 — 4가지 시나리오

```
환자 국적은?
├─ 카자흐스탄 / 러시아 (무사증 O)
│   ├─ 체류 30일(카자흐)·60일(러시아) 이내 + 단순 검진/단기치료
│   │   → 【케이스 A】 무사증 + K-ETA
│   └─ 그 이상 / 동반자 동행 / 정식 유치 / 재입국 필요
│       → 【케이스 B】 C-3-3 + 사증발급인정서
└─ 우즈벡·몽골·키르기스·중국 등 (무사증 X)
    → 【케이스 B】 C-3-3 + 사증발급인정서 (필수)

+ 91일 이상 장기 항암·수술 후 관리가 예상되면 → 【케이스 C】 G-1-10
```

### 【케이스 A】 무사증 + K-ETA — 가장 가벼움
| 단계 | 담당 | 내용 |
|---|---|---|
| 1 | 코디 | 여권 유효기간 6개월 이상 확인 + **여권 영문 성명 정확히 확보** |
| 2 | 코디 | K-ETA **공식 링크만** 안내 (`www.k-eta.go.kr`) + 가짜 사이트 경고 |
| 3 | 환자 | K-ETA 신청 (탑승 72시간 전까지) — 필요 시 화상으로 입력 동행 |
| 4 | 코디 | **진료예약 확인서**(치료 일정·예상 금액) 발급 → 입국심사 대비 |
| 5 | 코디 | 체류 상한 안내: 카자흐 **30일** / 러시아 **60일** — 치료 일정이 넘으면 케이스 B로 |

### 【케이스 B】 C-3-3 + 사증발급인정서 — 우리 표준
| 단계 | 담당 | 내용 | 소요 |
|---|---|---|---|
| 1 | 코디 | 환자 정보·서류 수집 (§6 체크리스트) | 1~2주 (환자 속도) |
| 2 | 코디 | 진료 일정 병원과 확정 → **진료예약 확인서 + 예상 진료비** 발급 | 2~5일 |
| 3 | 코디 | **초청장** 작성 (병원 명의 + 본로이 유치업자 공동 표기, 인감 날인) — 플랫폼 PDF 사용 | 1일 |
| 4 | 코디 | **비자포털(visa.go.kr)에서 사증발급인정서 신청** — 체류자격 「의료관광」 | 접수 |
| 5 | 출입국 | 심사 → **사증발급인정번호 이메일 통지** | 통상 1~2주 |
| 6 | 코디 | 환자에게 **인정번호 + 관할 재외공관 안내** 전달 | 즉시 |
| 7 | 환자 | 현지 대사관/영사관에 여권 + 사증발급신청서(인정번호 기재) 제출 | 4영업일~2주 |
| 8 | 환자 | 비자 발급 → 항공권 발권 → 입국 | — |

> ⏱ **전체 리드타임 4~8주**로 잡아라. 환자에게 "치료 시작 최소 6주 전에 시작하자"고 말하는 게 안전하다.

### 【케이스 C】 G-1-10 (91일 이상)
- 입국 후 검진에서 장기치료 필요가 확인되면 관할 출입국에 체류자격 변경 신청.
- **우리가 대신 접수할 수 없다**(§4-②) → 환자 본인 방문 또는 등록 행정사 제휴.
- 우리 역할: 병원 소견서·치료계획서·입원확인서·비용 증빙 준비 + 동행 통역.
- 연장은 만료 **4개월 전부터** 신청 가능 → **캘린더에 미리 걸어라.**

## 6. 📋 환자에게 요청할 정보·서류 (체크리스트)

**핵심 원칙: 한 번에 다 요구하지 마라.** 환자가 도망간다. 3단계로 나눠 받는다.

### 1단계 — 문의 접수 즉시 (최소 정보, 5개)
- [ ] **국적** (여권 발급국)
- [ ] **여권 영문 성명** — 🔴 여권에 적힌 철자 그대로. 한 글자 틀리면 항공 탑승 거부.
- [ ] **생년월일 · 성별**
- [ ] **희망 입국 시기** (대략)
- [ ] **치료 목적 / 진단명** (진단서 있으면 사진이라도)

→ 이것만으로 §5 시나리오 판정 + 비자 필요 여부 답변이 가능하다.

### 2단계 — 사증발급인정서 신청 확정 시 (환자 서류)
| 서류 | 상세 | 비고 |
|---|---|---|
| [ ] 여권 사본 | 사진면 스캔, **유효기간 6개월 이상** | 필수 |
| [ ] 증명사진 | **3.5×4.5cm 컬러, 최근 6개월 이내 촬영** | 필수 |
| [ ] 사증발급신청서 | 소정 양식 | 필수 |
| [ ] 의료 입증자료 | **현지 병원 진단서 또는 의사 소견서** | 필수 |
| [ ] **재정능력 입증** | 잔고증명서 — **총 예치액 6개월간 US$5,000 이상 + 예치기간 1개월 이상** | 🔴 **불허 1순위 사유** |

**동반자가 있으면 추가로:**
- [ ] **동반가족**(배우자·직계존비속): 가족관계 증명서류 — 혼인증명서·출생증명서 (**아포스티유 또는 번역 공증**)

> 🔴 **번역 함정**: 한국어·영어가 아닌 서류(러시아어·카자흐어 진단서 등)는 **공증 번역**이 필요하다. 이걸 미리 말 안 하면 마지막에 2주가 날아간다.

### 3단계 — K-ETA 신청용 (케이스 A일 때)
- [ ] 여권 정보 (국적·성명·생년월일·성별·번호·발급일·만료일)
- [ ] 🔴 **안면사진 파일** — **JPG · 100KB 이하 · 700픽셀 이하** (§1-3. 여권사진과 달라도 됨)
- [ ] 여권 인적면 사진 (JPG · 300KB 이하 — 원문상 선택이나 실무상 첨부)
- [ ] **한국 내 체류지 주소·연락처** — 숙소 미정이면 병원 주소 안내
- [ ] 이메일 주소 (**승인 통지가 여기로 옴** — 오타 나면 결과를 못 받는다)
- [ ] 직업 · 복수국적 여부
- [ ] 항공 일정(예정)

> ⚠️ **사진에서 막히면 「K-ETA 앱으로 하세요」가 1번 답이다** (앱이 용량·크기 자동 보정). §1-3 참고.
> ⚠️ **신청은 본인이 아니어도 된다** — 법무부 안내상 **가족·친구 등이 대리로 신청** 가능하고, 공식 사이트에서 **본인 포함 최대 30명 일괄 신청·결제**도 된다. 단 **우리가 수수료를 받는 유료 대행은 금지**(§4-③).

## 8. ⚠️ 자주 걸리는 함정 (실제로 사고 나는 지점)

1. **여권 영문 철자 불일치** — K-ETA·비자·항공권 이름이 한 글자라도 다르면 **탑승 거부**. 접수 1단계에서 여권 사진을 받아 대조하라.
2. **재정능력 서류** — C-3-3 불허 1순위. **US$5,000 · 예치기간 1개월 이상** 조건을 미리 정확히 알려라. (※ 우수 유치기관이 되면 e-Visa 한정으로 **면제** — §9)
3. **번역 공증 누락** — 러시아어·카자흐어 진단서는 공증 번역 필요. 마지막에 발견하면 2주 손실.
4. **사증발급인정서 3개월·1회용** — 일정 확정 전에 미리 받아두면 만료. 재신청해야 한다.
5. **"K-ETA 받았으니 입국 확정"이라는 오해** — K-ETA는 탑승 허가일 뿐, 최종 판단은 입국심사관. 환자에게 진료예약 확인서·숙소 정보를 소지시켜라.
6. **무사증 체류 상한 착각** — 카자흐 **30일**(러시아 60일 아님). 치료 일정이 30일을 넘으면 케이스 A는 무효다.
7. **가짜 K-ETA 사이트 결제** — 상담 시 항상 공식 링크를 직접 보낼 것.
8. **17세 이하·65세 이상은 K-ETA 면제** — 하지만 **무사증 자격 자체는 별개**다. "면제"를 "비자 필요 없음"으로 잘못 안내하지 마라.
9. 🔴 **환자 이탈(불법체류)은 초청기관 책임으로 돌아온다** — 우수 유치기관 심사에서 **불법체류율이 60점(가장 큰 배점)**이다. 초청은 신중하게, 귀국 확인까지 사후관리 케이던스로 추적하라.
10. 🔴 **K-ETA 안면사진 「용량 초과」 에러** — 법무부 FAQ에 별도 문항으로 실릴 만큼 흔한 지점. **100KB · 700픽셀** 제한이 원인. → **「K-ETA 앱으로 다시 하세요」**가 정답(자동 보정). §1-3 참고. **여권 사진면만 올리면 된다고 잘못 안내하지 마라 — 얼굴 사진이 별도로 필수다.**
11. **K-ETA 이메일 오타** — 승인 결과가 이메일로만 온다. 접수 때 이메일을 한 번 복창시켜라.
12. **K-ETA로 들어오면 체류자격 변경은 원칙적으로 불허** — 법무부 안내 원문이 "원칙적으로 체류자격 변경은 허용되지 않는다"이다. **장기치료가 예상되면 처음부터 C-3-3으로 들여와라**(§3·§5-C).

## 9. 다음 단계 (전략) — 「의료관광 우수 유치기관」 지정

**이게 우리가 합법적으로 "진짜 대행"에 가장 가까워지는 유일한 길이다.**

법무부가 지정하는 제도로, 지정되면 **「전자사증(e-Visa) 대리신청기관」** 자격이 붙는다.

| 항목 | 내용 |
|---|---|
| **신청 자격** | 최근 1년간 **의료관광 초청(비자) 실적 30건 이상** **또는** 외국인 진료실적 **500건 이상** (유치기관 = 병원·유치업자 모두 대상) |
| **심사 배점** | **불법체류율 60점** + 초청/진료·유치실적 40점 (+ 사증 불허율) |
| **심사 면제** | 보건복지부 인증 유치기관(KAHF) · 상급종합병원 |
| **혜택 ①** | 🔑 **비자포털에서 전자사증(e-Visa) 직접 신청 권한** — 대사관 방문 없이 온라인으로 |
| **혜택 ②** | 🔑 **환자 재정능력 입증서류 제출 면제** (e-Visa 신청 한정) — §8-2 불허 1순위가 사라진다 |
| **혜택 ③** | 동반 가능 범위 확대 — 직계·형제자매 → **4촌 이내 방계가족** |
| **혜택 ④** | 처리기간 단축 (지정여행사 관광사증 수준) |
| **제외** | 최근 2년 이내 지정 취소 이력 |

### 우리 현실과 로드맵
- 현재 유치 실적 = 사실상 0 → **지금은 신청 불가.**
- **KHIDI 중간평가 목표 「외국인환자 유치 12건」(8/27)이 곧 우수기관 요건 30건의 40%다.** 두 목표가 같은 방향이다.
- 📌 **실무 조치**: 케이스 B(사증발급인정서 초청)를 돌릴 때마다 **초청 건수를 별도로 카운트**하라. 나중에 우수기관 신청서에 그대로 들어간다.

## 11. 검증 상태 (정직 고지)

- ✅ **문서 조사로 확인**: K-ETA 스펙·면제 대상, 카자흐/러시아 무사증+K-ETA 필요, 사증발급인정서 절차·유효기간, C-3-3/G-1-10 요건·서류, 출입국민원 대행기관 자격(변호사·행정사 한정), 우수 유치기관 요건·혜택, K-ETA 공식 대행기관 부존재 — 모두 **정부·재외공관 공식 출처 기준**.
- ⚠️ **실제 케이스로 검증 못 함**: 우리가 초청자로 사증발급인정서를 **실제 신청해 본 적이 없다.** 첫 케이스에서 ①비자포털 계정 개설 절차 ②유치업자 단독 초청 vs 병원 명의 초청의 실제 수용 여부 ③실 소요일수 를 확인하고 **이 문서에 반영할 것.**
- ⚠️ **G-1-10 자격 변경 가능 여부**(§3)는 심사 재량 영역이라 단정하지 않았다. 첫 장기 케이스 때 관할 출입국에 문의하고 결과를 기록할 것.

### 🔧 2026-07-27 정정 이력 (초판의 오류)

PO가 *"K-ETA에 여권 사진 말고 증명사진도 필요하다는데 정확히 확인해봐"*라고 되물어 재검증한 결과, **초판 §6 3단계가 부정확**해서 고쳤다.

| 초판(틀림) | 정정 |
|---|---|
| "최근 6개월 이내 촬영 사진 파일(JPG)" | **"안면사진 JPG·100KB 이하·700픽셀 이하"** — K-ETA 안내에 **「6개월 이내」 기한 조건은 없다.** 그건 **C-3-3 비자용 증명사진(3.5×4.5cm) 조건**인데 내가 두 제도를 섞어 썼다. |
| 사진이 1장인 것처럼 서술 | **업로드는 2종**(안면사진 = 필수 / 여권 인적면 = 원문상 선택) |
| 규격 미기재 | 규격·촬영조건·**용량초과 시 앱 사용** 대처법 추가(§1-3, §8-10) |
| "탑승 최소 72시간 전 권장" | **"탑승 전까지 필수 + 심사 통상 72시간 이내"** (72시간은 신청 마감이 아니라 **심사 소요시간**) |

- ⚠️ **여전히 못 확인한 것**: 「여권 인적면 사진 첨부 = 선택사항」은 **법무부 FAQ 원문(2021년판)**에만 명시돼 있고, **현행 K-ETA 화면에서도 선택인지는 확인 못 했다**(공식 사이트가 규격 상세를 게시하지 않고, 실제 신청 화면은 여권번호 입력 후에야 열림). **실무는 그냥 올리는 것으로 안내**하라. 첫 환자 신청 때 화면을 보고 확정할 것.
