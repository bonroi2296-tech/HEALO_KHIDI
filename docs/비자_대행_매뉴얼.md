## 0. 30초 요약 (바쁘면 이것만)

| 질문 | 답 |
|---|---|
| **K-ETA가 뭐야?** | 비자가 아니다. **비자 없이 올 수 있는 나라 사람이 비행기 타기 전에 온라인으로 미리 받는 「탑승 허가」**. 1만원(+카드수수료 3%), 3년 유효. 🔴 **사진을 2장 올려야 한다 — 여권 인적면 사진 + 얼굴 사진, 둘 다 필수**(§1-3, 여기서 제일 많이 막힌다). |
| **사증발급인정서는?** | 비자가 아니다. **한국에 있는 초청자(우리·병원)가 법무부에서 미리 "이 환자 비자 내줘도 된다"는 확인 번호를 받아두는 것.** 환자는 현지 대사관에서 그 번호만 적으면 심사 없이 비자를 받는다. |
| **우리 카자흐·러시아 환자는 뭐가 필요해?** | 카자흐 = 무사증 30일 + **K-ETA 필수**. 러시아 = 무사증 60일 + **K-ETA 필수**. 90일 넘거나 정식 의료관광이면 **C-3-3 비자**. 91일 이상 장기치료는 **G-1-10**. |
| **우리가 대행할 수 있어?** | **부분적으로 O.** ①우리가 **초청자로 직접** 사증발급인정서를 신청하는 것 = **가능**(우리 권한, 대행 아님). ②환자를 대신한 출입국 민원 **대행** = **불가**(변호사·행정사만). ③**K-ETA 유료 대행 = 절대 금지**(정부가 공식 대행기관을 지정한 적 없음). 단 **무료로 대신 신청·대신 결제하는 것은 공식 FAQ가 명시 허용**한다(§4-③). |
| **그래서 우리 서비스는?** | "**비자 대행업**"이 아니라 "**초청기관으로서 비자가 나오게 만드는 것 + 무료 안내·서류 지원**". 이게 합법이고, 이게 실제로 환자에게 필요한 전부다. |

## 1. K-ETA (전자여행허가) — 쉬운 설명

### 뭔가
비자 없이 한국에 올 수 있는 나라 국민이, **비행기 타기 전에 온라인으로 개인·여행 정보를 미리 내고 받는 허가**다.
- 비자가 아니다. 비자를 대체하지도 않는다.
- 이게 없으면 **항공사가 탑승권을 안 준다.** (한국 도착 전에 막힌다)
- 승인받아도 **입국이 보장되는 건 아니다.** 최종 판단은 인천공항 입국심사관.

### 스펙 (2026-07 기준 · 출처 = 법무부 2026-01-01판 신청방법 안내 + K-ETA 공식 FAQ)
| 항목 | 내용 |
|---|---|
| 신청처 | **공식 사이트 www.k-eta.go.kr / 공식 앱 「K-ETA」 — 이 둘뿐** |
| 수수료 | **10,000원 + 온라인 결제수수료 3% → 실제 결제창 청구액 `KRW 10,306`** (이 외 추가금을 요구하면 사기) |
| 결제수단 | 🔴 **해외 온라인결제가 되는 국제 신용·직불카드만** (VISA·MASTER·AMEX·JCB·Diners·DISCOVER·UnionPay·Alipay+). **계좌이체 불가.** 국내 발급카드는 「은행」이 아니라 **「카드사」**를 골라야 한다 |
| 유효기간 | **3년** (여권 만료일이 더 빠르면 그날까지) |
| 신청 시점 | **반드시 항공기·선박 탑승 전까지.** 심사는 **일반적으로 72시간 이내**지만 **72시간 이상 걸릴 수 있고 급행(express)은 없다** → 실무는 **최소 1주 전** |
| 대상 | 무사증 입국 대상 **112개국/지역** 국민 = **사증면제협정(B-1) 67개국 + 무사증입국허용(B-2) 45개국**(+영국 보호민 등 5종) 중 한시 면제국이 아닌 사람 |
| 목적 제한 | 관광·친지방문·행사/회의 참가·상용(영리 목적 제외) |
| **업로드 파일** | 🔴 **여권 인적면 사진 + 안면사진(얼굴 사진) 둘 다 필수** — §1-3 참고 |
| 면제 대상 | 외교·관용여권 소지자, ABTC 카드 소지자, 승무원, **단순 환승객**, **17세 이하 / 65세 이상**, **유효한 사증(VISA)·외국인등록증·거소증 소지자** |
| 한시 면제국 | 일본·미국 등 22개국은 **2026-12-31까지** K-ETA 없이 입국 — **우리 타겟(카자흐·러시아)은 해당 없음** |

> ⚠️ **면제 관련 함정 2개 (공식 FAQ 원문)**
> - **「입국일 기준 18세가 되는 경우 K-ETA 허가서가 필요하다.」** 신청 시점에 17세여도 입국일에 18세면 받아야 한다.
> - 면제 대상자도 **원하면 신청할 수 있다.** 받으면 **입국신고서 작성이 생략**된다(대신 수수료는 낸다). 고령 환자에게 줄서기를 줄여주고 싶으면 쓸 수 있는 카드다.
> - **단순 환승**은 불필요하지만, 수하물 재수속 등으로 **입국심사대를 통과해야 하면 필요**하다. 이때 체류지 주소·연락처 칸에는 **환승 공항 주소·전화번호**를 적는다(예: 인천공항 `272 Gonghang-ro, Jung-gu, Incheon 22382`, `+82 1577-2600`).

### 🔴 사진 — K-ETA에서 가장 많이 막히는 지점

**여권 사진면만 있으면 되는 게 아니다. 「안면사진(얼굴 사진)」을 별도로 올려야 한다. 그리고 둘 다 필수다.**

| 구분 | 필수? | 규격·주의 |
|---|---|---|
| **① 여권 인적면(사진면) 사진** | 🔴 **필수** | 2026-01-01판 공식 안내 화면 문구가 **「[필수] 여권 인적면을 찍은 사진을 업로드 해주세요」**. 업로드하면 인적사항이 자동 입력된다. 🔴 **사진 하단의 MRZ(기계판독 영역 2줄)가 반드시 화면에 들어와야 한다.** |
| **② 안면사진 (얼굴 사진)** | 🔴 **필수** | **JPG/JPEG** · **100KB 이하** · **가로·세로 700픽셀 이하** (신청화면의 「사진 규격 안내」 버튼에서 최신 규격 확인 가능) |

**안면사진 촬영 조건**
- **컬러** 사진, **정면 응시**, **눈 뜬 상태**
- **얼굴이 사진의 75% 이상** 차지
- **모자·스카프·선글라스 착용 금지** (※ 히잡 등 종교적 착용은 별도 FAQ 존재 — 필요 시 K-ETA 센터에 이메일 문의)
- 화려한 무늬 옷 피하기
- ✅ **여권 사진과 똑같을 필요 없다.** 새로 찍은 사진이어도 된다. (K-ETA 안내에 "6개월 이내 촬영" 같은 기한 조건은 **명시돼 있지 않다** — 그건 C-3-3 비자용 증명사진 조건이다. §6 참고)

> 🚨 **"파일 용량 초과" 에러가 뜨면 = 이 100KB / 700픽셀 제한 때문이다.**
> 법무부 FAQ에 **같은 증상이 별도 문항으로 실려 있을 만큼 흔하다.**
> ✅ **해결책: PC 대신 「K-ETA」 모바일 앱으로 신청하라.** 앱으로 얼굴을 찍으면 **용량·크기를 자동으로 맞춰준다.** 여권도 앱 카메라로 찍으면 인적사항이 자동 입력된다.
> → 환자가 사진에서 막히면 **"앱으로 하세요"가 정답**이다. 이걸 1번 안내로 쓰라.

> 📌 **여권 사진을 올렸는데 국적이 자동 입력되지 않으면** = 이미지 품질 문제다. 공식 안내 문구가 **「고화질 이미지를 정방향으로 다시 업로드하라」**이다. 그리고 **국적은 나중에 수정할 수 없다**(성·이름·여권번호 등은 확인 화면에서 수정 가능).

### 신청 7단계 (2026-01-01판 공식 안내 그대로)

| STEP | 화면 | 코디가 챙길 것 |
|---|---|---|
| 1 | 약관 동의 | — |
| 2 | **이메일 인증** (인증번호 5분) | 🔴 **여기 적은 이메일로 심사결과·신청번호가 온다.** 환자가 못 여는 메일이면 우리 메일로 받고 전달하라 |
| 3 | **여권정보 입력** | 여권 인적면 사진 업로드 → 자동 입력 → **오타 재확인**(특히 알파벳 `O` / 숫자 `0`) |
| 4 | **신청정보 입력** | 안면사진, 입국목적, 체류예정지(우편번호 검색), 체류예정지 연락처, 입·출국 예정일, 감염병·범죄 이력, 동반인, 직업 |
| 5 | 입력정보 확인 | 신청인별로 하나씩 열어 확인 |
| 6 | **수수료 결제** | 1인당 ₩10,000 + 3% (§1 스펙) |
| 7 | 신청 완료 | **대표자 신청번호 + 개별신청번호**가 발급된다. **둘 다 결과조회에 필요하니 보관**(이메일로도 자동 발송) |

**입력 실무 팁 (공식 안내 문구 기준)**
- **입국 목적**: 해당 항목이 없으면 `기타` 선택 후 **영문으로 직접 입력**.
- **체류 예정지**: 우편번호·도로명·건물명으로 검색. 상세주소(호실 등)가 없으면 `NONE`. → **숙소 미정이면 우리가 병원 주소·우편번호를 미리 보내줘라.**
- **체류 예정지 연락처**: "신청인, 회사, 지인, 호텔, 게스트하우스 등 **한국 내 연락 가능한 연락처**" → **코디네이터 번호를 적어도 된다.**
- **출국 예정 편명**은 선택 입력. 입·출국 예정일은 필수.
- **여행정보(입국목적·체류지·연락처)는 허가 후에도 [여행정보 업데이트]에서 수정 가능**하고, **입·출국일이 바뀌어도 재신청할 필요 없다.**

> 🔴 **감염병 문항은 「암 환자」와 무관하다 — 여기서 잘못 답하지 마라.**
> 신청서의 `감염병 여부`는 **지정된 15종 감염병**(콜레라·페스트·황열·SARS·조류인플루엔자 인체감염증·신종인플루엔자·MERS·에볼라·결핵·마버그열·라싸열·크리미안콩고출혈열·두창·디프테리아·신종감염병증후군)에 **현재 걸려 있는지**를 묻는 것이다.
> **암·심혈관질환 등은 여기 해당하지 않는다 → `아니요`.** 단 **결핵은 목록에 있다.**
> 해당되는데 거짓으로 `아니오`를 고르면 **관계법령에 따라 처벌·입국제한**될 수 있다. 반대로 겁먹고 `네`를 골라 병명을 적으면 불허 위험이 생긴다. **코디가 반드시 함께 확인하라.**

## 2. 사증발급인정서 (CCVI) — 쉬운 설명

### 뭔가
**비자 자체가 아니라, 비자를 빨리·확실하게 받게 해주는 사전 확인서**다.

일반 경로와 비교하면 이렇다:

```
[일반] 환자 → 현지 대사관에 서류 다 내고 처음부터 심사 → 느리고 불허 위험
[인정서] 우리/병원 → 한국 출입국에 미리 신청 → 「사증발급인정번호」 받음
        → 환자에게 번호 전달 → 환자는 대사관에서 여권 + 번호만 제출
        → 대사관은 특별한 사유 없으면 별도 심사 없이 발급 ✅
```

> ⚠️ **이름이 비슷한 두 서류를 헷갈리지 마라.**

> - **사증발급신청서** = **환자가** 현지 재외공관에 내는 비자신청서. 여기에 위 인정번호를 적는다.

## 4. 🔑 우리가 대행할 수 있나 — 세 갈래로 정확히

이 질문이 이 문서의 핵심이다. **"대행"이라는 한 단어에 법적으로 완전히 다른 3가지가 섞여 있다.**

### ✅ ① 초청자로서 직접 신청 — **가능. 이게 우리 권한이다.**
- 사증발급인정서는 **"외국인 본인 또는 국내 초청자"**가 신청한다. 우리가 초청자면 **자기 이름으로 내는 본인 민원**이지 남을 대신하는 "대행"이 아니다.
- 본로이는 **외국인환자 유치업 등록기관**: 등록번호 **A-2026-01-02-06761** (서울특별시장, 유효 2026-03-11 ~ 2029-03-10) + SGI 서울보증 배상책임보험 1억.
- 따라서 **C-3-3 초청 자격이 있다.**

> 💡 **다만 실무 권장은 "병원 명의 초청"이다.** 등록 유치의료기관(병원) 명의 초청장이 재외공관 신뢰도가 가장 높다(유치업자 단독보다 강함). 실제로 **주블라디보스톡 총영사관은 「복지부 의료관광유치기관 지정증 + 사업자등록증 + 사업자등록증상 대표자 명의 초청장」을 명시 요구**한다. 본로이는 **유치업자로 공동 표기**하는 게 현재 우리 방식이다.
> 초청 병원 (코드 `inviterHospitals.ts`에 등록됨):
> - **면력한방병원** — 유치의료기관 등록 `M-2025-01-06-8596` (유효 ~2028-03-10)
> - **신촌면력한방병원** — 유치의료기관 등록 `M-2025-01-06-8783` (유효 ~2028-04-30)
> - ⏳ 성동점·광명점도 유치의료기관 등록 완료 → **등록증 정보(등록번호·대표자·유효기간) 입력 대기 중** (`docs/LAUNCH_GATES_PO.md` 참고)

### ❌ ② 환자를 대신한 출입국 민원 「대행」 — **불가.**
- 근거: **출입국관리법 제79조의2 + 「출입국민원 대행기관 관리지침」**(법무부고시)
- **출입국민원 대행기관이 될 수 있는 자**: **변호사, 행정사**, 변호사·행정사 인력을 갖춘 법인, 행정사합동사무소 — **끝.**
  (단, **기술행정사·외국어번역행정사는 제외**)
- 등록 절차: 관할 출입국·외국인청에 **대행기관 등록신청** (변호사 개업신고 서류 / 행정사 업무신고확인증 첨부)
- **유치업 등록증은 대행기관 자격이 아니다.** 유치업 등록(복지부·지자체 소관)과 출입국민원 대행기관 등록(법무부 소관)은 **완전히 다른 제도**다.
- 현황 조회: 하이코리아(hikorea.go.kr) → 정보조회 → 출입국민원 대행기관 현황

> **실무 결론**: 환자의 **체류자격 변경·연장 신청 같은 국내 출입국 민원을 우리가 대신 접수할 수는 없다.**
> 필요하면 **등록 행정사와 제휴**하고, 우리는 서류 준비·번역·동행까지만 한다.

### ❌ ③ K-ETA 유료 대행 — **하지 마라.** (단, 무료 대신신청·대신결제는 공식 허용)
- **정부는 K-ETA 공식 대행기관을 지정한 바 없다.** (외교부·재외공관 공지)
- 유료 대행 사이트는 전부 정부가 "주의" 공지한 유사 사이트다. 우리가 수수료를 받고 대행하면 **같은 부류로 취급된다.**
- 🔴 **금지**: K-ETA에 별도 수수료를 붙여 상품화. 공식 1만원 외 추가 청구.

## 5. 그래서 환자가 오면 — 4가지 시나리오

```
환자 국적은?
├─ 카자흐스탄 / 러시아 (무사증 O)
│   ├─ 체류 30일(카자흐)·60일(러시아) 이내 + 단순 검진/단기치료
│   │   → 【케이스 A】 무사증 + K-ETA
│   └─ 그 이상 / 동반자 동행 / 정식 유치 / 재입국 필요
│       → 【케이스 B】 C-3-3 + 사증발급인정서
└─ 우즈벡·몽골·키르기스·중국 등 (무사증 X)
    → 【케이스 B】 C-3-3 + 사증발급인정서 (필수)

+ 91일 이상 장기 항암·수술 후 관리가 예상되면 → 【케이스 C】 G-1-10
```

### 【케이스 A】 무사증 + K-ETA — 가장 가벼움
| 단계 | 담당 | 내용 |
|---|---|---|
| 1 | 코디 | 여권 유효기간 6개월 이상 확인 + **여권 영문 성명 정확히 확보**(MRZ 기준) |
| 2 | 코디 | K-ETA **공식 링크만** 안내 (`www.k-eta.go.kr`) + 가짜 사이트 경고 |
| 3 | 환자/코디 | K-ETA 신청 — **탑승 전까지 필수, 실무는 1주 전.** 필요 시 화상으로 입력 동행. 🔴 **결제 주체는 §4-③ 표대로**(러시아 = 우리, 카자흐 = 환자 본인 원칙) |
| 4 | 코디 | **진료예약 확인서**(치료 일정·예상 금액) 발급 → 입국심사 대비. 🔴 **입국심사관은 방문 목적을 확인한다** — 환자가 "무엇 때문에 어느 병원에 며칠"을 스스로 말할 수 있게 미리 맞춰둬라 |
| 5 | 코디 | 체류 상한 안내: 카자흐 **30일** / 러시아 **60일** — 치료 일정이 넘으면 케이스 B로 |

### 【케이스 B】 C-3-3 + 사증발급인정서 (90일 이하) — 우리 표준
| 단계 | 담당 | 내용 | 소요 |
|---|---|---|---|
| 1 | 코디 | 환자 정보·서류 수집 (§6 체크리스트) + **관할 공관 공지 확인**(§3 표) | 1~2주 (환자 속도) |
| 2 | 코디 | 진료 일정 병원과 확정 → **진료예약 확인서 + 예상 진료비** 발급 | 2~5일 |
| 3 | 코디 | **초청장** 작성 (병원 명의 + 본로이 유치업자 공동 표기, 인감 날인) — 플랫폼 PDF 사용 | 1일 |
| 4 | 코디 | **비자포털(visa.go.kr)에서 사증발급인정서 신청** — 체류자격 「의료관광」 | 접수 |
| 5 | 출입국 | 심사 → **사증발급인정번호 이메일 통지** | 통상 1~2주 |
| 6 | 코디 | 환자에게 **인정번호·발급일·여권번호·여권만료일 4종 + 관할 재외공관 안내** 전달 (§2 표) | 즉시 |
| 7 | 환자 | 현지 대사관/영사관에 여권 + 사증발급신청서(인정번호 기재) 제출 | 4영업일~2주 |
| 8 | 환자 | 비자 발급 → 항공권 발권 → 입국 | — |

> ⏱ **전체 리드타임 4~8주**로 잡아라. 환자에게 "치료 시작 최소 6주 전에 시작하자"고 말하는 게 안전하다.

### 【케이스 C】 G-1-10 (91일 이상)
- 입국 후 검진에서 장기치료 필요가 확인되면 관할 출입국에 체류자격 변경 신청.
- **우리가 대신 접수할 수 없다**(§4-②) → 환자 본인 방문 또는 등록 행정사 제휴.
- 우리 역할: 병원 소견서·치료계획서·입원확인서·비용 증빙 준비 + 동행 통역.
- 연장은 만료 **4개월 전부터** 신청 가능 → **캘린더에 미리 걸어라.**

### 5-1. 「외국인환자 유치 운영 매뉴얼」과의 역할 분담

두 문서는 **겹치는 게 아니라 층이 다르다.** 중복 서술하지 말고 아래대로 나눈다.

| 문서 | 다루는 것 | 최신본 |
|---|---|---|
| **외국인환자 유치 운영 매뉴얼** | 문의→확정→입국→수술 전후→퇴원→사후관리 **전체 여정의 단계·담당(본로이/면력/병원)** | 🔴 **`_v2`가 최신**이다 (`_교정`이 아니다 — v2에만 「B-c 변경·취소」, 동반자 인원 확인, 90일 초과 시 외국인등록 안내, 진료요약서(러시아어), 만족도 설문, 재이용 상담이 들어 있다) |
| **비자 대행 매뉴얼**(이 문서) | 그 여정 중 **비자·K-ETA 한 칸을 어떻게 실제로 처리하는지** | 이 파일 |

**연결 지점 3개 (운영 매뉴얼 → 이 문서)**
1. `B. 확정 – a. 치료 결정 – 3. K-ETA 신청 대행이 필요한지 확인` → **§4-③**(무료 지원 범위·결제 주체)
2. `B. 확정 – a. 치료 결정 – 4. 진료 초청장·사증발급신청서 발급 필요 여부 확인(동반자 포함)` → **§5 케이스 B** + **§2**(인정서 vs 신청서 용어 구분)
3. `C. 입국 – b. 병원 방문 – 3. 체류 예정 기간이 90일을 넘으면 비자 연장·외국인등록 안내` → **§3 G-1-10** + **§4-②**(우리가 대신 접수 못 한다)

> ⚠️ 운영 매뉴얼 본문의 **"K-ETA 신청 대행"**은 **유료 대행이 아니라 무료 대신신청**을 뜻한다. 외부 공유용 문서에서는 오해를 피하려면 **"K-ETA 신청 지원"**으로 표현하는 게 안전하다.

## 6. 📋 환자에게 요청할 정보·서류 (체크리스트)

**핵심 원칙: 한 번에 다 요구하지 마라.** 환자가 도망간다. 3단계로 나눠 받는다.

### 1단계 — 문의 접수 즉시 (최소 정보, 5개)
- [ ] **국적** (여권 발급국)
- [ ] **여권 영문 성명** — 🔴 여권에 적힌 철자 그대로. 한 글자 틀리면 항공 탑승 거부.
- [ ] **생년월일 · 성별**
- [ ] **희망 입국 시기** (대략)
- [ ] **치료 목적 / 진단명** (진단서 있으면 사진이라도)

→ 이것만으로 §5 시나리오 판정 + 비자 필요 여부 답변이 가능하다.

> 🔴 **영문 성명은 「MRZ 기준」으로 받아라** (K-ETA 공식 FAQ 러시아어판 지침).
> 여권 하단 기계판독영역(MRZ) 첫 줄에서 **왼쪽 6번째 글자부터가 성**이고, `《`(<<) 뒤가 이름, `〈`(<) 뒤가 부칭이다.
> - 예1: `P<RUSPETRENKO<<OTTO<VON` → 성 `PETRENKO`, 이름 `OTTO VON`
> - 예2: `P<KAZASANOV<<OTTOVON` → 성 `ASANOV`, 이름 `OTTOVON`
> - **이름에 하이픈이 있으면 하이픈을 빼고 적는다.**
> - 여권번호: **러시아는 9자리 숫자**(시리즈 2자리 + 번호 7자리, `N`과 공백 없이). **카자흐는 영문 1자 + 숫자 8자리.**

### 2단계 — 사증발급인정서 신청 확정 시 (환자 서류)
| 서류 | 상세 | 비고 |
|---|---|---|
| [ ] 여권 사본 | 사진면 스캔, **유효기간 6개월 이상** | 필수 |
| [ ] 증명사진 | **3.5×4.5cm 컬러, 최근 6개월 이내 촬영** | 필수 (K-ETA 안면사진과 별개) |
| [ ] 사증발급신청서 | 소정 양식 | 필수 |
| [ ] 의료 입증자료 | **현지 병원 진단서 또는 의사 소견서** | 필수 |
| [ ] **재정능력 입증** | 🔴 **공관마다 기준이 다르다 — §3 표 확인 후 안내.** 카자흐는 최저한도 없음(1일 US$100 체제비 + 진료비 기준 심사) / 베트남은 US$5,000·1개월 | **불허 1순위 사유** |
| [ ] 신분 입증서류 | 재직증명서 / 근로계약서 / 사업자등록증 / 학생증 중 1 | 필수 |
| [ ] 신분증 사본 | 현지 신분증 (카자흐는 주재국 주소지 등록증도) | 필수 |
| [ ] 연락처 | 현 주소 · 휴대폰 · 이메일 (인정번호 수신용) | 필수 |
| [ ] 방문 이력 | 과거 한국 방문·비자 발급/거절 이력, 강제퇴거 이력 | 심사 영향 |

**동반자가 있으면 추가로:**
- [ ] **동반가족**(배우자·직계존비속): 가족관계 증명서류 — 혼인증명서·출생증명서
- [ ] **간병인**: **간병계약서 사본** — 🔴 인원 상한이 공관마다 다르다(베트남 2인 / 블라디보스톡 **보호자 1명**). §3 표 확인

> 🔴 **번역 요건 — "무조건 공증"이 아니다** (2026-07-27 재확인)
> - **번역 자체는 어디서나 필수**다. 한국어·영어가 아닌 진단서·소견서는 **국문 또는 영문 번역본을 반드시 첨부**한다.
> - **공증까지 요구하는지는 공관마다 다르다.**
>   - **주카자흐스탄 대사관**: **"카자흐스탄 소견서/진단서는 영문 또는 국문 번역 첨부"** — **공증 요구 문구 없음.**
>   - **주베트남 대사관**: **"정부가 지정한 공증사무소에서 한글 또는 영문 번역 공증 필요"** — 공증 요구.
>   - **주블라디보스톡 총영사관**: 번역·공증 문구 **없음**.
> - **가족관계 증명서류(혼인·출생증명서)**는 성격상 아포스티유·영사확인이 요구되는 경우가 많다 → **동반가족 케이스는 접수 전에 반드시 공관에 확인.**
> - 📌 **실무 규칙**: 기본은 **「번역본 첨부」**로 안내하고, **공증은 그 환자의 관할 공관 공지를 열어 확인한 뒤** 필요할 때만 요구하라. 필요 없는 공증을 시키면 환자 돈·시간이 낭비되고, 필요한데 빠뜨리면 2주가 날아간다.
> - ⚠️ 이 항목은 **접수 전 재확인이 필요한 「수시 변동」 항목**이다(§10 유효기한 표).

### 3단계 — K-ETA 신청용 (케이스 A일 때)
- [ ] 여권 정보 (국적·성명·생년월일·성별·번호·발급일·만료일)
- [ ] 🔴 **여권 인적면 사진 파일** — **필수**, MRZ 2줄이 다 보이게, 정방향·고화질
- [ ] 🔴 **안면사진 파일** — **필수**, **JPG · 100KB 이하 · 700픽셀 이하** (§1-3. 여권사진과 달라도 됨)
- [ ] **한국 내 체류지 주소·연락처** — 숙소 미정이면 **병원 주소·우편번호**를 우리가 보내줄 것 (상세주소 없으면 `NONE`)
- [ ] 이메일 주소 (**승인 통지가 여기로 옴** — 오타 나면 결과를 못 받는다)
- [ ] 입국 예정일 · 출국 예정일 (편명은 선택)
- [ ] 직업 · 자국 연락처 · 과거 한국 방문 경험 · 복수국적 여부
- [ ] **동반인 명단** (국적·성·이름·생년월일·관계) — 🔴 §8-13 함정 확인

> ⚠️ **사진에서 막히면 「K-ETA 앱으로 하세요」가 1번 답이다** (앱이 용량·크기 자동 보정). §1-3 참고.
> ⚠️ **신청·결제는 본인이 아니어도 된다** — 공식 FAQ가 **대리 결제**를, 공식 신청화면이 **대표신청자 방식**을 명시 허용한다. 단 **수수료를 받는 유료 대행은 금지**(§4-③).

## 8. ⚠️ 자주 걸리는 함정 (실제로 사고 나는 지점)

1. **여권 영문 철자 불일치** — K-ETA·비자·항공권 이름이 한 글자라도 다르면 **탑승 거부**. 접수 1단계에서 여권 사진을 받아 **MRZ 기준으로** 대조하라(§6-1단계).
2. 🔴 **K-ETA는 제출하면 이름·여권번호·생년월일·성별·국적을 못 고친다** — 고치려면 **기존 건 심사가 끝난 뒤 재신청 + 재결제**이고 **먼저 낸 수수료는 환불되지 않는다.** 결제 버튼 누르기 전에 코디가 한 번 더 읽어라. (수정 가능한 것: 입국목적·한국 내 주소·연락처뿐)
3. 🔴 **동반인 정보를 적어도 동반인의 K-ETA는 신청되지 않는다** — 공식 화면 경고 문구다. 보호자도 받으려면 **[신청자 추가 +]로 별도 신청**해야 한다. 환자만 받고 보호자가 공항에서 막히는 사고가 여기서 난다.
4. 🔴 **러시아 발급 카드로는 K-ETA 결제가 안 된다** — 국제 결제망 중단 때문. 러시아 케이스는 **우리 카드로 대신 결제**를 기본값으로(§4-③). 이걸 모르고 "환자가 알아서 하겠지" 하면 신청이 아예 못 넘어간다.
5. **감염병 문항 오답** — 15종 감염병 한정 질문이다. **암은 `아니요`**, 결핵은 `네`. 겁먹고 `네`를 고르면 불허 위험, 해당되는데 `아니오`면 처벌·입국제한. §1 참고.
6. **재정능력 서류** — C-3-3 불허 1순위. 🔴 **US$5,000은 전국 공통 숫자가 아니다**(카자흐 공관은 최저한도 없음). **관할 공관 공지를 열고 그 숫자로 안내하라**(§3 표). (※ 우수 유치기관이 되면 e-Visa 한정으로 **면제** — §9)
7. **번역 요건 착각** — 번역본은 **어디서나 필수**, **공증은 공관마다 다르다**(카자흐는 번역 첨부만, 베트남은 공증). 필요 없는 공증을 시키지도, 필요한데 빠뜨리지도 마라. §6 참고.
8. **사증발급인정서 3개월·1회용** — 일정 확정 전에 미리 받아두면 만료. 재신청해야 한다.
9. **인정번호만 전달하고 끝내기** — 환자 신청서에는 **인정번호·발급일·여권번호·여권만료일 4개**가 필요하다(§2).
10. **"K-ETA 받았으니 입국 확정"이라는 오해** — K-ETA는 탑승 허가일 뿐, 최종 판단은 입국심사관. 환자에게 진료예약 확인서·숙소 정보를 소지시키고 **방문 목적을 말할 수 있게** 준비시켜라.
11. **무사증 체류 상한 착각** — 카자흐 **30일**(러시아 60일 아님). 치료 일정이 30일을 넘으면 케이스 A는 무효다.
12. **가짜 K-ETA 사이트 결제** — 상담 시 항상 공식 링크를 직접 보낼 것.
13. **17세 이하·65세 이상은 K-ETA 면제** — 하지만 **무사증 자격 자체는 별개**다. 그리고 🔴 **입국일 기준 18세가 되면 필요**하다. "면제"를 "비자 필요 없음"으로 잘못 안내하지 마라.
14. 🔴 **K-ETA 사진 「용량 초과」 에러** — **100KB · 700픽셀** 제한이 원인. → **「K-ETA 앱으로 다시 하세요」**가 정답(자동 보정). **여권 사진면만 올리면 된다고 잘못 안내하지 마라 — 얼굴 사진이 별도로 필수다.** 반대로 얼굴 사진만 올려도 안 된다 — **여권 인적면 사진도 필수**다.
15. **K-ETA 이메일 오타** — 승인 결과·신청번호가 이메일로만 온다. 접수 때 이메일을 한 번 복창시켜라. 인증번호 유효시간은 **5분**.
16. **K-ETA 불허 시 추가서류 제출 불가** — 공식 FAQ 원문: **신원보증서 등 신청인이 임의로 내는 추가 서류는 받지 않는다.** 불허되면 **재외공관에서 목적에 맞는 사증**을 받아야 한다 → 우리 대응은 곧바로 **케이스 B 전환**이다.
17. **K-ETA로 들어오면 체류자격 변경은 원칙적으로 불허** — **장기치료가 예상되면 처음부터 C-3-3으로 들여와라**(§3·§5-C).
18. 🔴 **환자 이탈(불법체류)은 초청기관 책임으로 돌아온다** — 우수 유치기관 심사에서 **불법체류율이 60점(가장 큰 배점)**이다. 초청은 신중하게, 귀국 확인까지 사후관리 케이던스로 추적하라.

  ⚠️ 다만 **「12건 = 요건의 40%」라고 말하지 마라.** 그건 요건이 30건일 때만 맞는 계산인데
  **위 §9대로 그 숫자가 확정되지 않았다**(30건/50건/200명으로 갈림). 확정 전에는 비율을 쓰지 말 것.
- 📌 **실무 조치**: 케이스 B(사증발급인정서 초청)를 돌릴 때마다 **초청 건수를 별도로 카운트**하라. 나중에 우수기관 신청서에 그대로 들어간다.

## 11. 검증 상태 (정직 고지)

- ✅ **공식 배포자료로 확인**(2026-07-27 2차): K-ETA 신청 7단계·업로드 2종 필수·MRZ·수수료 및 결제수단·대리 결제 허용·심사 소요·제출 후 수정 불가·불허 시 추가서류 불가·감염병 문항 범위·동반인 함정, 사증면제 112개국 및 카자흐 30일·러시아 60일 — **법무부 2026-01-01판 신청안내 / 공식 FAQ 3개 언어 / 국가별 구분표 원문 기준.**
- ✅ **재외공관 공지로 확인**(2026-07-27): 카자흐·블라디보스톡·베트남 3개 공관의 C-3-3 재정능력·번역·동반자·초청기관 요건이 **서로 다르다는 사실**과 각 공관의 실제 문구.
- ✅ **문서 조사로 확인**(초판): 사증발급인정서 절차·유효기간, G-1-10 요건, 출입국민원 대행기관 자격(변호사·행정사 한정), 우수 유치기관 요건·혜택, K-ETA 공식 대행기관 부존재.
- ⚠️ **실제 케이스로 검증 못 함**: 우리가 초청자로 사증발급인정서를 **실제 신청해 본 적이 없다.** 첫 케이스에서 ①비자포털 계정 개설 절차 ②유치업자 단독 초청 vs 병원 명의 초청의 실제 수용 여부 ③실 소요일수 를 확인하고 **이 문서에 반영할 것.**
  - 📌 다만 **②는 방향이 잡혔다** — 주블라디보스톡 총영사관이 **「복지부 유치기관 지정증 + 사업자등록증 + 대표자 명의 초청장」**을 명시 요구하므로 **병원 명의 초청이 안전한 기본값**이다. 유치업자 단독 초청의 수용 여부만 첫 케이스에서 확인하면 된다.
- ⚠️ **화면으로 검증 못 함**: 비자포털의 사증발급인정서 **신청자(초청자) 측 화면**. PO 보관 매뉴얼은 **환자용 전자서식(2016년판)**이라 초청자 화면은 다루지 않는다. 첫 케이스에서 캡처해 §2에 붙일 것.
- ⚠️ **자료에 없어 확정 못 한 것**: K-ETA 일괄신청 **인원 상한(30명?)**, K-ETA 불허 사유 상세, C-3-3 전국 공통 수수료표.
