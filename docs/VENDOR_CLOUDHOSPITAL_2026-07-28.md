**함정 2개**
1. 구독료를 내고도 **매출에서 또 뗀다.** 한방 단가 50만원 환자에 통역이 붙으면 15만원이 나간다.

   Premium 전용은 「**인증** 병원 검색 노출」이다.

   **제안서에 안 적혀 있다.** 사이트 직접 확인은 접속 차단으로 못 했다.
   → 계약 논의가 재개되면 한 문장으로 받아낼 것:
   *"Economy 로 등록만 하면 환자 검색 결과에 우리가 나옵니까? 화면으로 보여주세요."*

## 2. 계약하지 않는 이유

### (1) 유입 구성이 우리와 다르다 — 제안서 7쪽, **자사 데이터**

| 진료과 유입 비율 | 비율 | 환자 단가 | 금액 |
|---|---|---|---|
| 성형·피부·줄기세포 | **40%** | 줄기세포 등 | 3,000만원 |
| 안과 | 19% | 성형외과 | 1,500만원 |
| 건강검진·정형외과 | 14% | 건강검진 | 150만원 |
| 치과 | 12% | 치과 | 200만원 |
| 여성질환 | 10% | 내과 | 100만원 |
| **한의원** | **5% (꼴찌)** | **한방** | **50만원 (꼴찌)** |

- 국가별 유입: 미국·영어권 45% / 일본·중국 20% / 동남아 15% / 몽골·중동 20%
  → **카자흐스탄·러시아·CIS 는 항목에 아예 없다.**
- 플랫폼 전체: 2025년 방문자 80만, 환자 DB 월평균 3,000건.
- 성공사례 D병원(10쪽): 4개월간 진료요청 30건 → **실제 방문 7건**(전환 23%),
  환자 단가 3,000만원(줄기세포급) → 해외매출 2억.
- 기본 포함 국가가 **미국**이고, 카자흐스탄을 넣으려면 국가 추가 300만원.

**공정하게 짚을 것** — 15쪽에 「Yandex 및 지역별 검색광고 : 러시아, 중앙아시아」가 채널로 적혀 있다.
중앙아시아 역량이 **없다고 단정할 수는 없다.** 다만 그것은 유료광고 항목이고 Starter Tech 에 광고 집행은 포함되지 않는다.

### (2) 일정이 사업과 안 맞는다

| | |
|---|---|
| 계약 → 서비스 오픈 | 약 4주 (제안서 22쪽) |
| 오늘 계약해도 오픈 | 8월 말 → **중간평가 8/27 기여 없음** |
| 검색 노출 성숙 | 3~6개월 → **사업 종료 후에 익는다** |
| 최소 계약기간 | 2년 / 3년 → **사업 종료는 11/20** |

### (3) 사업비로 결제하기 어렵다

사업기간이 11/20 에 끝나는데 2~3년치를 선납하면 **남는 15~27개월치는 정산에서 인정되지 않을 수 있다.**
비목변경 사전승인(마감 10/21)과 500만원 초과 이체 사전공문 승인도 겹친다.
→ 사실상 자부담을 각오해야 하는 돈이다. **정산 인정 여부는 진흥원 확인 전이다.**

## 4. 남겨둔 카드

계약을 완전히 닫는 것은 아니고, **선불 없이** 시험할 여지는 있다.

> "선납 2년 대신 **유치 성사 건당 수수료**로, 카자흐스탄 타겟 **3개월 파일럿**을 하고 싶습니다."

- 수락하면 → 선불 0원으로 이들 채널을 실측할 수 있다
- 거절하면 → 카자흐스탄 유입 실적이 없다는 뜻이므로 검토를 종료하면 된다

⚠️ **재개 조건** — 아래 둘 중 하나라도 나오면 다시 본다. 안 나오면 재검토 불필요.
1. 최근 12개월 **CIS(카자흐·러시아·우즈벡) 실제 내원 건수** (문의 말고 내원)
2. **러시아어·카자흐어 실제 검색순위 화면** + 얀덱스 운영 여부

## 5. 검증 한계 (다음 세션이 그대로 믿지 말 것)

1. **CloudHospital 의 카자흐스탄·CIS 실제 유치 실적은 제공받지 못했다** — 제안서에 국가별 실적이 없다.
2. **「인증 병원 검색 노출」의 정확한 의미는 확인 못 했다** — icloudhospital.com 이 브라우저에서 차단돼 실물을 못 봤다.
3. **사업비 정산 인정 여부는 진흥원 확인 전**이다. 위 (3)은 규정 대조 결과이지 진흥원 답변이 아니다.
4. 「매출 500%↑」(보도자료)와 「매출 +30%」(자사 사이트)처럼 **회사가 내놓는 숫자끼리 서로 안 맞는 곳**이 있다.
