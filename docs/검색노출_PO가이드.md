# 검색 노출 — 어떤 단어로 우리가 뜨나 (PO용 쉬운 가이드)

> "구글·얀덱스에 뭐라고 쳐야 우리(healwith.co.kr)가 나오나?"에 대한 답.
> 기술 용어 최소화. 마지막에 "실제로 누가 우리를 찾는지" 보는 법까지.

---

## 0. 한 줄 요약

- **브랜드 이름(healwith·힐위드·healwith.co.kr)** 으로 치면 거의 확실히 뜬다.
- **일반 단어**(예: "한국 암 치료")는 경쟁이 심해서 새 사이트인 우리는 **아직 첫 페이지에 못 들 수 있다.** 시간·콘텐츠·외부링크가 쌓여야 올라간다.
- 기술 세팅(검색엔진이 우리를 읽는 통로)은 **이미 다 돼 있음** — 구글·얀덱스·네이버 소유권 인증 완료, sitemap·robots·6개 언어 hreflang·구조화데이터 전부 OK. 즉 "못 읽혀서 안 뜨는" 문제는 아니다.

---

## 1. ✅ 거의 확실히 우리가 뜨는 검색어 (브랜드)

우리만 쓰는 고유 이름이라 경쟁이 없음 → 색인만 됐으면 1등.

- `healwith.co.kr` (도메인 그대로 — 가장 확실)
- `healwith 암`, `healwith korea`, `healwith cancer`
- `힐위드` (한글 표기)

> 안 뜨면? = 아직 **색인(인덱싱) 전**일 수 있음. 4번 "색인 빨리 시키는 법" 참고.

---

## 2. 🎯 "이걸로 떠라" 하고 노려둔 검색어 (경쟁 있음 — 보장 아님)

코드(`app/page.jsx`, `app/layout.jsx`)의 keywords + 페이지 제목/본문이 노리는 말들.
**핵심 시장 = 러시아·카자흐(얀덱스)** 이므로 러시아어/카자흐어가 제일 의미 있음.

| 언어 | 노린 검색어 |
|---|---|
| 🇷🇺 러시아어 | лечение рака в Корее (한국 암치료) · второе мнение онколога Корея (한국 종양내과 2차소견) · сколько стоит лечение рака в Корее (비용) · лучшие онкологические клиники Кореи (베스트 클리닉) |
| 🇰🇿 카자흐어 | Кореядағы онкологиялық емдеу · Кореядағы онколог дәрігер · Корея медициналық туризм |
| 🇰🇷 한국어 | 해외 암환자 원격상담 · 한국 암 전문의 컨시어지 · 외국인 한국 암 치료 비용 |
| 🇬🇧 영어 | Korea cancer treatment concierge · second opinion Korea oncologist · cost of cancer treatment in Korea |
| 🇨🇳/🇯🇵 | 韩国癌症治疗 / 韓国がん治療 |

> ⚠️ keywords 태그는 **구글 순위엔 영향 0**(구글이 무시함). 단 **얀덱스는 아직 약간 본다** → 우리 시장(러·카자흐)엔 의미 있어서 유지·보강함.
> 구글에서 진짜 순위를 올리는 건 **페이지 제목·본문 내용·외부에서 우리를 링크한 수**다.

---

## 3. ⚠️ 솔직한 한계 (왜 일반 단어로 아직 안 뜨나)

- 우리는 **새 도메인**이라 검색엔진이 주는 "신뢰 점수"가 아직 낮음 → 시간이 약.
- "한국 암 치료" 같은 큰 단어는 대형 병원·블로그가 수백 개 경쟁 → 신생 사이트가 1페이지 가긴 어려움.
- **현실적 전략**: 큰 단어 말고 **구체적인 롱테일**("카자흐스탄 암환자 한국 위암 치료 비용" 류)로 좁게 노리는 게 빠름. 그래서 `/ru/for-russian-patients`·`/kk/for-kazakh-patients` 전용 랜딩을 따로 둠.

---

## 4. 색인(인덱싱) 빨리 시키는 법 — 클릭 몇 번

검색엔진이 우리 페이지를 "등록"해야 검색에 나옴. 소유권 인증은 끝났으니 sitemap만 제출/재요청하면 됨.

**구글:** [Google Search Console](https://search.google.com/search-console) 로그인 → 속성 `healwith.co.kr` →
- 좌측 `Sitemaps` → `https://healwith.co.kr/sitemap.xml` 제출(이미 있으면 OK)
- 상단 검색창에 특정 URL 붙여넣고 `색인 생성 요청(Request Indexing)`

**얀덱스:** [Yandex Webmaster](https://webmaster.yandex.com) → `Индексирование → Файлы Sitemap` → `https://healwith.co.kr/sitemap.xml` 등록.
(상세는 `docs/YANDEX_SEO_SETUP.md` — 단 그 문서의 도메인 예시는 옛 `khidi.healo.kr`이니 실도메인 `healwith.co.kr`로 읽을 것.)

---

## 5. 📊 "실제로 누가 우리를 찾는지" 보는 법 (가장 중요)

내가(어시스턴트) 구글·얀덱스 실시간 순위를 대신 볼 수는 없음. 진짜 데이터는 PO가 무료 도구로 직접 봄.

**구글 서치 콘솔(Google Search Console) = 우리 사이트의 "검색 성적표"**
- [search.google.com/search-console](https://search.google.com/search-console) 로그인 (구글 계정, 소유권 인증 완료 상태)
- 좌측 `실적(Performance)` 클릭 → 표에서:
  - **검색어(Queries)** 탭 = 사람들이 "어떤 단어"로 우리를 보고/눌렀는지 실제 목록
  - 노출수(Impressions) = 검색결과에 우리가 뜬 횟수 / 클릭수 = 실제 들어온 횟수
- 여기 단어가 곧 **"지금 진짜 우리가 뜨는 검색어"** 의 정답.

**얀덱스 웹마스터**: `Поисковые запросы(검색어)` 메뉴에서 동일하게 러시아·카자흐 검색어 확인.

> 💡 시크릿창에서 직접 쳐보는 것도 OK(로그인된 창은 결과가 개인화돼 왜곡됨). 단 "내 눈에 보인다 = 모두에게 1등"은 아님 → 정확한 건 서치 콘솔.
