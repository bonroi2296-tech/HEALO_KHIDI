**2. 왜 그렇게 했는지**

- **더미 데이터를 되묻지 않고 지운 이유**: 처음엔 "6개 언어 번역·실가격이 있으니 진짜 콘텐츠 아니냐"고 PO 에게 **두 번 되물었다가 지적받았다**("몇 번 얘기하니"). 데이터가 **잘 만들어져 보이는 것**은 더미가 아니라는 근거가 못 된다 — 씨드 스크립트가 그럴듯하게 채운 것뿐. **피벗 전 도메인인지(산후조리·난임·소아성장 = 여성/웰니스)로 판단**해야지 완성도로 판단하면 매번 틀린다. 안전장치는 **질문이 아니라 백업**.
