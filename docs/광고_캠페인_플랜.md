# 광고(유료) 캠페인 플랜 — Google Ads · Yandex Direct

> 출처: PO 제공 `HEALwith_keywords260626.xlsx`(러·카자흐 종양 광고 키워드 시트) 기반.
> ⚠️ **이 문서는 "플랜"만. 실제 집행·결제는 PO가 예산 정한 뒤 시작.** (돈 나가는 일 = PO 결정)
> 자연검색(SEO) 무료 정렬은 이미 코드에 반영됨(암종별·러시아어 랜딩 메타). 이건 **유료 광고** 트랙.

## 0. 큰 그림 — 돈은 "검색광고"에 몰아라

시트 §전략 1: **예산은 검색광고(Google/Yandex)에 집중.** 이미 "한국에서 암 치료"를 검색하는 사람 = 구매의도 최상. 디스플레이·영상보다 검색이 우선.

| 채널 | 시장 | 용도 | 비고 |
|---|---|---|---|
| **Google Ads** | 카자흐스탄·CIS(구글 우세) | 검색광고 | "상담·세컨드오피니언" 문구가 "치료"보다 승인 잘 됨(시트 §6) |
| **Yandex Direct** | 러시아·CIS(얀덱스 우세) | 검색광고 | 러시아어 키워드 핵심 |
| Instagram/TikTok | 양쪽 | 인지·리타겟 | 질병 타깃 금지 → 지역+관심사+Click-to-WhatsApp(시트 §전략 4) |

## 1. 캠페인 구조 — 암종별로 쪼개라 (전환율 ↑)

시트 §전략 2: 일반어("лечение рака")보다 **암종별**이 전환율 높음. 광고그룹을 암종별로 분리하고, 각 그룹을 우리 **해당 암종 랜딩**으로 보낸다(메시지 일치 = 품질점수↑ = 클릭단가↓).

| 광고그룹 | 핵심 키워드(RU) | 연결 랜딩(이미 있음) |
|---|---|---|
| 유방·여성암 | лечение рака груди в Корее | `/treatments/female` |
| 위·대장암 | лечение рака желудка в Корее · колоректального | `/treatments/digest` |
| 간·췌장암 | лечение рака печени в Корее | `/treatments/liver` |

## 2. 🛑 금지 — 광고 거부 + 법적 리스크 (시트 §ЗАПРЕЩЕНО)

- **"완치 / 보장 / 100% / вылечим / гарантия излечения"** 류 결과보장 문구 절대 금지 → Google/Yandex 광고 거부 + 의료법 리스크.
  - ✅ 이미 **사이트 자동검사(`check:content`)에 영구 룰로 박음** — 우리 페이지엔 못 올라감.
  - ⚠️ **광고 소재(헤드라인·설명문)에도 동일 적용** — 광고 카피 쓸 때 이 단어 쓰지 말 것.
- **Meta(IG/FB) 질병 기반 타깃팅 금지** → "암환자" 타깃 ✗. 대신 **지역(알마티·아스타나·카자흐스탄) + 관심사 + Click-to-WhatsApp**.
- 승인 팁(§6): 헤드라인은 **"치료(лечение)"보다 "상담·세컨드오피니언(консультация·второе мнение)"** 이 심사 통과 쉬움.

## 3. 시작 전 PO가 정할 것 (= 돈 결정)

1. **월 예산** (예: 테스트로 $300~500/월부터 → 전환 보고 증액)
2. **광고 계정**: Google Ads / Yandex Direct 계정 + 결제수단(카드)
3. **전환 추적**: 문의(`/inquiry`) 도달 = 전환 이벤트로 연결(이미 유치 전환 대시보드 `/admin/khidi/conversion` 있음 → 광고 클릭→문의→상담 연결되면 KHIDI 지표로 자동 집계)
4. **랜딩 정합**: 위 표대로 암종별 그룹 → 암종 랜딩 연결(메시지 일치)

→ 위 4개 정해주면 캠페인 세팅(키워드·소재·구조)은 시트대로 바로 짜줄 수 있음. **결제·게시 버튼은 PO가.**
