# HEALO 리스크 관리 대장

**갱신 주기:** 매월 1회 또는 신규 리스크 발생 시 즉시
**관리 단위:** 리스크 ID (R-NN), 발생 가능성 × 영향도 = 등급 (상/중/하)

---

## 1. 등급 산정 기준

| 발생 가능성 \ 영향도 | 낮음(1) | 보통(2) | 높음(3) |
|---|---|---|---|
| 낮음(1) | 하 | 하 | 중 |
| 보통(2) | 하 | 중 | 상 |
| 높음(3) | 중 | 상 | 상 |

### R-02. 의료법 해석 — "사전상담"의 원격진료 해당 여부

- **발생 가능성:** 낮음(1) / **영향도:** 높음(3) / **등급:** 중
- **상세:** 한국 의료법상 원격의료는 의료인-의료인 간만 허용. 환자-의사 직접 상담은 회색지대
- **현재 대응:** "사전상담" = 진료 아닌 의료 정보 제공·진단 의뢰 영역으로 설계
- **추가 대응:**
  - 외부 의료법 전문 변호사 자문 의견서 확보 (예정)
  - 면책 조항 약관 명시 (`docs/government-project/02_기능명세서.docx` 참조)
  - 진단·처방 행위 명백한 분리
- **현재 상태:** 약관 1차 적용 완료, 외부 자문 일정 협의 중

### R-03. 개인의료정보 유출
