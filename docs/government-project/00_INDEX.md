### D. 자동화 스크립트
`make_req.py`, `make_func.py`, `make_eval.py` — Phase A .docx 생성 스크립트 (재실행 가능)
`make_backoffice_req.py` — 산출물 10(백오피스 재설계 요구사항 대비표) .docx 생성 스크립트 (재실행 가능, `python3 make_backoffice_req.py`)
`make_ict_req.py` — 산출물 11(과제 요구사항 6대 ICT 분석·구현 대비표) .docx 생성 스크립트 (재실행 가능, `python3 make_ict_req.py`)

> ⚠️ **산출물 11 갱신 규칙**: 6대 ICT 관련 기능을 추가·고도화하면 `make_ict_req.py`의 해당 서비스 「구현 결과」·「착수 후 고도화」와 제23조 월별 이력, 제28조 실데이터 수치를 갱신하고 재생성한다. 실데이터 수치는 **추정 금지 — 운영DB 정확 COUNT로 재조회**.
