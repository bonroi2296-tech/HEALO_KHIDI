## 아직 갈리는 것 4개 — 하나씩 골라 주세요

### 1. 「면력한방병원」을 뭐라고 부를까요? ⭐ 제일 급합니다

교정본에서도 **아직 세 가지**로 갈립니다:

| 표기 | 어디에 |
|---|---|
| `Иммуногоспиталь` | 케어 여정·병원 소개 (2곳) |
| `Immune Hospital` | 검색 노출 문구·서비스 소개 (2곳) |
| `«Иммунная клиника»` | 카자흐어 서비스 소개 (1곳) |

여기에 코드 쪽에는 `Клиника Мёнрёк`·`клиника Myeonryeok` 도 남아 있었습니다.
**환자는 이걸 서로 다른 병원으로 읽습니다.** 하나만 골라 주세요 (러시아어·카자흐어를 다르게 쓰셔도 됩니다).

### 2. 「견적서」 — смета 와 расчёт 가 딱 반반입니다

| 단어 | 몇 군데 |
|---|---|
| `смета` 계열 | 20곳 |
| `расчёт` 계열 | 20곳 |

법으로 정해진 고지 문서라, **문서 자체를 가리킬 때** 쓸 단어 하나만 정해 주세요.
(계산하는 행위나 금액을 말할 때는 다른 단어를 써도 괜찮습니다 — 그 구분도 알려주시면 그대로 반영합니다.)

### 3. 「문의」 — 환자가 처음 보내는 신청

교정본 안에서도 `заявка` · `обращение` · `запрос` · `анкета` 가 섞여 있습니다.
문의 폼 → 접수 → 답변까지 **한 흐름에서 계속 쓸 단어** 하나를 골라 주세요.

### 4. 카자흐어에서 「코디네이터」를 뭐라고 부를까요?

지금 **화면마다 다릅니다**:

| 표기 | 어디에 |
|---|---|
| `Координатор` | 공개 사이트 (러시아어 그대로) |
| `Оператор` | 코디님이 교정하신 문의 화면 |
| `Үйлестіруші` | 코디네이터 포털 |

환자가 보는 화면과 직원이 보는 화면에서 다르게 불려도 괜찮은지, 하나로 통일할지 알려주세요.

## 하나 더 — 줄바꿈 때문에 여러 번 저장하고 계시죠?

교정 이력을 보니 홈 소개 문구에서 **줄바꿈 위치를 3번 왔다 갔다** 하신 흔적이 있었습니다
(`home.stats.subtitle`, `home.hero.subtitle`). 저장하고 화면 보고 다시 고치기를 반복하신 것으로 보입니다.

→ **편집 화면에 「저장 전 미리보기」가 없어서** 생긴 일이라면 그건 번역 문제가 아니라 도구 문제입니다.
불편하셨다면 알려주세요 — 미리보기를 붙이는 쪽으로 만들겠습니다.

3. 그다음부터 **새 화면을 만들 때 AI 가 그 단어를 쓰도록** 번역 프롬프트에 자동으로 들어갑니다.
4. 누가 다른 단어를 쓰면 실서비스에 나가기 전에 자동 검사가 막습니다.
