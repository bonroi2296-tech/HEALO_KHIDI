# 기획서: 원격협진 "소견서 같이 보기" (2·3단계)

> PO 질문(2026-06-12) "환자/의사가 소견서를 올려서 같이 보고 싶다"에서 출발.
> 1단계(올리면 상대에게 바로 표시 + 알림)는 2026-06-12 구현 완료. 이 문서는 다음 두 단계의 실행 설계.

## 2단계 — 방 안에서 보기 (예상 1일)

**문제**: 지금은 파일을 누르면 새 탭으로 빠짐 → 폰에서는 영상통화 화면이 사라져 상담 흐름이 끊김.

**설계**
- 공유 자료 항목 탭 → 새 탭 대신 **상담방 안 문서 패널** 오픈 (자막 패널과 같은 오버레이 패턴 재사용)
- 렌더링: 이미지(JPG/PNG/WebP)는 `<img>`, PDF는 `<iframe src=서명URL#page=N>` (모바일 사파리 iframe PDF 제약 시 1차 폴백: 페이지를 이미지로 — 차후)
- 영상은 PIP 미니뷰로 유지 (consultation 헤더 아래 우측 상단 고정, 기존 비디오타일 재사용)
- 파일 URL 은 기존 `/api/.../documents` 서명 URL 그대로 (5분 만료 → 패널 열 때마다 재요청)
- 터치 줌/스와이프 페이지 이동 (PDF 는 iframe 내장 뷰어에 위임)

**작업 분해**
1. `DocViewerPanel` 컴포넌트 (열기/닫기 상태는 page.jsx) — 0.5일
2. PIP 미니뷰 + 모바일 레이아웃 (375px 캡처 검증) — 0.25일
3. 문구 6개 언어 (열기/닫기/페이지) — 0.25일

## 3단계 — 페이지 동기화 "따라가기" (예상 1~2일)

**설계**
- 전송로: 자막에 쓰는 LiveKit 데이터채널 재사용 — 새 메시지 타입 `doc_sync { docId, page, scrollRatio }`
- 권한: 누구든 "발표 시작" 가능 (의사 우선 아님 — 환자가 자기 검사지를 짚는 케이스), 마지막 발표자 우선
- 수신 측 UI: "○○님이 자료를 보고 있어요 — [따라가기]" 배너 → 수락 시 페이지 자동 추종, 본인 스크롤 시 추종 일시 해제 + [다시 따라가기]
- 전송 빈도: 페이지 변경 시 즉시 + 스크롤은 300ms 디바운스
- 실패 허용: 데이터채널 유실돼도 자료 자체는 각자 패널에 있으므로 기능 저하만

**작업 분해**
1. doc_sync 발신/수신 (useLiveKitDataChannel 확장) — 0.5일
2. 따라가기 배너/해제 UX + 6개 언어 — 0.5일
3. 실기기(폰 2대) 검증 — 0.5일
