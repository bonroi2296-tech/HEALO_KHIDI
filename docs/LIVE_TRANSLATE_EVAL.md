# Gemini 3.5 Live Translate — 평가 메모 & 통역 파이프라인 진단

> 작성: 2026-06-21 (주간 트렌드 스캔에서 파생). 배포·코드변경 없음 — 의사결정용 메모.

## 1. 트렌드 보석 — Gemini 3.5 Live Translate

- **무엇**: 구글이 2026-06-09 공개한 **실시간 음성→음성 통역** 모델(`gemini-3.5-live-translate-preview`). 70+ 언어, 말하는 도중 몇 초 뒤따라가며 연속 통역(턴제 아님), 억양·속도·피치 보존. **Live API(WebSocket)** 로 제공, **LiveKit에 기본 연동 지원**.
- **출처**:
  - 구글 블로그: https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-live-3-5-translate/
  - Live API 통역 문서: https://ai.google.dev/gemini-api/docs/live-api/live-translate
- **상태**: public **preview**. 단가 **미공개**(우리 비용통제 원칙상 리스크).

## 2. 우리 현재 통역 구조 (실측 — 코드 기준)

화상방(`app/consultation/[id]/page.jsx`)의 자막·통역은 **2경로**:

| 경로 | 트리거 | STT 방식 | 카자흐어 | 특징 |
|---|---|---|---|---|
| ① 브라우저 STT | 기본(크롬에서 동작) | Web Speech API (`useSpeechRecognition.js`) → 텍스트 → `/translate-realtime`(Gemini 번역) | **❌ 미지원 → ru-RU 폴백** | 무료·저지연. 크롬 전용. |
| ② 서버 STT | ①이 실패/미지원/조용한 사망 시 (`forceServerStt`) | 오디오 조각 → Gemini 멀티모달이 **전사+번역 1회** (`/[id]/stt`) | **✅ 지원** | 모든 브라우저 OK. 조각(clip) 단위라 약간 끊김. |

**핵심**: 카자흐어 통역은 경로 ②(서버 STT, Gemini 멀티모달)로 **이미 가능**하다. 즉 "카자흐어 음성통역"은 Live Translate 없이도 이미 된다 — 단 조각(clip) 단위라 연속 스트리밍은 아님.

## 3. Live Translate가 우리한테 주는 실제 증분

이미 Gemini 멀티모달로 전사+번역을 하므로, Live Translate의 추가 가치는 **"카자흐어 지원"이 아니라**:

1. **연속 스트리밍 통역**(조각 왕복 → 끊김 없는 몇 초 지연) — UX 향상.
2. 억양/피치 보존된 **음성 출력**(자막뿐 아니라 TTS 통역) 가능성.

→ 즉 **"있으면 좋은 품질 업그레이드"이지, 없는 기능을 메우는 게 아님.**

## 4. 🔴 이번에 발견한 진짜 구멍 — 크롬 카자흐어 사용자 라우팅

- **증상**: 크롬을 쓰는 **카자흐어 사용자**는 경로 ②(카자흐어 지원)로 **안 넘어가고** 경로 ①의 **러시아어 폴백(ru-RU)** 에 머문다.
- **원인**: `useServerStt` 분기(`page.jsx:1139`)가 **"브라우저 STT가 실패했거나 미지원일 때만"** 서버 STT로 전환한다. 그런데 크롬은 카자흐어를 `ru-RU`로 폴백해 **"지원"으로 판정**(`useSpeechRecognition.js`의 `LANG_MAP.kz = 'ru-RU'`, `stt.isSupported = true`) → 서버 STT 전환 조건에 안 걸림. 결과적으로 카자흐 환자의 발화를 **러시아어 인식기로 처리**(부정확) 후 번역.
- **영향**: 카자흐스탄은 **우리 1순위 타깃 시장**이라 통역 정확도 직결. KHIDI 평가(외국인환자 유치)와도 연결.
- **수정(완료, 2026-06-21)**: 화자 언어가 **브라우저가 진짜로 지원하지 않는 언어(kz)** 면 처음부터 경로 ②(서버 STT)로 강제. `useSpeechRecognition.js`에 `isBrowserSttNative(lang)` 헬퍼 추가(폴백 집합 `{kz}`), `page.jsx`가 `myLang`이 폴백 전용이면 `forceServerStt` ON + 브라우저 STT 시작 안 함. 순수 분기 로직 단위테스트 `sttRouting.test.ts`(6개)로 잠금.
- **검증**: vitest 285 통과(+6) / tsc 0. **라이브 실동작(화상방 카자흐어 발화)은 PO 동석 검증 필요**(자동 불가).

## 5. 측정에 대한 솔직한 메모

- 당초 "카자흐어 통역 품질 측정 스크립트"를 만들려 했으나, 위 진단대로 **카자흐 텍스트 번역은 Gemini가 이미 잘 처리**(측정해도 새 정보 적음). 측정이 필요한 진짜 절반 = **음성인식 정확도**인데 이는 **실제 오디오 + 라이브**가 있어야 해 자동 측정 불가(화상방 2명+ — 우리가 늘 막히는 지점).
- 따라서 무의미한 AI 퀘타 소모를 피하려 **자동 측정 스크립트는 보류**. 실측이 필요하면 PO 동석 라이브에서 ②서버 STT 카자흐 통역을 1회 녹화·검수하는 게 정확하다.

## 6. 2026-08-06 실측 — 「지어내기」 A/B 대조 (PO 지시로 실행)

**왜 다시 봤나**: 위 3절에서 *"이미 작동하는 서버 STT로 충분"* 이라 판정했는데, 2026-08-03 실서비스 실측에서 **그 서버 받아쓰기가 없는 말을 15~17% 지어내는 것**이 확인됐다. 판정 근거가 흔들렸으므로 두 길을 같은 소리에 대고 직접 비교했다.

**방법**: `e2e/fixtures/audio/ko-patient-speech.wav`(정답 대본 확정)에서 조각 13개를 만들었다 — 온전한 문장 2 / 잘린 파편 3 / **완전 무음 2** / **잡음만 2** / 아주 작은 소리 2 / 잡음 섞인 1 / 뒤에 무음 붙은 1.
- **A(지금 길)** = `app/api/khidi/consultation/[id]/stt/route.ts` 와 같은 모델(`gemini-flash-latest`)·같은 프롬프트(DOMAIN_PRIMING + NO_INVENTION)·`temperature 0`, 조각당 3회 = 39회
- **B(새 길)** = `gemini-3.5-live-translate-preview`, Live API 스트림, ko→ru, `output_audio_transcription`, 조각당 2회 = 26회

| 항목 | A (지금 길) | B (새 길) |
|---|---|---|
| **무음·잡음에서 없는 말 창작** | **10/12 = 83%** | **0/8 = 0%** |
| 내용 오염(숫자·시술명 바뀜) | 6/27 = 22% | 4/18 = 22% (**비김**) |
| 들은 말을 빠뜨림 | 0회 | **5회** |
| 못 알아들었을 때 행동 | 그럴듯한 말을 만든다 | 아무 말도 안 한다 |

**A가 완전 무음/잡음에서 만들어낸 문장**(전부 아무도 말한 적 없음):
`환자분의 경부 CT 결과에서는` · `거기는 이제 항암 화학요법을 해야 된다라고 이야기를 했다 그러더라고요` · `прогрессирование заболевания` · `지금 3시 한 7분 정도 되는데 한 3시 반까지 진행하겠습니다` · `안녕하세요. 한국보건산업진흥원` · `I'll do my best for you.`

**해석(단정 아님)**: A는 프롬프트에 「지어내지 마라」가 이미 두 곳 다 들어 있는데도 안 지킨다. 8/03 에 프라이밍 재료를 걷어내는 방식으로 한 번 손봤지만 비율은 안 줄었다(17%→15%, 표본 작음). **프롬프트 튜닝으로 닫히는 구멍이 아닐 가능성이 높다** — B는 프롬프트가 아예 없는 전용 통역 모델이라 지어낼 재료 자체가 없다. 다만 「모델 내부」는 확인 불가이므로 인과로 단정하지 않는다.

**B의 대가**: `위암`(рак желудка)이 3회 통째로 빠졌고, `두 달`이 `две недели`(두 주)로 2회 바뀌었다. **틀린 정보를 «넣지»는 않지만 정보를 «잃는다».** 의료 기록에서 어느 쪽이 덜 위험한지는 PO 판단 영역.

**못 잰 것**: ①실제 사람 2명 통화 ②카자흐어 발화(카자흐어 하는 사람 필요) ③실사용 지연시간 — B 숫자에 내가 넣은 대기시간이 섞여 있어 지연 비교에 쓰면 안 된다.

**재현**: 조각 생성기·실행기는 세션 작업폴더(`make_clips.py` / `run_ab.py`). 문장 경계 자동감지는 문장 «안»의 짧은 쉼에서 갈라져 실패한다 — `0.95~4.85s`(문장1) / `6.25~9.45s`(문장2) 로 고정해야 한다.
