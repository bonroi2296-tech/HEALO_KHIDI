# healwith 투자자 프레젠테이션 스크립트

> **대상:** 개발 지식 없이 투자자에게 서비스를 소개·데모하는 대표님  
> **용도:** 발표 시 읽거나 참고할 수 있는 대본 및 체크리스트

---

## 1. 오프닝 (약 1분)

**[말할 내용]**

"안녕하세요. healwith 대표 ○○○입니다.

healwith는 **한국 의료를 찾는 해외 고객**과 **한국 병원**을 연결하는 **의료 컨시어지 플랫폼**입니다.

고객은 우리 사이트에서 병원·시술을 검색하고, AI 챗봇으로 상담한 뒤, **한 번의 문의**로 여러 병원에 견적 요청을 보낼 수 있습니다. 병원은 healwith를 통해 리드를 받고, 응답·전환까지 한 곳에서 관리합니다.

이제 화면을 보시면서 서비스가 어떻게 돌아가는지 짧게 보여드리겠습니다."

## 2. 고객(환자) 여정 데모 (약 2~3분)

**[보여줄 화면]**  
브라우저에서 **healwith 메인 페이지**(홈)를 연 상태로 시작.

**[말할 내용]**

- "먼저 **해외에서 한국 의료를 찾는 고객**이 어떻게 쓰는지 보여드립니다."
- "메인에는 **추천 시술**과 **병원 목록**이 나옵니다. 다국어(영어, 한국어, 중국어, 일본어 등)를 지원합니다."
- "고객이 관심 있는 시술이나 병원을 고르면 **상세 페이지**로 들어가 가격·소개·이미지 등을 볼 수 있습니다."

**[다음]**  
**문의/상담 페이지**로 이동.

- "여기서 **AI 챗봇**과 대화하면서 '이런 시술 있어요?', '이 병원 어때요?' 같은 질문을 할 수 있습니다. 답은 우리가 등록한 병원·시술 데이터를 기반으로 합니다."
- "상담 후 **원하는 병원을 골라서 한 번에 문의**를 넣습니다. 이름, 이메일, 희망 시술, 희망 일정 등을 입력하고 제출하면, 해당 병원들에 문의가 전달됩니다."

**[정리 한 마디]**  
- "즉, 고객은 **한 곳에서 검색·상담·문의**까지 끝내고, 병원은 **품질 좋은 리드**를 받는 구조입니다."

## 3. 병원(파트너) 측 데모 (약 1~2분)

**[보여줄 화면]**  
(데모용 파트너 계정이 있다면) **파트너 대시보드** 로그인 후 화면.

**[말할 내용]**

- "이쪽은 **제휴 병원**이 쓰는 화면입니다. 로그인하면 **대시보드**에서 오늘/이번 주 문의 수, 최근 리드 목록을 볼 수 있습니다."
- "**리드 관리** 메뉴에서는 '어떤 고객이 어떤 시술로 문의했는지', '전달됨·열람·응답·전환' 같은 **상태**를 한눈에 보고, 병원이 직접 응답·후속 관리할 수 있습니다."
- "**시술 관리**에서는 이 병원이 제공하는 시술(이름, 가격대, 설명 등)을 등록·수정합니다. 우리가 병원 웹사이트에서 **대표 시술을 자동으로 추출해 넣어주는 기능**도 있어, 데이터 입력 부담을 줄였습니다."

**[정리 한 마디]**  
- "병원 입장에서는 **리드 수신 → 상태 관리 → 전환**까지 한 플랫폼에서 처리할 수 있습니다."

## 4. 운영(관리자) 측 요약 (약 1분)

**[말할 내용]**  
(실제로 관리자 화면을 열지 않아도 됩니다. 말로만 요약해도 됩니다.)

- "우리 **운영팀**이 쓰는 관리자 화면에서는  
  - **문의·리드**를 한꺼번에 보고 배정·상태 관리하고,  
  - **병원·시술** 데이터를 등록·수정·보강하고,  
  - **대량 데이터**를 엑셀 등으로 가져오거나, 병원 웹사이트를 수집해 시술 정보를 자동으로 채우고,  
  - **AI가 답변할 때 참고하는 지식(RAG)·응대 패턴(플레이북)**을 관리하며,  
  - **감사 로그·알림 설정**으로 보안과 운영을 점검합니다.  
  즉, **고객·병원·운영**이 모두 하나의 플랫폼 위에서 돌아가도록 되어 있습니다."

## 5. 가치 제안·차별점 (약 1분)

**[말할 내용]**

- "healwith의 차별점을 세 가지로 말씀드리면,
  1. **고객 편의**: 한 번의 문의로 여러 병원 견적 요청, AI 상담으로 24시간 1차 응대.  
  2. **병원 편의**: 품질 좋은 해외 리드 수신, 리드 상태·전환 관리, 시술 정보 자동 수집으로 입력 비용 절감.  
  3. **운영 효율**: 문의·리드·병원·시술·AI 지식·감사까지 하나의 시스템에서 관리해, 인력과 비용을 줄이면서 확장할 수 있습니다."

## 8. 자주 나올 수 있는 질문 (FAQ)

| 질문 | 답변 예시 |
|------|-----------|
| "수익 모델은?" | "병원에게 리드/전환당 과금 또는 구독, 향후 프리미엄 노출·광고 등으로 확장 검토 중입니다." |
| "지금 몇 개 병원이 쓴다?" | (실제 숫자로 답변) "현재 ○○개 제휴/등록 병원이 있으며, 단계적으로 확대하고 있습니다." |
| "AI가 잘못 답하면?" | "AI는 등록된 병원·시술 데이터와 운영이 관리하는 지식(RAG)만 참고해 답합니다. 민감한 의료 판단은 하지 않고, 최종 상담·결정은 병원과 고객이 직접 하도록 설계했습니다." |
| "해외 결제·예약까지 되나?" | "현재는 문의·견적 요청·리드 전달·상태 관리까지가 핵심입니다. 결제·예약 연동은 로드맵에 있습니다." |
