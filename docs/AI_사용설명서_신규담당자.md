## 1. 이 AI가 뭐 하는 놈인가

**클로드 코드(Claude Code)** = 우리 서비스(healwith.co.kr)의 **코드를 직접 읽고 고치고 올리는** AI입니다. 챗GPT처럼 "이렇게 하세요"라고 알려주는 게 아니라, **자기 손으로 파일을 고치고 저장하고 배포까지** 합니다.

### 할 수 있는 것 (직접 시키면 됩니다)
- 코드 읽기·고치기·새 기능 만들기
- 우리 데이터베이스(DB) 조회 — "8월에 문의 몇 건 들어왔어?" 같은 질문에 **실제 숫자**로 답함
- 화면 띄워서 사진 찍기 (로그인해야 보이는 관리자 화면도 됨)
- 문서·엑셀·PPT·한글문서 만들기
- 실서비스가 살아있는지 점검, 오류 로그 확인
- 깃허브(GitHub — 코드 보관소)에 작업 올리고 합치기

### 못 하는 것 / 사람 손이 필요한 것
- **대표님 PC나 당신 PC의 브라우저를 대신 클릭**하지 못합니다 (웹에서 돌리는 세션 기준)
- 앱스토어 업로드·은행·정부 사이트 로그인처럼 **본인 인증이 필요한 것**
- **사업 판단** — 얼마 쓸지, 어느 병원과 계약할지, 무엇을 먼저 할지
- 전화·미팅

### ⚠️ 중요 — "못 한다"는 말은 반드시 되물으세요
AI가 일하는 자리(우리는 「상자」라고 부릅니다)가 **세 종류**고, 각각 할 수 있는 게 다릅니다.

| 상자 | 뭐가 되나 |
|---|---|
| **웹 세션** (claude.ai 에서 여는 것) | 코드·문서·DB 다 됨. 대표님 PC 브라우저는 못 건드림 |
| **로컬 세션** (대표님 PC에 설치된 것) | 위 전부 + PC 브라우저 조작 + 앱 파일 만들기 |
| 폰 | 보기만 |

2026-08-19에 실제로 AI가 "앱 파일 만들기는 원천적으로 못 한다"고 말했는데, **웹 세션 기준으로만 맞는 말**이었고 로컬 세션에서는 됐습니다. 대표님이 두 번 되물어서 정정됐습니다.
→ **"못 한다"가 나오면 "어느 상자 기준이야? 다른 데선 되는 거 아냐?"** 라고 물으세요.

## 2. 첫날 — 이 순서대로 하세요

### ① 세션(대화창)을 엽니다
접속 계정·경로는 대표님께 받으세요. *(문서 작성 시점에 이 부분은 확인하지 못했습니다 — 대표님이 쓰시는 방식 그대로 인계받으면 됩니다.)*

### ② 첫 문장은 이걸 복붙하세요
```
나 오늘부터 이 프로젝트 담당하게 된 신규 담당자야. 개발은 전혀 모른다.
docs/AI_사용설명서_신규담당자.md 랑 docs/PROJECT_CONTEXT.md 최상단 인수인계를 읽고,
지금 이 프로젝트가 어떤 상태인지 — 진행 중인 일 / 막혀 있는 일 / 내가 알아야 할 것 —
표 한 장으로 정리해줘. 전문 용어는 쉬운 말로 풀어서.
```

### ③ 세션을 열면 AI 화면에 자동으로 뜨는 것들
우리 프로젝트는 세션이 열릴 때 **현재 상태 브리핑**이 자동으로 AI에게 주입되게 만들어놨습니다. 여기엔 이런 게 들어 있습니다.

- 실서비스에 아직 안 나간 작업이 몇 건인지
- 진행 중인 작업 목록(브랜치)과 **서로 겹치는 작업이 있는지**
- 3일 넘게 방치된 작업
- 대표님 취향 원장(지금까지 쌓인 선호)

당신이 직접 읽을 필요는 없습니다. **"지금 브리핑에 뭐가 떴어? 쉬운 말로 3줄로 알려줘"** 라고 하면 됩니다.

### ④ 배경 지식이 필요하면 (읽을 필요는 없고, 있는 줄만 아세요)

## 3. 일 시키는 법

### 3-1. 복붙해서 쓰는 문장 틀 5개

**① 고쳐달라고 할 때 — 「증상 + 확인까지」**
```
[어디서] [무엇이] 안 된다고 한다. 원인 찾아서 고치고,
실제로 그 화면을 눌러서 되는 것까지 확인한 다음에 알려줘.
```
> 왜 "확인까지"를 붙이나: 2026-08-20 실측 사고 — 환자 증상 제출이 **전부 저장 실패**하고 있었는데 화면은 멀쩡해 보였습니다. 코드는 통과했고 아무도 몰랐습니다. 대표님이 "실제로 한 번 돌려봐"라고 해서 드러났습니다.

**② 물어볼 때 — 「숫자로」**
```
[무엇]이 몇 건인지 실제 데이터로 세서 알려줘. 기억이나 문서 말고 지금 조회해서.
```

**③ 점검시킬 때**
```
[영역] 훑어봐. 문제 있으면 ①지금 당장 아픈 것 ②나중에 봐도 되는 것으로 갈라서 보고해줘.
```

**④ 여러 개를 한 번에 시킬 때 (중요)**
```
아래 다 처리해줘. 중간에 하나씩 보고하지 말고 끝까지 한 다음에 한 번에 보고해.
결정할 게 있으면 지금 한꺼번에 다 물어봐.
1) ...
2) ...
3) ...
```
> 왜: 2026-08-15 실측 — 남은 8건을 "1건 고치고 묻고, 또 1건 고치고 묻고" 식으로 끊자 대표님이 *"하나씩 대답 다 듣고 작업 시작해, 하나씩 깨작깨작하지 말고"*. 지금은 규칙으로 박아뒀지만 당신도 이렇게 말해주면 확실합니다.

**⑤ 작업을 마칠 때**
```
/handoff
```
> 슬래시(/)로 시작하는 건 **미리 만들어둔 명령**입니다. `/handoff`는 이번에 한 일·결정한 것·다음에 할 일을 인수인계 문서에 정리합니다. **세션 끝낼 때 이거 한 번**이면 다음 사람(또는 다음 대화)이 이어받을 수 있습니다.

### 3-2. 나쁜 지시 → 좋은 지시

| ❌ 이렇게 말하면 | 무슨 일이 생기나 | ⭕ 이렇게 |
|---|---|---|
| "챗봇 개선해줘" | 어디를 어떻게 개선할지 AI가 자기 맘대로 정합니다 | "환자가 러시아어로 물어봤을 때 답이 영어로 나온대. 확인하고 고쳐줘" |
| "이거 될까?" | 추측으로 답할 수 있습니다 | "이거 실제로 해보고 되는지 알려줘" |
| "빨리 해줘" | 검증을 건너뜁니다 | "급한 거니까 30분 안에 되는 만큼만 하고, 못 한 건 못 했다고 알려줘" |
| "알아서 해줘" | 돈·삭제까지 알아서 할 수 있습니다 (안전장치는 있지만) | "알아서 해도 되는데, 돈 나가거나 뭘 지우는 건 나한테 먼저 물어봐" |

### 3-3. 시키기 전에 이것만 확인
- **같은 걸 다른 사람이 이미 하고 있지 않나?** — 우리는 여러 대화창(세션)을 동시에 돌립니다. 2026-06-22에 배포·AI챗·안전가드 **3개 영역이 중복**돼서 서로 충돌한 적 있습니다. 시작 전에 **"지금 다른 세션이 이 영역 하고 있어? 열린 작업 목록 확인해줘"** 한마디.

## 4. AI 답을 읽는 법

우리는 AI 응답 형식을 **규칙으로 강제**해놨습니다. 그래서 답이 아래 모양으로 옵니다. 이 모양을 알면 읽기 쉽습니다.

### 4-1. 첫 줄은 반드시 「판정」입니다
셋 중 하나여야 합니다.
1. **문제 없음** (당신이 할 것 없음)
2. **문제 있음 — AI가 고칩니다**
3. **문제 있음 — 사람 손이 필요합니다**

> 첫 줄이 "이 시스템은 이러이러하게 동작하는데요…" 로 시작하면 **잘못된 응답**입니다. 2026-08-06 실측: 구조를 정확히 설명했는데 대표님이 *"그래서 해결을 했다는 거야 문제가 있다는 거야"*. → **"그래서 문제가 있다는 거야 없다는 거야? 한 줄로."**

### 4-2. 「확인한 것 / 확인 못 한 것」 칸
완료 보고에는 **반드시 두 칸**이 있어야 합니다. "확인 못 한 것: 없음"이라도 칸은 있어야 합니다.

> 왜: 2026-07-31 대표님 지적 — *"너 맨날 내가 물어보면 그제서야 아 이거 안 됐구요 저거 안 됐구요"*. AI가 게을러서가 아니라 **확인된 것만 적고 못 잰 건 안 적는** 순서 때문이었습니다.
> **이 칸이 없으면 = 다 확인했다는 뜻이 아니라, 안 적은 것뿐입니다.** 없으면 요구하세요.

### 4-3. 마지막 칸은 「당신이 할 일」
없으면 "없다"고 적혀 있어야 합니다. 표만 잔뜩 있고 "그래서 내가 뭘 해야 하나"가 없으면 되물으세요.
```
그래서 내가 할 일이 있어 없어? 있으면 뭘 어디서 하면 되는지 링크까지.
```

### 4-4. 버튼(선택지)이 뜨면
AI가 결정이 필요할 때 **클릭 버튼**을 띄웁니다.
- **버튼은 한 화면에 하나**가 규칙입니다. 버튼이 연달아 계속 뜨면 → *"질문 그만하고 그냥 진행해"*
- **버튼을 취소한 것도 답입니다.** "다른 거 해"라는 뜻으로 AI가 알아듣게 규칙에 박아놨습니다
- **버튼 내용이 이해 안 되면 그냥 "무슨 말인지 모르겠어, 쉽게"** 라고 하세요. 2026-09-08에 실제로 대표님이 어려운 버튼은 답을 안 하고 쉬운 버튼만 골라 답한 일이 있습니다

> 실측: 2026-07-20 한 세션에서 버튼이 43개 떴고, **질문을 만드는 데만 13분 48초**를 썼습니다. 응답이 느려지는 가장 큰 원인이었습니다.

### 4-5. 이런 응답이 오면 되돌려 보내세요 (복붙용)

| AI가 이렇게 답하면 | 이렇게 되받으세요 |
|---|---|
| 길고 어려운 설명 | `쉽게 설명해줘. 두 줄로.` |
| 구조·흐름 설명이 안 그려짐 | `그림으로 그려줘. 글 말고.` |
| "고쳤습니다" (화면 얘기인데 사진이 없음) | `화면 사진으로 보여줘.` |
| 커밋 번호·영문 상태값·봇 알림을 그대로 옮겨 적음 | `그거 내가 알아야 하는 거야? 아니면 넘어가.` |
| "권한 밖입니다" / "못 합니다" | `진짜 못 하는 거야, 규칙 때문에 안 하는 거야? 어느 상자 기준이야?` |
| "내일 자동 검사가 확인해줄 겁니다" | `지금 확인해봐.` (2026-08-18 실측: 실제로 그 자리에서 28초 만에 됐습니다) |
| "다른 세션이 하고 있어서 안 했습니다" | `그 세션 살아 있어? 죽었으면 니가 마무리해.` |
| 목록만 훑고 "확인했다" | `열어서 내용까지 봤어? 목록만 본 거야?` |

## 5. 「다 됐습니다」를 그대로 믿으면 안 되는 이유

이건 AI가 거짓말을 해서가 아닙니다. **AI가 재는 자(기준)와 사람이 보는 것이 다르기 때문**입니다.

| AI가 "됐다"고 말하는 근거 | 실제로는 |
|---|---|
| "코드가 통과했습니다(빌드 성공)" | 화면이 그려진다는 뜻일 뿐, **동작한다는 뜻이 아닙니다** |
| "화면이 200으로 열립니다" | 열리기만 하고 저장은 실패할 수 있습니다 (실제 사고 있었음) |
| "문서에 그렇게 돼 있습니다" | 문서는 **「그 날짜의 사실」**입니다. 2026-08-03에 AI가 한 달 전 문서를 읽고 "앱스토어 결제부터 하세요"라고 보고했는데, 대표님 답이 *"결제 했는데 언제적 소리 하고 있냐"* — 실제로는 5건이 이미 끝나 있었습니다 |
| "합쳤습니다(머지)" | **실서비스에 나갔다는 뜻이 아닙니다.** 5장 참고 |

### 되물음 5문장 — 이게 우리 팀의 검증 장치입니다
```
1. 그거 실제로 눌러보고 하는 말이야?
2. 확인 못 한 건 뭐야?
3. 어떤 자로 쟀어? 안 재본 각도 있어?
4. 더 확인할 건 없어? 허점 없어?
5. 지금 상태가 깨끗하다는 거야 아니라는 거야?
```
> **실측:** 2026-07-28 하루에 세 번 이렇게 되물었고 **세 번 다 실제 결함이 나왔습니다.** 그중 둘은 AI가 방금 만든 것, 하나는 광고비가 걸린 것이었습니다. 한 번이라도 "네 다 됐습니다"로 넘어갔으면 전부 실서비스로 나갔습니다.
>
> ⚠️ 다만 **끝없이 되묻는 것도 답이 아닙니다.** 2026-08~09에 대표님이 "또 뒤지면 또 나올 거지?"를 아홉 번 물었고, AI가 답하는 법이 확정됐습니다 — **"방금 판 자리는 다 팠다(다시 봐도 안 나온다) / 새 자리는 나온다"** 로 갈라서 답하게 돼 있습니다. 이 모양으로 답이 오면 그건 정상입니다.

## 6. 진행상황 확인하는 법 — 4단 사다리

가장 많이 헷갈리는 부분입니다. **"고쳤다"와 "손님이 볼 수 있다"는 네 단계 차이**입니다.

```
① 고쳤다        AI가 자기 작업 공간에서 파일을 고침
     ↓            (이 단계에선 아무도 못 봅니다)
② 신청서 냈다    합치기 신청서(PR) 제출 → 자동 검사 돌아감
     ↓
③ 본판에 합쳤다  main 이라는 본체에 들어감
     ↓            ⚠️ 여기까지 와도 손님은 못 봅니다
④ 실서비스에 나감  매일 오후 3시(한국시간)에 한 번, 그날 합친 것 전부가 한꺼번에 나감
```

### 단계별 확인 문장 (복붙)
| 알고 싶은 것 | 이렇게 물으세요 |
|---|---|
| 지금 뭐 하고 있어? | `지금 어디까지 됐어? 위 4단계 중 어디야?` |
| 내가 부탁한 게 손님한테 보이나? | `그거 실서비스에 나갔어? /api/health 쳐서 확인해줘` |
| 오늘 뭐가 나갔나? | `오늘 실서비스에 나간 것 목록이랑, 아직 안 나간 것 알려줘` |
| 방치된 거 없나? | `며칠째 안 합쳐지고 떠 있는 작업 있어?` |

> **왜 오후 3시 한 번인가:** 배포(빌드)마다 돈이 나갑니다. 2026-07 실측에서 클라우드 요금의 94%가 빌드 비용이었고, 그중 67%는 **아무도 안 보는** 미리보기였습니다. 그래서 "합치는 건 자유, 실서비스 반영은 하루 한 번"으로 정했습니다.
> **급하면** 예외가 있습니다 — 장애·보안·대표님이 지금 보자고 한 것. 그럴 땐 `이거 급해. 지금 바로 내보내줘` 라고 하면 됩니다.

### 실서비스가 살아있는지 보는 법
주소창에 이거 치면 됩니다 (당신이 직접 봐도 됨):
```
https://healwith.co.kr/api/health
```
`ok`가 뜨면 살아있는 겁니다. `commit`에 적힌 값이 **지금 실서비스에 올라가 있는 버전**입니다.

## 7. 절대 혼자 결정하지 마세요 (= 대표님 몫)

AI에게는 안전장치가 걸려 있어서 아래 것들은 **실행 직전에 확인창**이 뜹니다. 확인창이 뜨면 **누르지 말고 대표님께 물어보세요.**

| 이런 게 나오면 | 왜 위험한가 |
|---|---|
| 데이터 **삭제**, 표(테이블)·칸(컬럼) 없애기 | 되돌릴 수 없습니다. 실환자 자료입니다 |
| 로그인·암호화·개인정보 관련 변경 | 환자 진단명·연락처가 들어 있습니다 |
| 유료 서비스 가입·한도 올리기·결제 | 돈이 나갑니다 |
| "강제로 밀어넣기"(force push), 되돌리기(reset) | 남의 작업이 사라질 수 있습니다 |
| 외부(병원·에이전시·환자)에 **메일·메시지 발송** | 회수가 안 됩니다 |

> 실제로 2026-09-08에 AI가 만든 저장 버튼이 **실환자 한 명의 치료 이력을 지운** 사고가 있었습니다(즉시 복구). 이런 게 왜 규칙으로 박혀 있는지의 이유입니다.

**추가로 대표님만 정할 수 있는 것:** 무엇을 먼저 할지(우선순위), 병원·파트너 관련 판단, 대외 문구·가격.

## 8. 우리가 실제로 겪은 시행착오 — 미리 알고 가세요

> 아래는 전부 **실제로 났던 일**입니다. 같은 걸 또 겪지 마시라고 정리했습니다.

| # | 이런 일이 생깁니다 | 실제 사례 | 이렇게 하세요 |
|---|---|---|---|
| 1 | **"다 했다"의 근거가 측정이 아니라 기억·문서** | 2026-09-10 "다 한 거지?"를 세 번 물었는데 앞의 두 번이 틀렸습니다 | `그거 지금 재보고 하는 말이야?` |
| 2 | **고친 게 실서비스엔 안 나가 있음** | 세션 내내 고치고 검증까지 했는데 **본판에 하나도 안 가 있던** 적 있음 | `본판에 들어갔어? 실서비스는?` |
| 3 | **화면은 멀쩡한데 저장이 안 됨** | 환자 증상 제출이 전부 실패, 위험도 95%를 화면엔 0%로 표시 | `직접 입력해보고 DB에 들어갔는지 확인해줘` |
| 4 | **A를 고쳤더니 B가 고장** | 톤 안 맞는 화면을 지우면서 **응급 전화 동선**까지 같이 삭제(한 달 뒤 발견) | `이거 고치면 영향받는 데 어디야? 거기도 확인해줘` |
| 5 | **한 곳만 고치고 나머지를 안 봄** | 언어 6개 중 한국어만 고쳐서 러시아·카자흐 환자가 영어 화면을 받음 | `다른 언어·다른 화면도 같은 문제 있어? 전수로 봐줘` |
| 6 | **어려운 말로 설명** | *"쉽게 좀 설명해줘 뭔 말인지 모르겠어"* (여러 번) | `쉽게. 두 줄로.` |
| 7 | **글로 설명하다 세 번 왕복** | 2026-08-03 설계를 글→표→다시 글로 세 번 설명. 그림을 그리자 대표님이 **설계 결함 2개**를 바로 잡아냄 | `처음부터 그림으로 그려줘` |
| 8 | **로봇 알림을 그대로 옮겨 적음** | 봇 알림 11건을 커밋번호까지 보고 → *"아쒸 뭐라는 거야"* | `내가 판단할 게 아니면 말하지 마` |
| 9 | **변화 없는데 계속 보고** | 애플 심사 결과를 20분마다 "아직 안 왔습니다" → *"그만해"* | `변화 있을 때만 알려줘` |
| 10 | **초안으로 올려두고 대기** | 검사 다 통과해놓고 신청서를 초안으로 둔 채 10시간 동안 상태만 8번 확인(실질 작업 0) | `기다리지 말고 니가 마무리해` |
| 11 | **여러 세션이 같은 걸 동시에 고침** | 배포 창구 하나를 브랜치 6개가 각자 고침 | `다른 세션이 이거 하고 있어?` |
| 12 | **자기가 만든 걸 "지울까요?" 라고만 물음** | *"백업은 뭔데? 뭔지 알아야 지우든가 말든가 하지"* | `그게 뭔지부터 쉽게 설명해` |
| 13 | **"확인해보세요"라고 사람에게 떠넘김** | 확인은 AI 몫입니다 | `니가 확인하고 결과만 알려줘` |
| 14 | **낡은 문서를 현재 사실처럼 보고** | 한 달 전 문서로 "결제부터 하세요" → 이미 다 끝나 있었음 | `그거 언제 확인한 거야? 지금 다시 봐` |
| 15 | **본론과 곁가지를 같은 무게로 보고** | 중요한 것과 부수적인 것을 섞어 보고하자 대표님이 통째로 잘라냄 | `중요한 것만. 나머진 접어둬` |

## 9. 용어 사전 (이것만 알면 됩니다)

| 우리가 쓰는 말 | 원어 | 무슨 뜻 |
|---|---|---|
| 작업본 / 가지 | branch | AI가 작업하는 **복사본**. 여기서 뭘 해도 실서비스엔 영향 없음 |
| 합치기 신청서 | Pull Request, PR | "이 작업을 본체에 넣어도 될까요" 신청. 번호(#1234)가 붙음 |
| 본판 / 본체 | main | 진짜 코드. 여기 들어가야 배포 대상이 됨 |
| 합치기 | merge | 신청서를 본판에 넣는 것 |
| 자동 검사 | CI | 신청서마다 자동으로 도는 검사. 초록불/빨간불 |
| 배포 | deploy | 실서비스에 실제로 반영하는 것 (오후 3시 창구) |
| 저장 기록 | commit | 작업 저장 단위. `9e1af559` 같은 번호가 붙음 |
| 되돌리기 어려움 | irreversible | 삭제·발송처럼 취소 안 되는 것 |
| DB | database | 환자·문의·병원 자료가 들어있는 저장소 |
| 인수인계 | handoff | 다음 사람이 이어받게 정리해둔 것. `/handoff` 로 만듦 |

## 10. 하루 루틴

```
어제부터 지금까지 뭐가 달라졌어? 실서비스 이상 없어? 내가 오늘 볼 것 3개만.

```

```
전체 훑어봐. 허점 없어?
```

## 11. 이건 하지 마세요

1. **AI가 준 셸 명령어를 직접 터미널에 치지 마세요.** AI가 할 수 있는 건 AI가 합니다. 명령어를 쥐여주면 그건 AI가 일을 떠넘긴 겁니다 — *"이건 니가 해도 되는 거 아님?"* (규칙에 박혀 있음)
2. **확인창이 떴는데 무슨 뜻인지 모른 채 승인하지 마세요.** `이거 승인하면 뭐가 어떻게 되는 건지 쉽게 설명해줘` 먼저.
3. **여러 대화창을 동시에 열어 같은 영역을 시키지 마세요.** 충돌합니다.
4. **"알아서 다 해줘"만 던지고 결과를 안 보지 마세요.** 되물음 한 번이 사고 하나를 막습니다.
5. **화면 바뀐 걸 파일 목록으로 확인했다고 넘어가지 마세요.** 반드시 사진.
