## ⚠️ 먼저 — 이 문서는 「감시 목록」이 아니다

이 문서의 **1차 초안은 잘못 쓰여 있었다.** 「AI가 이렇게 답하면 당신이 이렇게 되받으세요」를 17가지나 늘어놨는데, 세어보니 **그 17개가 전부 이미 AI 쪽 규칙으로 박혀 있는 것**이었다. 대표님 지적으로 잡았다(2026-09-10).

그게 왜 나쁜가:

- 새 담당자가 **「내가 매번 감시해야 하는구나」**로 읽는다 — 실제로는 AI가 지켜야 할 몫이다
- AI가 규칙을 어겼을 때 **감시 안 한 사람 탓**이 돼버린다

그래서 이 문서는 이렇게 갈라놨다.

| 칸 | 뜻 |
|---|---|
| **3장 — AI의 약속** | AI가 **알아서 하기로 돼 있는 것.** 안 지키면 **AI 잘못**이지 당신 잘못이 아니다 |
| **4장 — 안 지켜졌을 때** | 외울 문장은 **딱 하나**다. 17개 아니다 |

## 1. 이 AI가 뭐 하는 놈인가

**클로드 코드(Claude Code)** = 우리 서비스(healwith.co.kr)의 **코드를 직접 읽고 고치고 올리는** AI입니다. 챗GPT처럼 "이렇게 하세요"라고 알려주는 게 아니라, **자기 손으로 파일을 고치고 저장하고 배포까지** 합니다.

### 할 수 있는 것 — 그냥 시키면 됩니다
- 코드 읽기·고치기·새 기능 만들기
- 데이터베이스 조회 — "8월에 문의 몇 건 들어왔어?"에 **실제 숫자**로 답함
- 화면 띄워서 사진 찍기 (로그인해야 보이는 관리자 화면도 됨)
- 문서·엑셀·PPT·한글문서 만들기
- 실서비스 점검, 오류 로그 확인
- 깃허브에 작업 올리고 합치기

### 못 하는 것
- 대표님·당신 PC의 브라우저를 대신 클릭 *(웹에서 돌리는 세션 기준)*
- 앱스토어 업로드·은행·정부 사이트처럼 **본인 인증**이 필요한 것
- **사업 판단** — 얼마 쓸지, 어느 병원과 계약할지, 뭘 먼저 할지
- 전화·미팅
- **실물 폰으로 직접 보기** — 화면 크기 흉내는 내지만 진짜 기기는 아님

### ⚠️ 단, "못 한다"는 말은 한 번 되물으세요
AI가 일하는 자리(**「상자」**)가 세 종류고 각각 할 수 있는 게 다릅니다.

| 상자 | 뭐가 되나 |
|---|---|
| **웹 세션** (claude.ai에서 여는 것) | 코드·문서·DB 다 됨. 대표님 PC 브라우저는 못 건드림 |
| **로컬 세션** (대표님 PC에 설치된 것) | 위 전부 + PC 브라우저 조작 + 앱 파일 만들기 |
| 폰 | 보기만 |

2026-08-19에 AI가 "앱 파일 만들기는 원천적으로 못 한다"고 말했는데 **웹 세션 기준으로만 맞는 말**이었고 로컬에선 됐습니다. *(이것도 이제는 AI 규칙에 박혀 있습니다 — 3장 12번.)*

## 2. 첫날 — 이 순서대로

### ① 세션(대화창)을 엽니다
접속 계정·권한은 **대표님이 정해서 열어주는 것**입니다. 12장 참고.

### ② 첫 문장은 이걸 복붙하세요
```
나 오늘부터 이 프로젝트 담당하게 된 신규 담당자야. 개발은 전혀 모른다.
docs/AI_사용설명서_신규담당자.md 랑 docs/PROJECT_CONTEXT.md 최상단 인수인계를 읽고,
지금 이 프로젝트가 어떤 상태인지 — 진행 중인 일 / 막혀 있는 일 / 내가 알아야 할 것 —
표 한 장으로 정리해줘. 전문 용어는 쉬운 말로 풀어서.
```

### ③ 세션을 열면 AI에게 자동으로 뜨는 것
대화창이 열릴 때 **현재 상태 브리핑**이 AI에게 자동 주입됩니다 — 실서비스에 안 나간 작업, 겹치는 작업, 방치된 작업, 대표님 취향 원장까지. **당신이 읽을 필요도, 물어볼 필요도 없습니다.** AI가 그걸 읽고 시작하게 돼 있습니다.

### ④ 배경 문서 — 있는 줄만 아세요
| 문서 | 뭐가 들었나 |
|---|---|
| `docs/PROJECT_CONTEXT.md` 맨 위 | **가장 중요.** 최근 세션이 뭘 했고 왜 그렇게 결정했는지 |
| `docs/KNOWN_ISSUES.md` | 알려진 문제·다음 할 일 |
| `docs/대표님_서비스_이해_매뉴얼.md` | 서비스가 뭐 하는 건지 (비개발자용) |
| `CLAUDE.md` + `.claude/hooks/` | **AI가 지켜야 하는 규칙.** 3장의 약속들이 여기 박혀 있습니다 |
| `docs/POSTMORTEMS.md` | 지금까지 난 사고 190여 건 |

## 3. AI의 약속 — 안 지키면 AI 잘못입니다

> 아래는 **당신이 요구해야 하는 것이 아니라, AI가 매번 알아서 하기로 돼 있는 것**입니다. 각 줄 오른쪽이 그 규칙이 실제로 박혀 있는 자리입니다. 시켜서 되는 게 아니라 **기본값**입니다.

| # | AI가 알아서 하는 것 | 규칙 위치 |
|---|---|---|
| 1 | **쉬운 말로 답한다.** 전문 용어는 풀어서 + 원어 병기 | `CLAUDE.md` 소통 스타일 · 말투 스타일 |
| 2 | **첫 줄은 판정.** ①문제 없음 ②내가 고친다 ③사람 손 필요 — 셋 중 하나로 시작 | 훅 4-1 |
| 3 | **완료 보고엔 「확인한 것 / 확인 못 한 것」 두 칸.** 못 잰 게 없으면 "없음"이라고 명시 | 훅 14 |
| 4 | **마지막은 「당신이 할 일」.** 없으면 "손 갈 것 없습니다"라고 적는다 | 훅 14-2 |
| 5 | **구조·흐름·설계는 첫 응답부터 그림으로.** 글로 두 번 설명하지 않는다 | 훅 5-1 |
| 6 | **화면을 고친 턴은 그 화면을 띄워 사진으로.** 파일 목록·커밋 번호로 갈음하지 않는다 | 훅 7-1 |
| 7 | **빌드 통과 ≠ 동작.** 실제 여정을 눌러보고 실DB로 확인한 뒤 "됐다"고 말한다 | `CLAUDE.md` ⭐1 |
| 8 | **완료 판정의 근거는 문서·기억이 아니라 그 순간의 측정** (배포=`/api/health`, 상태=`git status`) | 취향원장 2026-09-10 |
| 9 | **끝낸 일엔 「어느 화면·공개 여부·실서비스 반영 시각」 3줄을 붙인다** | 훅 11-1 |
| 10 | **남은 일엔 「지금 되나 / 뭘 기다리나」를 같이 적는다** | 훅 11 |
| 11 | **로봇 알림(빌드봇·검사봇·커밋번호)은 옮겨 적지 않는다.** 사람이 판단할 것만 올린다 | 훅 16 · 4-4 |
| 12 | **"못 한다"고 할 땐 「능력이 없다」인지 「규칙상 안 한다」인지, 어느 상자 기준인지 밝힌다** | 훅 3-5 |
| 13 | **묶음 작업은 앞에서 결정을 다 받고, 중간 보고 없이 끝까지 한 다음 한 번에 보고** | 훅 3-1 |
| 14 | **질문 버튼은 한 화면에 하나.** 답한 바로 다음에 또 묻지 않는다 | 훅 3-1·3-3 |
| 15 | **새 작업 전에 다른 세션이 같은 영역을 하는지 먼저 대조한다** | `AUTOMERGE.md` 3 |
| 16 | **"내일 자동검사가 확인해줄 것"으로 미루지 않는다.** 지금 잴 방법을 먼저 찾는다 | 취향원장 2026-08-18 |
| 17 | **목록만 보고 "확인했다"고 하지 않는다.** 본문을 연다 | 훅 14-2 |
| 18 | **발견한 문제는 「지금 아픈 것 / 적어둘 것」으로 갈라서 보고한다** | 취향원장 2026-08-14 |
| 19 | **버그는 원인 + 재발방지까지 한 세트.** 기계로 막을 수 있으면 자동검사로 박는다 | `CLAUDE.md` 반복확정 7·10 |
| 20 | **돈·삭제·보안 앞에서는 멈춰서 사람에게 확인한다** (기계가 실행 직전에 붙잡습니다) | `CLAUDE.md` 자율 안전선 · `guard-destructive.mjs` |

**그래서 당신이 시킬 때 붙일 필요 없는 말들:** “확인까지 해줘” · “쉽게 설명해줘” · “그림으로 보여줘” · “실제로 돌려봐” · “다른 세션이 하고 있어?” — 전부 기본값입니다. 붙여도 되지만, **안 붙였는데 안 지켜졌으면 그건 AI 잘못**입니다.

## 4. 안 지켜졌을 때 — 외울 문장은 하나

AI도 규칙을 어깁니다(그 기록이 `POSTMORTEMS.md` 190여 건입니다). 17가지 대응을 외울 필요 없습니다. **이 한 문장이면 됩니다.**

```
그거 규칙 안 지킨 거 아냐? CLAUDE.md 랑 훅 다시 보고,
뭘 어겼는지 + 왜 그랬는지 + 다시 안 그러게 뭘 할 건지까지 알려줘.
```

이게 왜 통하나: AI는 매 응답마다 이 규칙들을 다시 읽도록 돼 있습니다. 어겼다는 건 **읽고도 건너뛴 것**이라, 지적하면 그 자리에서 잡힙니다. 그리고 같은 게 반복되면 「문서에 적기」가 아니라 **자동검사로 박는 것**까지가 AI 몫입니다.

### 그래도 자주 쓰게 되는 두 마디

| 상황 | 한마디 |
|---|---|
| 답이 길고 머리 아플 때 | `머리 아프다. 두 줄로. 내가 할 일만.` |
| 결론이 안 보일 때 | `그래서 지금 상태가 깨끗한 거야 아닌 거야?` |

## 5. 「다 됐습니다」를 한 번은 되물어야 하는 이유

AI가 거짓말을 해서가 아닙니다. **AI가 재는 자와 사람이 보는 것이 다르기 때문**입니다. 3장 7·8번이 이걸 막으라고 있는 규칙인데, **실측상 사람이 한 번 되물었을 때 결함이 더 나왔습니다.**

> **2026-07-28 실측:** 대표님이 하루에 세 번 되물었고 **세 번 다 실제 결함이 나왔습니다.** 둘은 AI가 방금 만든 것, 하나는 광고비가 걸린 것이었습니다.

그래서 **중요한 게 실서비스로 나가기 전 한 번만** 이렇게 물으면 됩니다. 매번은 아닙니다.

```
그거 실제로 눌러보고 하는 말이야? 확인 못 한 건 뭐야?
```

> ⚠️ **끝없이 되묻는 것도 답이 아닙니다.** 2026-08~09에 대표님이 "또 뒤지면 또 나올 거지?"를 아홉 번 물었고, AI가 답하는 법이 확정됐습니다 — **"방금 판 자리는 다 팠다 / 새 자리는 나온다"**로 갈라서 답하게 돼 있습니다. 이 모양으로 오면 정상입니다.

## 6. 진행상황 확인 — 4단 사다리

**"고쳤다"와 "손님이 볼 수 있다"는 네 단계 차이**입니다.

```
① 고쳤다        AI 작업 공간에서 파일을 고침 (아무도 못 봄)
     ↓
② 신청서 냈다    합치기 신청서(PR) 제출 → 자동 검사가 돌아감
     ↓
③ 본판에 합쳤다  main 이라는 본체에 들어감  ⚠️ 여기까지도 손님은 못 봅니다
     ↓
④ 실서비스에 나갔다  매일 오후 3시(한국시간) 한 번, 그날 합친 것 전부가 한꺼번에
```

**이 네 단계는 AI가 보고에 알아서 적게 돼 있습니다**(3장 9번). 안 적혀 있으면 그건 규칙 위반이지 당신이 매번 물어야 하는 게 아닙니다.

당신이 **직접** 확인하고 싶을 때만 — 주소창에 이거 치면 됩니다.
```
https://healwith.co.kr/api/health
```
`ok`가 뜨면 살아있는 것이고, `commit` 값이 지금 실서비스에 올라가 있는 버전입니다.

> **왜 오후 3시 한 번인가:** 배포마다 돈이 나갑니다. 2026-07 실측에서 클라우드 요금의 94%가 빌드 비용이었고 그중 67%는 **아무도 안 보는** 미리보기였습니다. 급한 것(장애·보안)은 예외로 바로 내보냅니다.

## 7. 진짜 사람 몫 — 이것만 당신이 판단합니다

### 7-1. 멈춰 세워야 하는 것 (승인창이 뜹니다)
기계가 실행 직전에 붙잡아 확인창을 띄웁니다. **뜻을 모르면 누르지 말고 대표님께.**

| 이런 게 나오면 | 왜 |
|---|---|
| 데이터 **삭제**, 표·칸 없애기 | 되돌릴 수 없음. 실환자 자료입니다 |
| 로그인·암호화·개인정보 변경 | 환자 진단명·연락처가 들어 있습니다 |
| 유료 가입·한도 올리기·결제 | 돈이 나갑니다 |
| 강제로 밀어넣기·되돌리기 | 남의 작업이 사라질 수 있습니다 |
| 외부(병원·에이전시·환자)에 메일·메시지 발송 | 회수가 안 됩니다 |

> 2026-09-08에 AI가 만든 저장 버튼이 **실환자 한 명의 치료 이력을 지운** 사고가 있었습니다(즉시 복구).

### 7-2. 기계가 대신 못 하는 것
- **실물 폰·태블릿으로 직접 보기** — 흉내는 내지만 진짜 기기가 아닙니다
- **사업 판단** — 우선순위, 병원·파트너, 가격, 대외 문구
- **외부 사람과의 소통** — 전화·미팅·협상
- **세션을 끝낼 시점 정하기** → 끝낼 때 `/handoff` 한 번 (다음 사람이 이어받게 정리됩니다)

## 9. 용어 사전

| 우리가 쓰는 말 | 원어 | 무슨 뜻 |
|---|---|---|
| 작업본 · 가지 | branch | AI가 작업하는 **복사본**. 여기서 뭘 해도 실서비스엔 영향 없음 |
| 합치기 신청서 | Pull Request, PR | "본체에 넣어도 될까요" 신청. 번호(#1234)가 붙음 |
| 본판 · 본체 | main | 진짜 코드. 여기 들어가야 배포 대상 |
| 합치기 | merge | 신청서를 본판에 넣는 것 |
| 자동 검사 | CI | 신청서마다 자동으로 도는 검사. 초록불 / 빨간불 |
| 배포 | deploy | 실서비스에 실제로 반영 (오후 3시 창구) |
| 저장 기록 | commit | 작업 저장 단위. `9e1af559` 같은 번호 |
| DB | database | 환자·문의·병원 자료가 들어있는 저장소 |
| 인수인계 | handoff | 다음 사람이 이어받게 정리한 것. `/handoff`로 만듦 |
| 훅 | hook | AI가 매 응답마다 강제로 다시 읽는 규칙 파일 |

3. **여러 대화창을 동시에 열어 같은 영역을 시키지 마세요.** 충돌합니다
4. **AI 답을 감시하려고 애쓰지 마세요.** 3장은 AI 몫입니다. 이상하면 4장의 한 문장
