### 1. **API 라우트**
**파일**: `app/api/admin/site-settings/route.ts`

#### 엔드포인트:

##### GET `/api/admin/site-settings`
- **기능**: 현재 사이트 설정 조회
- **인증**: 관리자 전용
- **응답**:
  ```json
  {
    "ok": true,
    "settings": {
      "logo_url": "https://...",
      "hero_background_url": "https://..."
    }
  }
  ```

##### PUT `/api/admin/site-settings`
- **기능**: 사이트 설정 업데이트 (upsert)
- **인증**: 관리자 전용
- **요청 Body**:
  ```json
  {
    "logo_url": "https://...",
    "hero_background_url": "https://..."
  }
  ```
- **동작**:
  - 기존 설정이 있으면 UPDATE
  - 없으면 INSERT (첫 생성)

## 🚀 테스트 시나리오

### 1. 브랜딩 설정 페이지 접근
```
1. 관리자 로그인
2. 사이드바 "시스템" > "브랜딩 설정" 클릭
3. ✅ /admin/settings/branding 페이지 로드
4. ✅ 현재 설정 표시 (없으면 빈 값)
```

### 2. 로고 이미지 변경
```
1. "로고 이미지 URL" 입력창에 URL 입력
   예: https://via.placeholder.com/150x40
2. ✅ 미리보기 영역에 이미지 표시
3. "저장" 버튼 클릭
4. ✅ Toast: "✓ 브랜딩 설정이 저장되었습니다"
5. ✅ 1초 후 페이지 새로고침
6. ✅ 헤더 로고 즉시 변경 확인
```

### 3. 히어로 배경 변경
```
1. "히어로 배경 이미지 URL" 입력창에 URL 입력
   예: https://via.placeholder.com/1920x1080
2. ✅ 미리보기 영역에 배경 이미지 + 오버레이 표시
3. "저장" 버튼 클릭
4. ✅ Toast + 새로고침
5. ✅ 홈페이지 히어로 배경 즉시 변경 확인
```

### 4. 에러 처리
```
1. 잘못된 이미지 URL 입력
   예: https://invalid.url/image.png
2. ✅ 미리보기 영역에 "❌ 이미지 로드 실패" 표시
3. 저장 시 URL은 저장되지만 이미지는 표시 안 됨
```
