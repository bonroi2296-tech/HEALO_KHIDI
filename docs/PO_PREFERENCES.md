# PO 취향·선호 누적 원장 (PO Preference Ledger)

> **이건 뭔가:** CLAUDE.md의 *고정 규칙*(말투·보안·빌드)과 **별개로**, 세션 중에 PO 지시·반응에서 **그때그때 묻어나온 취향·선호·성향**을 누적 기록하는 곳. 코드만 봐선 안 보이고, 고정 규칙으로 박기엔 아직 유동적인 것들.
>
> **누가 채우나:** `/handoff` 스킬이 세션 종료 시 **이번 대화를 분석**해, 새로 드러난 PO 취향을 아래 「활성 취향」에 1건씩 추가/갱신(중복 금지·날짜 절대표기). 세션 시작 시 `session-orient.sh` 훅이 「활성 취향」을 **자동으로 컨텍스트에 띄움** → 다음 세션이 안 읽어도 PO 성향을 안 어김.
>
> **고정 규칙으로 승격:** 어떤 취향이 3회 이상 반복·확정되면 CLAUDE.md(또는 훅)의 고정 규칙으로 올리고 여기선 "→ CLAUDE.md 승격"으로 표시.
>
> **군살 방지:** 「활성 취향」은 항상 짧게(훅이 매번 띄우므로). 더 이상 유효하지 않거나 고정 규칙으로 승격된 항목은 「보관(히스토리)」로 내린다.

- **(2026-07-28) ⭐ 「용어 쉽게 풀기 + 원어 병기」가 시간이 지나면 슬그머니 사라진다 — 매 응답 지켜라 (CLAUDE.md 고정규칙이지만 드리프트 확인돼 활성으로 재등록)**: PO 가 **"개발 용어 최대한 풀어 쓰고 내가 학습할 수 있게 병기해달라고 한거 안한지 개오래된거 같은데 내가 얘길 안하니깐 이시키가 교정을 안하네"** 라고 직접 지적. 세션이 길어지면 어시가 `PR`·`머지`·`RLS`·`env` 같은 날용어를 그대로 쓰기 시작한다. → **형식 고정: 「쉬운 말(원어)」**. 예) 합치기 신청서(PR), 본판에 합침(머지), 접근권한 규칙(RLS), 환경변수(env·비밀키 설정값), 자동 검사(CI), 되돌리기(롤백). 처음 나오는 용어는 한 번 더 한 줄로 풀어라. **PO 가 지적해야 고쳐지는 상태 = 실패.**

PO 답: **"e2e는 뭐 다른 세션이 작업하고 있지 않냐?"** — 실제로 [#1081](https://github.com/bonroi2296-tech/HEALO_KHIDI/pull/1081) 이 이미 월 $0 방식으로 진행 중이었고, 통역 버튼·쿠키 배너도 마찬가지였다. → **미결항목을 보고할 때는 `gh pr list` + 최근 원격 브랜치를 먼저 대조**하고, 진행 중인 것은 「PO 할 일」이 아니라 「돌아가는 중」으로 분류해라. 문서는 특정 시점 스냅샷이라 항상 낡아 있다.

- **(2026-07-28) ⭐⭐ 「마저 해」가 3번 나오면 내가 계속 끊고 있다는 뜻 — 중간 체크포인트로 턴을 끝내지 마라 (→ 4회 확정, CLAUDE.md 승격 후보)**: Play 콘솔 설정을 채우면서 어시가 3/11·6/11·8/11 마다 보고하고 턴을 끝내자 PO가 **"ㅇㅇ마저진행해"** → **"계속 마저 해줘"** → **"데이터 보안까지 마저 하고 정리해줘"** 로 **세 번 밀었다.** 어시는 「길어지니 중간보고가 친절」이라 여겼지만 PO 입장에선 **매번 다시 시동을 걸어줘야 하는 부담**이었다. → **한 덩어리 작업(설문 채우기·목록 처리)은 «막히거나 PO 결정이 필요한 지점»까지 쭉 가라.** 진행률 보고는 그 지점에 도착했을 때 한 번. 끊어야 할 유일한 이유는 **①진짜 blocker ②PO만 아는 판단**뿐이다.
