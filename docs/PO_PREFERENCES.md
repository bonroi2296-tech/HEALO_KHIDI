# PO 취향·선호 누적 원장 (PO Preference Ledger)

> **이건 뭔가:** CLAUDE.md의 *고정 규칙*(말투·보안·빌드)과 **별개로**, 세션 중에 PO 지시·반응에서 **그때그때 묻어나온 취향·선호·성향**을 누적 기록하는 곳. 코드만 봐선 안 보이고, 고정 규칙으로 박기엔 아직 유동적인 것들.

>
> **고정 규칙으로 승격:** 어떤 취향이 3회 이상 반복·확정되면 CLAUDE.md(또는 훅)의 고정 규칙으로 올리고 여기선 "→ CLAUDE.md 승격"으로 표시.
>
> **군살 방지:** 「활성 취향」은 항상 짧게(훅이 매번 띄우므로). 더 이상 유효하지 않거나 고정 규칙으로 승격된 항목은 「보관(히스토리)」로 내린다.
