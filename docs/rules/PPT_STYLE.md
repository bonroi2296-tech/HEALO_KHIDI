# PPT 표준 깔 (BeyondK 톤) — 발표자료 만들 때 이 규격으로

> **트리거**: PPT·발표자료·제안서 슬라이드·피치덱을 만들 때 **무조건** 이 문서대로.
> 출처: `비욘드케이컴퍼니소개(내부_경영지원).pdf` (2026-07-31 PO 지시 — "앞으로 PPT 는 이 깔로").
> 원본에서 폰트·색·판형을 실제로 추출한 값이라 눈대중이 아니다.

---

## 0. 판형

- **960 × 540 pt = 13.333 × 7.5 in (16:9)**. python-pptx 기본 4:3 이므로 반드시 지정.
- 좌우 안전 여백 **72pt**, 상단 kicker 시작 **좌 78pt / 상 36pt**.
- 여백을 무서워하지 마라. 원본은 슬라이드 절반이 빈칸인 장이 태반이다.

## 1. 폰트

**에스코어 드림 9종 설치 완료 (2026-07-31, 상업용 무료).** 아래 이름을 그대로 써라 — 무게마다 **글꼴 이름이 따로**다(굵게 표시 대신 이름으로 무게를 고른다).

| 용도 | 쓸 글꼴 이름 | 원본 |
|---|---|---|
| 큰 제목·챕터 표지·강조 | `에스코어 드림 8 Heavy` | HG꼬딕씨 P80g / SCDream 8Heavy |
| 소제목·표 안 강조 | `에스코어 드림 7 ExtraBold` | HG꼬딕씨 P60g / SCDream 7ExtraBold |
| 표 머리행 | `에스코어 드림 5 Medium` | — |
| 본문 | `에스코어 드림 4 Regular` | HG꼬딕씨 P40g / SCDream 4Regular |
| kicker·캡션·가는 글씨 | `에스코어 드림 3 Light` | HG꼬딕씨 P20g / SCDream 3Light |

- 설치 위치: `%LOCALAPPDATA%\Microsoft\Windows\Fonts` (사용자 전용 — 관리자 권한 불필요, 지우면 그대로 되돌아감). 원본: [에스코어 글꼴나눔](https://s-core.co.kr/company/font/)
- **HG꼬딕씨는 유료**(마켓히읗 6종 묶음 99,000원)라 안 샀다. 에스코어 드림으로 대체해도 톤이 거의 같아 굳이 살 필요 없다.
- 다른 PC(외부 공유용)에서 열 때 깨지면 → PDF 로 내보내거나 그 PC에도 에스코어 드림을 깔면 된다.
- 글자 크기(원본 실측): 본문 **11~12pt**, 부제 11pt, kicker 9pt, 표 10~11pt, 제목 **24pt**, 챕터 표지 28pt.
  → **크게 키우지 마라.** 이 톤의 정체성은 "작은 글씨 + 큰 여백"이다.

## 2. 색 (원본에서 추출 — 이 밖의 색은 쓰지 마라)

| 이름 | 코드 | 쓰는 곳 |
|---|---|---|
| 먹 | `#000000` | 제목, 강조 텍스트, 챕터 표지 배경 |
| 흰 | `#FFFFFF` | 기본 배경, 챕터 표지 글자 |
| 패널 회색 | `#F2F2F2` | 본문 박스, 표 헤더행, 하단 강조 띠 |
| 선 회색 | `#DCDDDD` / `#D9D9D9` | 구분선, 표 가로선 |
| 본문 회색 | `#767171` | 서술형 본문 |
| 흐린 회색 | `#7F7F7F` | kicker, 캡션, 각주 |
| **라임(핵심 강조)** | **`#D9FE55`** | 형광펜 강조 — 슬라이드당 **1개까지** |
| 연녹 | `#E2F0D9` | 도형 채움(옅은 단계) |
| 중간녹 | `#C5E0B4` / `#A9D18E` | 도형 채움(중간 단계) |
| 진녹 | `#00B050` | 연결선·포인트 (아주 드물게) |

- 라임은 **강조 1곳**에만. 두 곳 이상 칠하면 원본 톤이 아니다.
- 그라데이션·그림자·아이콘 장식 금지. 로고 이미지 외 아이콘 거의 안 쓴다.

## 3. 슬라이드 5종 (이것만 조합해서 만든다)

**A. 표지** — 흰 배경, 정중앙. 위에 작은 회색 영문 태그라인(11pt) → 아래 큰 검정 워드마크.

**B. 챕터 표지** — 전면 **검정**, 정중앙에 흰색 굵은 영문 28pt 한 줄만. (`Business background`, `So,`, `Plz,` 처럼 짧게)

**C. 서술형(한 문단으로 설득하는 장)** — 흰 배경, 전체 가운데 정렬 + 화면 세로 중앙.
굵은 한글 제목 24pt → 그 밑에 **짧은 가로선(폭 40pt)** → 본문 12pt 회색, **핵심어만 검정 굵게**.

**D. 내용형(표·도식이 들어가는 장)** — 좌상단부터:
kicker 9pt 회색(`Who` / `What` / `How` / `ABOUT US`) → 제목 24pt 검정 → 한 줄 부제 11pt.
본문은 **`#F2F2F2` 라운드 박스(모서리 반경 10pt)** 안에 넣는다.

**E. 표** — 기본형은 **세로선 없음**. 헤더행만 `#F2F2F2` 채움, 가로선 `#DCDDDD`, 좌측 정렬, 10~11pt.
표 위 소제목은 **굵게+밑줄**. 비교형(A vs B) 표만 얇은 검정 테두리 전체 + 가운데 정렬.

**+ 하단 강조 띠** — 결론 문장은 `#F2F2F2` 밴드에 가운데 정렬 11pt, 앞에 `▶`.

## 4. 자주 틀리는 것

- ❌ 제목 40pt 이상으로 키우기 → 원본은 24pt 다.
- ❌ 색을 늘리기(파랑·주황 추가) → 위 표 밖은 금지.
- ❌ 슬라이드를 꽉 채우기 → 빈칸이 이 톤의 절반이다.
- ❌ 라임 여러 곳 칠하기 → 한 곳.
- ❌ 4:3 로 만들기 → 16:9 (13.333×7.5in) 고정.
