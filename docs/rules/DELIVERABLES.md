# PO 에게 건넬 산출물 — 만들 때 지킬 것

> **언제 읽나**: PDF·인쇄물·안내서·안건·체크리스트처럼 **PO 나 상대가 실제로 들고 쓸 물건**을 만들 때.
> 코드가 아닌 「문서를 만드는 일」 전반은 `CLAUDE.md` 트리거 표(PPT·한글문서)를 먼저 보고, 여기는 **다 만든 뒤 건네기 전**에 본다.
> 근거는 전부 2026-09-11 카자흐 출장 서류 세션의 PO 지적이다.

---

## 1. 산출물에 「내 작업 기록」을 끼워 넣지 마라

출장 안내서 PDF 에 **「검수 결과」 2쪽**(내가 뭘 틀렸고 어떤 출처에 대조했는지)을 넣었다가 PO 지적을 받았다 —
*「야 근데 검수 결과는 왜 넣은거야」*.

**PO 가 들고 나갈 물건과 내가 일한 기록은 자리가 다르다.**

- 산출물에는 **쓰는 사람이 그 자리에서 필요한 것**만 넣는다.
- 검수·대조·수정 이력은 **별도 파일**로 뺀다(예: `_작업기록(들고 갈 것 아님)` 폴더).
- 다만 **아직 안 정해진 것**은 산출물 안에 남긴다 — 현장에서 채워야 하기 때문이다.

> 「내가 헤맨 과정은 보고에 쓰지 마라」(기억 `report-result-not-your-fumbles`)의 **산출물판**이다.
> 저건 채팅에서 하지 말라는 것이고, 이건 파일에 넣지 말라는 것이다.

## 2. 안건·가이드는 「질문 목록」이지 행동 지시서가 아니다

미팅 안건에 「과장하지 않기 / ~라고 말하면 안 됩니다 / ~하십시오」를 칸으로 만들어 넣었다가 —
*「과장하지 않기 이런거 빼 임마」*.

**PO 는 그 일을 아는 사람이고, 훈계를 받으러 안건을 여는 게 아니다.**

- 쓸 형태: **「물어볼 것」**(질문 불릿) + **「손에 들고 갈 수치」**(사실만).
- 지키면 좋은 것은 말로 적지 말고 **사실 옆에 붙여라.**
  예) 「치료비를 단일값으로 말하지 마십시오」 ✗ → **치료비를 네 구간으로 적어 둔다** ✓

## 3. 숫자를 내기 전에 「바깥 출처에 대본 적 있나」를 먼저 물어라

택시비 표를 자신 있게 냈는데 *「야 근데 태깃비가 그케 싼거 맞아? 너 현지 물가를 너무 무시하는거 아냐?」*.
계산식은 맞았지만 그 값은 **「앱·평시·최저 등급」의 밑바닥**이었고 실제로는 2배였다.

🔴 **문서끼리 앞뒤가 맞는지 보는 검사는, 같은 가정이 모든 문서에 똑같이 틀려 있어도 통과한다.**

- **단일값 대신 범위**로 내라 — 최선 / 현실 / 나쁜 경우.
- **출처**와 **그 값이 어떤 조건의 값인지**를 붙여라.
- 내부 일관성 검사(`audit.py` 류)는 필요하지만 **충분하지 않다.**

## 4. 예보·추정을 확정 사실처럼 적지 마라

날씨를 국제 예보 사이트 **하나**만 보고 「낮 20~25도, 9/14 약한 비」라고 문서에 박았다.
PO 가 자기 폰을 보여주며 — *「여기엔 비예보는 없는디 니가 본거엔 있어? 어디꺼 봤니 현지 자료야?」*.
현지 기상청 보도와 PO 폰이 일치했고 **내 자료만 3도 낮고 비가 있었다.**
게다가 전날 내가 「아침 5도는 틀렸다」며 고친 값이 **원래 값이 더 맞았다.**

- 예보·추정은 **「N월 N일 시점의 예보」**로 적는다.
- **자료가 갈리면 갈린다고 적는다.** 하나만 보고 정정하지 마라.
- **현지 출처**를 우선하고, 출처를 밝힌다.
- 출발·실행 직전 **재확인하라는 문장**을 문서에 박아 둔다.

## 5. 쪽이 애매하게 넘어가지 않게 하라

*「애매하게 한장 넘어가는 애들은 좀 잘 정리해서 한장에 담기게 해봐」* · *「넘치잖니 이런데가」*

고치는 순서:

1. **여백·행간·글자 크기**를 먼저 조인다(내용은 그대로).
2. 그래도 안 되면 **다른 장과 겹치는 설명**을 덜어낸다.
3. 🛑 **손으로 쓰는 칸**(체크리스트·기록란)은 글자를 더 줄이면 못 쓴다 — 2번으로 풀어라.
   반대로 **쪽이 남으면 칸 높이를 키워** 쪽을 채우고 쓰기도 편하게 한다.

⚠️ **검사할 때 걸리는 함정 둘**

- **마지막 쪽만 재지 마라.** 중간에 빈 쪽이 생긴다(강제 쪽 나눔 `page-break-before` 가 흔한 범인이다 —
  표 앞에 걸면 **앞쪽이 통째로 빈다**. `page-break-inside: avoid` 도 **표 전체에 걸면 표가 통째로 밀린다**; 행(`tr`)에만 걸어라).
- **쪽번호를 넣은 「뒤」에 재지 마라.** 쪽번호 글자가 맨 아래에 잡혀 **전부 꽉 찬 것으로 나온다.**

```python
# 쪽 채움 재기 — 쪽번호는 빼고, 모든 쪽을 본다
import fitz, re
d = fitz.open(path)
for i, p in enumerate(d, 1):
    H, b = p.rect.height, 0
    for blk in p.get_text("blocks"):
        if re.fullmatch(r"\d+ / \d+", blk[4].strip()): continue   # 쪽번호 제외
        b = max(b, blk[3])
    for img in p.get_images(full=True):
        for r in p.get_image_rects(img[0]): b = max(b, r.y1)
    print(i, round(b / H * 100, 1))
```

## 6. 인쇄물은 배경색이 빠지지 않게

헤드리스 크롬 `--print-to-pdf` 는 기본적으로 배경을 안 그린다. 각 문서 `<style>` 맨 위에:

```css
* { -webkit-print-color-adjust: exact; print-color-adjust: exact; }
```

그림에는 **`width`·`height` 속성과 `height:auto`** 를 같이 준다 —
속성만 주면 그림이 오기 전에 자리는 잡히지만 **세로가 원본 크기로 고정돼 비율이 깨진다.**
