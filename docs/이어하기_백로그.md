아침에 **"이어하기 백로그부터 진행해줘"** 라고 하시면, 아래 순서대로 다음 개선을 이어서 진행합니다.

- [x] **offers/apply API**: 실패 시 한글 `detail` 메시지 반환 (missing_hospital_id, invalid_json, hospital_id_mismatch, hospital_not_found)

## 사용 방법

1. **아침에** "이어하기 백로그부터 진행해줘" 또는 "백로그 1번부터 해줘" 라고 입력.
2. 위 목록에서 **아직 [ ] 인 항목**을 순서대로 구현·테스트·문서 반영.
3. 한 턴에서 여러 개 적용 후, **이어하기 백로그** 문서의 체크박스를 [x]로 갱신해 두면 다음에 이어서 진행 가능.
