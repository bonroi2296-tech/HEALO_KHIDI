# HEALO / healwith — 의료정보 국제표준 준수 점검 (HIPAA · GDPR · 국내법)

> 작성: 2026-06-29 · 상태: **초안(법률자문 전)** · 단일출처와의 관계: 사실(등록번호·처리자·보관기간)은 처리방침(`src/lib/legal/privacyPolicy.js`)·RoPA(`docs/RECORDS_OF_PROCESSING.md`)를 따른다.
> 목적: "우리 서비스가 HIPAA인지 GDPR인지 의료 국제표준을 지키냐"는 질문에 **솔직하게** 답하고, 해외 파트너 계약서(`docs/marketing/agency-*`, `overseas-clinic-*`)의 컴플라이언스 근거를 제공한다.

## 0. 한 줄 요약 (PO용)

- **"HIPAA 준수"라고 말하면 안 된다.** HIPAA는 미국 법이라 우리(한국 플랫폼·CIS 환자·한국 병원)에겐 **법적으로 적용 안 됨.** 대신 "**HIPAA 수준의 보안조치**"라고 말하는 건 가능(마케팅·신뢰용).
- **GDPR도 "전면 적용"은 아님.** 우리 환자는 대부분 카자흐·러시아(=EU 거주자 아님). EU 거주자가 쓰면 그때 적용. 다만 GDPR을 **자발적 기준**으로 맞춰두면 글로벌 신뢰 + 향후 확장에 유리(이미 RoPA·침해런북·DPO 갖춤).
- **진짜 우리를 구속하는 법 = ①한국 PIPA·의료법·외국인환자유치법 ②카자흐 94-V ③러시아 152-ФЗ.** 점수표(중간평가)·계약서·실제 리스크는 전부 여기서 나온다.
- **현재 보안 토대는 탄탄**(AES-256-GCM 저장암호화·서울 리전·RLS·DPO·침해런북). **가장 큰 미결 = ①처리자 DPA 서명 ②카자흐/러시아 현지화 ③자동 파기·삭제권 집행.**

## 1. 어떤 법이 우리에게 적용되나 (적용성 판단)

| 표준/법 | 우리에게 적용? | 근거 |
|---|---|---|
| **미국 HIPAA** | **아니오(법적 미적용)** | HIPAA는 미국 "Covered Entity"(미국 의료제공자·보험자)와 그 Business Associate에만 적용. 우리는 미국 환자·미국 의료기관·미국 진료가 없음. → **"HIPAA 준수/인증" 주장 금지.** "HIPAA에 준하는 안전조치"는 가능(자발적 벤치마크). 미국 진출 시 재검토. |
| **EU GDPR** | **조건부 적용** | Art.3(2) 역외적용 — EU 거주 정보주체에게 서비스 제공 시 적용. 현재 타깃은 비EU(카자흐·러시아). **EU 거주자가 1명이라도 쓰면 그 처리에 적용.** 자발적 정렬 권장(이미 상당 부분 갖춤). |
| **한국 PIPA(개인정보보호법)** | **예(전면 적용)** | 한국 사업자가 한국에서 처리. 민감정보(건강) §23, 국외이전 §28-8, 위탁 §26 등. **핵심 구속법.** |
| **한국 의료법** | **예(부분)** | §21·§22 환자정보 보호·진료기록 보존(10년)은 **진료 의료기관** 의무. 우리는 의료기관 아님(유치업자)이라 사본 장기보유 안 함. |
| **외국인환자 유치 지원법** | **예** | 유치업자 등록(A-2026-01-02-06761)·수수료 상한·광고규제. |
| **카자흐 94-V ЗРК** | **예(환자 카자흐 시)** | 명시 동의 + **현지화(1차 저장 카자흐 영토)** 요건 가능성. → 갭(§4). |
| **러시아 152-ФЗ** | **예(환자 러시아 시)** | 러 시민 개인정보 **러시아 내 1차 저장(현지화)** 의무. → 갭(§4). |

> **결론**: "의료 국제표준 준수"를 **HIPAA/GDPR 인증으로 주장하지 말고**, "한국 PIPA·의료법을 기본으로, GDPR·HIPAA **수준의 안전조치**를 자발적으로 적용한다"로 포지셔닝. 이게 사실이고 법적으로 안전.

## 3. 해외 파트너 데이터 흐름 (계약서가 다뤄야 할 실제 경로)

- **해외 에이전시(/agency)**: 환자 식별·연락 + **민감(건강)정보**(진단명·병기·진단서·검사결과·CT/MRI 파일)를 의뢰폼으로 **healwith에 전송**. → 에이전시는 출발지 수집자(별도/공동 controller). **환자 동의 확보의 1차 책임.**
- **해외 의료기관(/clinic)**: 위 + 귀국 후 **사후관리 경과(검사·영상·소견) 업로드** = 의료데이터 **양방향**. → 자국 의료법·기록보존 주체이기도 함.
- → 두 계약서 모두 **제8조(동의 확보 보증) + 별지 A(DPA)** 로 "동의 없는 데이터 유입 차단 + 처리조건 정렬"을 명문화함.

## 5. 권고 (우선순위)

1. **표현 교정(즉시·무비용)**: 대외문구에서 "HIPAA 준수/GDPR 인증" → "한국 PIPA·의료법 준수 + HIPAA/GDPR 수준 안전조치". (과장 표시 리스크 제거)
2. **처리자 DPA 일괄 서명**(갭1) — 가장 빨리 닫히는 큰 항목.
3. **해외 파트너 계약서 변호사 검토 후 서명**(`agency-*`·`overseas-clinic-*`) — 동의 확보 책임을 파트너와 계약으로 분담.
4. **삭제권·자동파기**(갭3) — GDPR/PIPA 정보주체 권리의 코드 집행.
5. **카자흐/러시아 현지화 법률검토**(갭2) — 러 환자 비중 데이터 보고 결정.
