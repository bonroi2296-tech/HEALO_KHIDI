## 4. 측정(GA4)이 진짜 도는지 실증 + 광고 꼬리표 🔴 — **브라우저 필요**

> 먼저 `docs/KNOWN_ISSUES.md` 의 GA4 항목들을 읽어. **어제 GA4 를 대대적으로 고쳤는데(수집 요청이 보안 헤더에 막히던 구멍 · AI 상담 2배 집계 · 옛 주소 광고 출처 증발 7곳) 「진짜 신호가 나가는지」는 아무도 눈으로 못 봤다.**
> **1순위(이것부터)**: `https://healwith.co.kr/?ga_debug=1` 로 열고 쿠키 **「전체 동의」** → GA4 관리 → **DebugView**. 몇 초 안에 `page_view`·`inquiry_*` 가 뜨면 확정. **이게 유일한 실증 통로다** — 뜰 때까지 「검증됨」이라고 쓰지 마라. ⚠️ 어제 수정분은 **오늘 오후 3시 배포 창구가 나간 뒤**에 확인해야 한다(그 전엔 옛날 코드가 떠 있다).
> **2순위**: 광고 링크에 **꼬리표(UTM)** 가 붙어 있는지 확인. 없으면 GA4 가 「직접 방문」으로 뭉뚱그려 **어느 광고가 문의를 만들었는지 영영 못 본다**(지난 데이터는 소급 불가). 형식: `?utm_source=yandex&utm_medium=cpc&utm_campaign=ru_lung_2608`. **이름을 한 번 정하면 절대 바꾸지 마라**(`yandex`/`Yandex` 를 섞으면 다른 출처 2개로 센다).
> **3순위**: GA4 콘솔에서 **맞춤 측정기준(custom dimension) `platform`·`lang` 을 이벤트 범위로 1회 등록** — 안 하면 보고서에 안 뜬다. 이게 있어야 「앱에서 몇 명이 문의했나」에 답할 수 있다.
> **PO 결정 2건을 버튼으로 정리**: ①동의 모드(Consent Mode v2) 켤지 — 비교표는 `docs/GA4_SETUP.md` §5 ②얀덱스 메트리카 — 코드·보안 헤더는 이미 준비 끝이라 **카운터 번호만 받으면 1분**이다. 러시아에선 구글보다 얀덱스가 크다.
> 🚫 **함정**: 🛑 **`cancer_type`(암종) 같은 건강 값으로 「잠재고객」을 만들지 마라** — 구글·얀덱스 정책 위반이고 **계정 정지**로 이어진다. 전환 측정은 괜찮고 리타게팅만 안 된다. · 이벤트에 심어둔 해석은 **가설이지 사실이 아니다**(예: 「AI 상담 2마디에서 멈춤」은 실패일 수도 **한 번에 답을 얻은 것**일 수도 있다). 숫자만 보고 고치지 마라.

## 5. 배포 창구 잔재 정리 + 오늘 15시 실동작 확인 🟠

> **오늘의 진짜 확인**: **오후 3시 창구가 실제로 도는지.** 어제 「창구가 구조적으로 못 돈다」(본판 자물쇠가 로봇의 직접 밀어넣기를 영구 거부)를 발견해 **옆문(`production` 브랜치)** 으로 고쳤는데, **그게 실제로 배포를 한 번 내보냈는지는 아직 아무도 확인 안 했다.** 워크플로 초록 ≠ 배포됨 — **Vercel 에서 실서비스 최신 반영본이 언제 것인지 직접 봐라.**

> 🚫 **함정**: 남의 브랜치는 반드시 `git worktree add --detach` 로 격리해서 만져라 — `checkout && reset --hard` 한 줄이면 **현재 브랜치가 날아간다.**

> **① PO 손**: `E2E_HOSPITAL_EMAIL`·`E2E_HOSPITAL_PASSWORD` 를 GitHub Actions 비밀값에 등록. **등록 전까지 이 검사는 조용히 건너뛴다**(= 검사가 없는 것과 같다). 이걸 PO 에게 먼저 요청해라.
> **② 원인 미규명**: 「`hospital@test.com` 으로 로그인하면 첫 화면으로 되돌아간다」는 증상의 **원인을 아직 못 찾았다.** 한때 `hospitals.is_active=false` 를 의심했는데 **문지기(`checkHospitalAuth`)는 그 값을 안 본다** — 반증 검사에서 걸러졌다. 문지기가 보는 `hospital_users.is_active` 는 두 계정 다 `true` 다. **재현부터 해라.**
> 🚫 **함정**: 「X 가 원인이다」라고 말하기 **전에** *X 가 진짜 원인이면 무엇이 참이어야 하는가* 를 한 줄 적고 그걸 먼저 확인해라(`CLAUDE.md` 실측 5번). 어제 이 항목에서 정확히 그 검사가 오답을 걸러냈다.
