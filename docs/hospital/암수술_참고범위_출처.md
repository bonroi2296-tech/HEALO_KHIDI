# 견적 화면 「참고 범위」의 출처

**마지막 확인: 2026-08-20 · 자료 기준일: 2026-06**

## 어디서 온 숫자인가

환자 견적 요청 화면에 뜨는 암종별 참고 범위는 **협력 대학병원(이대서울·세브란스 등)
국제진료센터에 직접 문의해 받은 답변**을 정리한 것이다.

- 원본: PO 보관 문서 「면력_암진료비_안내.pdf」 (면력한방병원, 카자흐스탄 협력병원 환자 안내용, 2026-06-17)
- 코드: `src/lib/costs/surgeryRanges.ts` (숫자와 주의사항이 여기 한 곳에만 있다)

## 이 숫자의 성격 — 잘못 대조하면 오진이 난다

| | 이 자료 | 병원 홈페이지 법정 공개 비급여 가격 |
|---|---|---|
| 대상 | **외국인**(건강보험 미적용, 국제수가 전액 본인부담) | 내국인 |
| 범위 | **총비용**(입원 5~10일 + 기본 검사 + 수술료) | 항목 하나의 단가 |

**서로 대조되지 않는다.** 2026-08-20 에 실제로 잘못 비교한 적이 있다: 세브란스 갑상선 로봇수술
「700만원」(항목 단가)과 이 자료의 「1,500~2,500만원」(총비용)을 나란히 놓고 *"2~3배 틀렸다"*
고 판단했는데, 애초에 다른 자였다.

병기별로 나뉘지 않는다. 병원도 병기별 확정가를 주지 못한다(암 치료엔 정찰가가 없다).
병원 답변 자체가 *「외국인 대상이라 애매한데 대충 이 정도」* 수준이며, 그것이 이 시장의 실상이다.

## 화면에서 지키는 것

- 「참고 범위(외국인 환자 기준)」라는 제목으로만 노출한다. 견적서라고 부르지 않는다.
- 포함 항목·변동 요인·출처·기준일(`SOURCE_DATE`)을 **항상 같이** 띄운다.
- *"최종 금액은 병원이 발급하는 정식 견적서로 확정됩니다"* 를 붙인다.
- 자료에 없는 암종(기타)은 **상자 자체를 띄우지 않는다.** 빈 값을 지어내지 않는다.

근거: 유치사업자는 「거짓 정보 제공」이 법으로 금지된다(의료해외진출법). 범위임을 밝히고
출처를 대는 것은 거짓이 아니지만, 확정가처럼 보이게 하는 순간 위반이 된다.

## 갱신

병원 구두 답변 기반이라 시간이 지나면 낡는다. **6개월마다 다시 물어 `SOURCE_DATE` 와 함께 갱신**한다.
다음 갱신 목표: 2026-12.
