healwith

## 5. 반론대응 FAQ (콜에서 자주 나올 질문)

| 에이전시가 묻는 것 | 우리 답 |
|---|---|
| "기존에 거래하는 한국 병원 있는데?" | 우리는 병원이 아니라 **컨시어지** — 통역·원격 사전상담·견적·사후관리를 대행. 기존 병원 거래와 병행 가능. 오히려 응답 느린 병원 대신 협진 4개 상급종합으로 빠른 케어경로. |
| "수수료 얼마?" | healwith 유치수수료의 **30~50%를 에이전시에 분배(협의 가능)**. 유치 확정 시 절반, 치료 완료 시 절반 지급. 첫 건은 소액 고정으로 신뢰 먼저. |
| "결제는 어떻게?" | 러시아 직접결제 이슈는 병원 직접청구 + 카자흐 허브로 처리. 환자 결제 부담 우리가 안내. |
| "정말 환자 케어 잘 되나?" | 사전 영상상담→견적→비자→치료→사후관리까지 **포털에서 단계별 실시간 확인**. 데모 링크 제공(아래). |
| "한방치료가 암에 효과 있냐?" | **(레드라인 준수)** 한방은 암 "치료/완치"가 아니라 **면역지원·부작용 관리·재활(삶의 질)** 보조. 수술·항암은 상급종합병원 담당. 절대 과장 금지. |
| "우리 환자 정보 안전한가?" | 환자 PII는 AES-256 암호화·한국 리전 저장. 동의 기반 최소 정보만. |
