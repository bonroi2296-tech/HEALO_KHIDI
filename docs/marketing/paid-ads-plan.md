## 2. 캠페인 구조 (추천)
- **캠페인 1 (Google Ads, KZ)**: 지역=Казахстан, 언어 RU+KK. 위 ⭐⭐⭐ 키워드. 랜딩=러시아어 암치료 가이드(가격 캘큘레이터 포함).
- **캠페인 2 (Yandex Direct, RU)**: 지역=Россия(+CIS). 같은 키워드. 랜딩=`/ru/for-russian-patients`.
- **공통 랜딩 원칙**: "무료 러시아어 상담" CTA + **가격대("부터" 범위) 노출** + 환자 스토리/의사 영상(전환 1등 요소).

## 5. 측정·평가 연결
- 모든 광고 랜딩 CTA → `/inquiry` 폼 → `inquiries` 적재 → `/admin/khidi/conversion`·`kpi-dashboard`에서 유치/상담 카운트.
- UTM 파라미터로 채널별 유입 추적 권장(google/yandex/ig 구분).
- **리드가 곧 KHIDI 사전상담 증빙** + 유치 전환 시 ④성과지표 직결.
