## 1. 병원에 보낼 본문

안녕하세요, 힐위드(본로이)입니다.

한국보건산업진흥원 지원사업으로 진행 중인 **러시아·카자흐스탄 암환자 대상 협력병원 소개 영상**을
제작합니다. 강서점 촬영 협조를 부탁드리고자 내용을 정리해 보내드립니다.

### 1-1. 촬영 개요

| | |
|---|---|
| 일시 | **다음 주 중 병원이 지정하시는 1일, 2시간** (진료가 한가한 시간대 희망) |
| 장소 | 면력한방병원 강서점 (열린프라자 6·7·10층) |
| 인원 | 촬영팀 + 본로이 3명 + 모델 1명 |
| 장비 | 카메라 2대 · 무선 마이크 · 소형 조명 (드론 · 레일 · 대형 조명 없음) |
| 병원 부담 | 콘센트, 소규모 대기 공간, 동행 담당자 1명 |
| 언어 | 한국어 촬영 → 러시아어 자막 |

영상에는 **치료 효과 · 완치율 · 타 병원 비교 표현을 넣지 않습니다.** 국내 광고물이 아니라
해외 환자 안내용 콘텐츠입니다.

### 1-2. 찍고 싶은 4장면과 필요한 분

| 장면 | 필요한 분 | 장소 | 시간 |
|---|---|---|---|
| ① 원장님이 해외 환자와 **화상으로 상담**하는 모습 (코디네이터 동석) | 원장님 · 코디 | 원장실·상담실 | 20분 |
| ② 원장님이 **해외 환자 문의 자료를 화면으로 검토**하는 모습 | 원장님 | 진료실(모니터) | 15분 |
| ③ 모델이 **접수부터 진료·치료 체험까지** 도는 동선 | 접수 1 · 간호사 1 · 원장님 | 6층 접수 → 진료실 → 치료실 | 55분 |
| ④ **원장님 인터뷰** (질문 6개, 미리 전달) | 원장님 | 조용한 방 | 25분 |

①②는 같은 방에서 이어 찍으면 이동 시간을 줄일 수 있습니다.

### 1-3. ③번 체험 동선 — 가능한 것에 O만 표시해 주시면 그대로 맞춥니다

**접수 · 진료**
- ( ) 6층 엘리베이터에서 내려 병원으로 들어오는 컷
- ( ) 접수 데스크에서 코디네이터가 통역하며 접수 *(접수 담당자 1분 필요)*
- ( ) 대기 공간에 앉아 대기
- ( ) 진료실에서 원장님 상담
- ( ) 간호사가 치료실로 안내
- ( ) 층 이동 동선 — 6 · 7 · 10층 중 **어느 층에서 어떤 촬영이 가능한지** 알려주십시오

**검사 · 치료** *(강서점 실제 운영 항목 기준)*
- ( ) 혈액검사(채혈) 준비 · 장비 컷
- ( ) **고주파 온열암치료** — 치료실 장비
- ( ) 적외선 온열요법
- ( ) 주사·수액 치료 *(약제 이름은 화면에 나오지 않게 처리합니다)*
- ( ) 림프 도수치료 · 침전기물리치료 *(치료사 1분 필요)*
- ( ) 침치료

**입원 · 회복 공간**
- ( ) **VIP 입원실 공실 1곳** — 모션베드 · 안마의자
- ( ) 다인 입원실 공실
- ( ) 힐링 공간(휴게 라운지)
- ( ) 그 밖에 **강서점에서 보여주고 싶은 공간**이 있으면 알려주십시오 (저희가 모르는 곳이 있을 수 있습니다)

**식사 · 영양**
- ( ) **임상영양사 치료식 1인분** 세팅 컷 + 모델이 식사하는 컷
- ( ) 임상영양사님 짧은 코멘트 (3분)
- ( ) 치료식 전담 셰프 조리 컷 *(셰프 푸드테라피 일정과 겹치면 그날로 맞추겠습니다)*

> **한 가지 여쭙습니다.** 촬영 모델은 실제 환자가 아니므로 ① **실제로 검사·치료를 받게 해도 되는지**
> ② 아니면 **장비 앞에 앉은 연출 컷까지만** 할지 병원 방침을 알려주십시오. 실제 체험이 가능하다면
> 비용 처리 방식도 알려주시는 대로 따르겠습니다.

### 1-4. 인터뷰 질문 6개 (원장님 사전 검토용 — 조정 의견 주시면 반영)

1. 원장님과 강서 본원을 소개해 주십시오. (한방·양방 협진 의료진 8명, 누적 5만 사례)
2. 면력한방병원의 **ITCRN 5원칙**(면역 · 체온 · 순환 · 저항성 · 영양)은 환자에게 실제로 어떻게 적용됩니까?
3. 해외 환자에게는 **양·한방 협진**이 생소합니다. 대학병원의 수술·항암 치료와 한방 면역치료가 어떻게 이어집니까?
   (강서 본원이 **이대서울병원과 도보 1분** 거리라는 점도 함께 말씀해 주시면 좋겠습니다)
4. 항암·방사선 치료 중 환자분들이 가장 힘들어하시는 부분은 무엇이고, 그 시기를 어떻게 관리하십니까?
5. **의료진 + 임상영양사 + 전담 셰프**의 3축 협진은 실제로 어떻게 돌아갑니까? 입원 중 하루 일과와 함께 설명 부탁드립니다.
6. 귀국 후 관리는 어떻게 이어질 수 있습니까? 한국 치료를 고민하는 해외 환자와 가족에게 한 말씀 부탁드립니다.

### 1-5. 촬영 전에 저희가 미리 드릴 것

- **인터뷰 질문 6개** (위와 동일)
- **해외 환자 문의 자료 1건** — ②번 촬영용. **촬영 3일 전까지** 전달드립니다. 원장님이 미리 보신 상태에서
  촬영하면 화면 검토 장면이 자연스럽고, 소견 의견도 그날 함께 받을 수 있습니다.
- 2시간 진행표 (분 단위)

### 1-6. 저희가 지키는 것

- **환자·보호자분은 촬영하지 않습니다.** 화면에 들어오시면 즉시 중단하고 해당 부분을 삭제합니다.
- 병원이 지정하신 시간대에만, 동행 담당자와 함께 이동합니다.
- 병원 감염관리 · 복장 지침을 따릅니다.
- **최종 편집본은 공개 전 병원 확인을 받습니다.**
- 병원 요청 시 3영업일 내 모든 채널에서 삭제 · 수정합니다.
- 병원 명칭 · 로고 사용은 병원 지침에 따르며, 타 의료기관 촬영분과 한 영상에 섞지 않습니다.

### 1-7. 회신 부탁드릴 5가지

1. 촬영 가능한 **날짜 · 시간대** (다음 주 중 1일, 2시간)
2. 인터뷰 **원장님 확정** + 질문 6개 검토 의견
3. **1-3 항목 O 표시** (특히 실제 검사·치료 촬영 가능 여부, 층별 촬영 가능 범위)
4. 협조 가능한 **인력** — 접수 · 간호사 · 치료사 · 임상영양사 · 셰프 / 동행 담당자
5. **이대서울병원 촬영과 같은 날로 묶어도 될지** (도보 1분이라 이동 부담이 없습니다)
