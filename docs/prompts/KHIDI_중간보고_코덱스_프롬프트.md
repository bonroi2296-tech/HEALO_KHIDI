1. **이 프롬프트에 없는 숫자·성과·기관명·날짜를 지어내지 마라.** 필요한데 없으면 본문에 `[확인 필요: 무엇]` 이라고 적고 비워라. 빈칸이 있는 초안은 쓸 수 있지만, 지어낸 숫자가 하나라도 있으면 전체를 못 쓴다.
2. **0 은 0 으로 써라.** 아래 성과지표 실측에는 0 이 여럿 있다. 0 을 「진행 중」·「준비 완료」·「다수」 같은 말로 바꾸지 마라. 정부 과제 평가위원은 원자료를 요구할 수 있고, 회계검토가 별도로 돌아간다.
3. **추정치에는 「추정」이라고 붙여라.** 특히 개발 가치 환산액.
4. 문서 언어는 **한국어**. 평가위원은 한국인 의료·ICT 전문가다.
5. 이 사업은 **아직 진행 중**이다. 완료형으로 쓰면 거짓이 되는 항목이 있으니 시제를 구분해라.

### 4-2. 구축된 기능

- **AI 상담 챗봇** — 3단계 RAG(검색증강생성) 구조. 모델 Google Gemini.
- **원격협진 화상상담** — WebRTC(LiveKit). 계정 없이 들어오는 게스트 초대링크·QR·다자 통화·대기실·리마인더.

- **통합 문의 퍼널** — 웹폼 + AI챗 + 메신저 4채널(WhatsApp·Telegram·WeChat·LINE).
- **관리자 시스템** — 5종 권한(관리자·코디네이터·병원·에이전시·환자), 상담관리·회원관리·RAG 관리·AI 품질 관리.
- **성과지표 자동 대시보드** — 위 §3 의 K-01·K-02·K-04 를 시스템이 자동 집계한다. 유치 전환 깔때기 화면(`/admin/khidi/conversion`)에서 실시간 확인 가능.
- **보안·개인정보** — 환자 개인정보 AES-256-GCM 암호화, 전 테이블 RLS(행 수준 접근제어), API 오류 메시지 노출 차단.
- **AI 품질 자동 채점** — 매일 자동으로 AI 응답의 환각(사실 조작)·안전 위반을 채점하고 응답시간 P95 를 기록하는 시스템이 돌고 있다.
- **모바일 앱** — iOS·Android 빌드.
