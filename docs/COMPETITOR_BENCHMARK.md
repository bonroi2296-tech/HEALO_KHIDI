## 3. 1·2위 대비 격차 TOP — 고치면 점수 가장 많이 오르는 순

1. **검증된 환자 후기 시스템** (신뢰 +, care-journey +): 동의 기반 실환자 후기 + 결과/별점. **단, `/stories`는 2026-05 피벗 때 의도적으로 끈 것 → 재활성화는 전략적 PO 결정.**
2. **병원·의사 신뢰 점수/배지** (신뢰 +): 보유 데이터로 Qunoscore류 투명 지표·자격 배지 노출.
3. **가격 투명성 + "무료·비구속" 프레이밍** (inquiry +): 퍼널·홈에 "상담 무료·언제든 취소" 명시 + 가격대 안내.
4. **인증 배지 노출** (신뢰 +): `certifications` 필드를 JCI·유치등록증 등 배지로 실제 전시.
5. **Human 채널 "준비 중" 해소** (inquiry +): env 연결해 실가동하거나, 미설정이면 깔끔히 숨김(미완성 인상 제거).
6. **care-journey 회복톤 실사진** (care-journey +): PO 선호 톤의 실사진 보강.

> **주의(우리 작업 계약):** 위 1~6은 대부분 **화면에 보이는 변경(UI)** → 바로 구현하지 않고 **제안 + 프리뷰(preview) URL로 먼저 보여주고 PO OK 후 반영**. 특히 1번(스토리 재활성)은 피벗 방향과 얽혀 **PO 전략 결정 필요**.
