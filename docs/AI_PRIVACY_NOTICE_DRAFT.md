# AI 채팅 개인정보 고지 문구 초안 (PO 검토용 — 미적용)

> 근거: 개인정보보호위 「생성형 AI 개발·활용 개인정보 처리 안내서」(2025.8) — SaaS LLM 사용 시
> 국외 이전 고지 필요. 우리 AI 채팅은 입력 내용을 Google Gemini(국외 서버)로 전송함.
> **법무 뉘앙스가 있어 PO 확인 후 적용** (적용 작업 반나절: 처리방침 1단락 + 채팅 진입 동의 1줄).

## 채팅 시작 화면에 추가할 안내 (6개 언어 번역 필요)
"상담 내용은 답변 생성을 위해 Google의 AI 서비스(해외 서버)로 전송·처리됩니다.
민감한 개인정보(주민번호, 여권번호 등)는 입력하지 마세요. [개인정보 처리방침]"

## 개인정보 처리방침에 추가할 단락
"제O조 (AI 서비스 이용에 따른 개인정보의 국외 이전)
회사는 AI 상담 서비스 제공을 위해 이용자가 채팅에 입력한 내용을 Google LLC 의
생성형 AI 서비스(Gemini API)로 전송합니다.
- 이전되는 항목: 채팅 입력 내용(이용자가 작성한 텍스트)
- 이전 국가: 미국 등 Google 데이터센터 소재국 / 이전 일시·방법: 채팅 이용 시 네트워크 전송
- 이용 목적: AI 응답 생성 / 보유 기간: Google 정책에 따름 (모델 학습에 미사용 — API 약관 기준)
- 환자 식별정보(이름·연락처)는 AI 전송 대상에서 분리·암호화 보관됩니다."

## 함께 확인할 것
- Google Gemini API 데이터 사용 약관 최신본 (학습 미사용 조항)
- 채팅 신원 폼의 기존 안내 문구와 톤 통일
