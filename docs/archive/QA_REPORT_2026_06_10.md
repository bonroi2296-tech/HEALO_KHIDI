## 1. 원격협진 게스트 경로 — 버그 연쇄 (전부 수정·배포됨)

기본 플로우가 "계정 없이 초대링크로 입장"인데, **이 경로를 처음부터 끝까지 실제로 돌려본 적이 없어서** 게스트 전제로는 곳곳이 막혀 있었음. 실기기 테스트로 줄줄이 발견:

| PR | 문제 | 수정 |
|---|---|---|
| #3 | 번역 자막이 Chrome 전용(Web Speech) | 수동입력 폴백 + 이메일 발송 정직표기 |
| #4 | 게스트 입장 시 500 크래시 | 헤더의 `consultation` null 참조 가드 |
| #5 | 게스트 의사에게 승인 버튼 안 뜸 | admissions API `X-Guest-Token` 허용 |
| #6 | 같은 링크 2대 입장 시 서로 끊김 | guest-join identity 에 난수 suffix |
| #6 | 컨트롤 옵션 과다 | ControlBar→TrackToggle, 기기선택 제거 |
| #7 | 링크 사용횟수 3·5회로 금방 잠김 | 기본 20회 (재접속마다 1회 차감 구조) |
| #8 | 게스트 번역 API 401 | translate-realtime `X-Guest-Token` 허용 |
| #9 | 게스트 채팅·종료·파일·번역기록 6곳 401 | `resolveConsultationActor` 공용 헬퍼로 일괄 |
| #10 | 모바일 헤더 2줄·대기실 글자겹침 | 대기실 단순화 + 헤더 한 줄 |
| #11 | 인앱브라우저 음성 죽음·업로드 버튼 없음 | 탈출 버튼 + STT 실패 안내 + 첨부 UI 신설 |
| #12 | 삼성인터넷 음성 무음 사망 | STT 실패 감지 휴리스틱 + 안내 |
| #13 | "어디서든" 음성 자막 안 됨 | **서버사이드 STT(Gemini)** — 브라우저 무관 |
| #14 | 무료 플랜 분당 한도 초과 위험 | 무음 스킵(VAD) — 호출 50~70% 감소 |

**핵심 산출물:**
- `resolveConsultationActor(request, consultationId, {requireRole})` — 계정(Bearer/쿠키) **또는** 게스트(`X-Guest-Token` 읽기전용 검증+레이트리밋) 통합 인증. consultation 하위 API 전부 이걸로 통일.
- 서버 STT: `POST /api/khidi/consultation/[id]/stt` — 4초 오디오 조각을 Gemini 전사. 크롬 외 브라우저 + 카자흐어 음성 커버. 클라가 브라우저 STT 실패 감지 시 MediaRecorder+VAD 로 자동 전환.
- 음성 자막 3중 안전망: 크롬=브라우저STT / 그외=서버STT / 마이크거부=타이핑.
