## 🚀 테스트 시나리오

### 1. 수신자 0명 → 첫 추가
```
1. /admin/settings/notifications 접속
2. ✅ "등록된 수신자가 없습니다" Empty State 표시
3. ✅ 우측 상단 "+ 수신자 추가" 버튼 보임
4. "첫 번째 수신자 추가하기" 또는 우측 버튼 클릭
5. 폼 입력:
   - 이름: 김철수
   - 채널: SMS
   - 전화번호: +821012345678
   - 활성화: 체크
6. "추가" 클릭
7. ✅ Toast: "✓ 수신자가 추가되었습니다"
8. ✅ 테이블에 즉시 표시
```

### 2. 수정
```
1. 행의 "수정" 버튼 클릭
2. ✅ 이름 필드 → input으로 변경
3. 이름 수정: "김철수" → "김철수 (운영팀)"
4. "저장" 클릭
5. ✅ Toast: "✓ 수정되었습니다"
6. ✅ 리스트 갱신
```

### 3. 활성 토글
```
1. "활성" 버튼 클릭
2. ✅ Toast: "✓ 상태가 변경되었습니다"
3. ✅ "비활성"으로 변경
```

### 4. 삭제
```
1. "삭제" 버튼 클릭
2. 확인 대화상자
3. ✅ Toast: "✓ 삭제되었습니다"
4. ✅ 리스트에서 제거 (is_active = false)
```

### 5. 테스트 발송
```
1. 개별: "테스트" 버튼 클릭
```
