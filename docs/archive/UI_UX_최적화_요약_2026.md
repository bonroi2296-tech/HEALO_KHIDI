# UI/UX 최적화 요약 (데스크탑·모바일)

> 적용일: 2026년  
> 대상: 사용자(고객) · 병원관리자(파트너) · 어드민 전 영역

---

## 1. 글로벌·레이아웃

- **safe-area:** 노치·홈 인디케이터가 있는 기기에서 콘텐츠가 잘리지 않도록 `pt-safe-area`, `pb-safe-area` 적용
  - 헤더(사용자·포털 상단바), 푸터, 모바일 하단 네비, 플로팅 문의 버튼, 포털 사이드바 하단
- **최소 높이:** `min-h-screen-safe`로 세로 스크롤 시 하단 safe area 반영
- **스크롤:** `.overflow-y-auto`에 `-webkit-overflow-scrolling: touch` 적용해 모바일에서 스크롤 부드럽게

---

## 2. 사용자(고객) 영역

- **헤더:** 상단 `pt-safe-area` 추가, 모바일 메뉴에 **무료 견적(CTA)** 버튼 추가, 메뉴 항목 터치 영역 `min-h-[44px]`
- **메인:** 하단 여백 `pb-24 pb-safe-area`로 하단 네비·safe area 확보
- **푸터:** `pt-safe-area`, 모바일에서 패딩·법인 정보 `break-words`로 가독성 개선
- **모바일 하단 네비:** 기존 `pb-safe-area` 유지
- **플로팅 문의 버튼:** 모바일에서 `bottom-20`으로 하단 네비와 겹치지 않게, `right-4`, `pb-safe-area`, 터치 타겟 56px
- **리스트(시술/병원):** 태그 칩·더보기 버튼 터치 영역 확대(`min-h-[44px]`), 리스트 하단 `mb-20 pb-safe-area`

---

## 3. 병원관리자(파트너) 영역

- **레이아웃:** `min-h-screen-safe`, 메인 `overflow-auto`, 콘텐츠 `max-w-6xl mx-auto`로 정렬
- **사이드바(HospitalNav):** 로그아웃 버튼 `min-h-[44px]`, 네비 링크 `min-h-[44px]`, 하단 `pb-safe-area`

---

## 4. 어드민 영역

- **레이아웃:** `min-h-screen-safe`
- **AdminNav:** 로그아웃·메뉴 링크 모바일에서 `min-h-[44px]`, 사이드바 하단 `pb-safe-area`
- **대시보드:** 퀵 링크 카드 모바일에서 `min-h-[100px]`~`min-h-[120px]`로 터치하기 쉽게

---

## 5. 공통·접근성

- **터치 타겟:** 모바일(768px 이하)에서 버튼·링크 최소 44px 유지 (기존 `index.css` 규칙 + 필요한 곳에 `min-h-[44px]`, `touch-target` 적용)
- **로그인:** `min-h-screen-safe`, `py-8`, `pb-safe-area`로 스크롤·하단 여백 확보

---
