# healwith 서비스 이해 매뉴얼 (대표님용)

> **대상:** 개발을 배우지 않으신 대표님  
> **목적:** healwith가 무엇을 하는 서비스인지, 어떤 화면들이 있고 어떤 가치를 내는지 이해하기 위함  
> **표기:** 가능한 한글 사용, 전문 용어는 괄호로 보조 설명

---

## 1. healwith가 뭔가요?

**healwith**는 **한국 의료관광·해외 환자**와 **한국 병원**을 이어 주는 **플랫폼**입니다.

- **고객(해외 환자)**  
  한국에서 받고 싶은 시술·병원을 검색하고, AI 상담을 한 뒤, **한 번의 문의**로 여러 병원에 견적을 요청할 수 있습니다.
- **병원(제휴 병원)**  
  healwith를 통해 **리드(문의/견적 요청)**를 받고, 응답·전환을 한 화면에서 관리합니다.
- **우리(운영)**  
  관리자 화면에서 문의·리드·병원·시술·AI 지식·알림·감사 로그까지 한 번에 관리합니다.

즉, **고객이 편하게 문의하고, 병원이 품질 좋은 리드를 받고, 우리가 효율적으로 운영**할 수 있게 하는 서비스입니다.

---

## 2. 서비스 구성 한눈에 보기

```
[고객]  →  메인/검색/병원·시술 상세  →  AI 상담 + 문의 제출  →  [병원] 리드 수신·관리
                ↑                                    ↑
                └── 우리가 등록·관리하는 병원·시술 데이터   └── 우리가 관리하는 문의·리드·알림
```

- **앞단(고객이 보는 것):** 메인, 병원/시술 검색·상세, 문의·상담 페이지  
- **병원 전용:** 파트너 로그인 → 대시보드, 리드 관리, 시술 관리, 프로필  
- **우리 전용:** 관리자 로그인 → 대시보드, 문의/리드/병원/시술/데이터/자동화/설정 등

---

## 3. 고객이 보는 화면 (앞단)

### 3.1 메인(홈) 페이지

- **역할:** 사이트 첫 화면. “한국 의료 컨시어지” 이미지를 주고, 바로 다음 단계로 갈 수 있게 합니다.
- **내용:**  
  - 추천 시술 몇 개  
  - 병원 목록(제휴 병원 강조 가능)  
  - 언어 선택(영어, 한국어, 중국어, 일본어 등)
- **대표님이 알면 좋은 점:** 여기 나오는 병원·시술은 모두 **관리자에서 “공개”로 설정한 것만** 보입니다. 숨기면 고객에게 안 보입니다.

### 3.2 병원·시술 검색 및 상세

- **역할:** 고객이 “어떤 병원이 있는지”, “이 시술은 얼마쯤 하나?”를 볼 수 있는 곳입니다.
- **내용:**  
  - 병원 목록/상세: 이름, 위치, 소개, 이미지, 운영 시간, 의료진 요약 등  
  - 시술 목록/상세: 시술명, 설명, 가격대, 소요 시간, 어떤 병원이 하는지 등  
- **대표님이 알면 좋은 점:**  
  - 병원·시술 정보는 **관리자 > 병원관리, 시술관리**에서 넣고 수정합니다.  
  - **“대표 시술 3개 자동 생성”** 기능으로 병원 웹사이트에서 시술 정보를 자동으로 가져와 채울 수 있어, 입력 작업을 줄일 수 있습니다.

### 3.3 문의·상담 페이지

- **역할:** 고객이 AI와 대화하고, 원하는 병원을 골라 문의(견적 요청)를 제출하는 곳입니다.
- **내용:**  
  - **AI 챗봇:** “이런 시술 있어요?”, “이 병원 어때요?” 같은 질문에, 우리가 등록한 병원·시술 정보를 바탕으로 답합니다.  
  - **문의 폼:** 이름, 이메일, 국적, 희망 시술, 희망 일정, 메시지 등을 입력하고, 병원을 선택해 제출합니다.  
- **대표님이 알면 좋은 점:**  
  - AI가 “어떤 내용을 참고해 답하는지”는 **RAG(지식 저장소)·플레이북(응대 패턴)**으로 관리합니다.  
  - 문의가 들어오면 **관리자 > 문의관리**에 쌓이고, 선택한 병원에는 **리드**로 전달됩니다.

---

## 4. 병원(파트너)이 보는 화면

### 4.1 파트너 대시보드

- **역할:** 제휴 병원이 로그인했을 때 처음 보는 요약 화면입니다.
- **내용:**  
  - 오늘/이번 주 문의(리드) 수  
  - 최근 리드 목록(누가, 어떤 시술로, 언제 문의했는지 등)  
- **대표님이 알면 좋은 점:** “우리 플랫폼에서 병원이 리드를 한눈에 본다”는 것을 설명할 때 쓰면 좋습니다.

### 4.2 리드 관리

- **역할:** 이 병원에 온 문의(리드)를 상태별로 보고, 응답·후속 관리하는 곳입니다.
- **내용:**  
  - 리드 목록: 고객명, 시술, 연락처, 상태(대기/전송됨/조회됨/응답함/전환/거절/만료 등)  
  - 상태를 바꾸거나, 메모·후속 작업  
- **대표님이 알면 좋은 점:** “전달됨 → 병원이 열람 → 응답 → 전환” 같은 **파이프라인**을 한 화면에서 관리한다는 메시지를 줄 수 있습니다.

### 4.3 시술 관리·프로필

- **역할:** 이 병원이 제공하는 시술을 등록·수정하고, 병원 프로필을 관리하는 곳입니다.
- **내용:**  
  - 시술 이름, 가격대, 설명, 이미지 등  
  - 병원 프로필(주소, 연락처, 소개 등)  
- **대표님이 알면 좋은 점:**  
  - 여기서 수정한 시술 정보는 **고객이 보는 시술 상세**에 그대로 반영됩니다.  
  - 관리자 쪽 **“대표 시술 3개 자동 생성”**으로 병원 웹사이트에서 가져온 데이터를 여기와 연동해 쓸 수 있습니다.

---

## 5. 우리(운영)가 쓰는 관리자 화면

관리자 메뉴는 **운영 / 데이터 관리 / 분석·도구 / 시스템**처럼 그룹으로 나뉘어 있습니다. 대표님이 “우리 서비스가 뭘 할 수 있는지”만 이해하시면 될 수준으로만 정리했습니다.

### 5.1 운영

- **대시보드:** 요약 수치·최근 문의 등 한눈에 보기  
- **문의관리:** 고객이 제출한 문의 전체 목록, 상태, 배정, 메모  
- **리드관리:** 병원별 리드, 상태(대기/전송/조회/응답/전환 등), 배정·재배정  

→ “고객 문의가 들어오면 여기서 보고, 병원에 리드로 넘기고, 전환까지 추적한다”라고 이해하시면 됩니다.

### 5.2 데이터 관리

- **병원관리:** 병원 추가·수정·삭제, 공개/비공개, 제휴 여부, **대표 시술 3개 자동 생성** 버튼  
- **시술관리:** 시술 추가·수정·삭제, 병원과 연결, 가격·설명·이미지  
- **대량 Import:** 엑셀 등으로 병원·시술을 한 번에 넣기  
- **데이터 보강:** 병원 정보를 외부 데이터(지도, 리뷰 등)로 보강  
- **데이터 크롤링:** 병원 웹사이트 등에서 정보 수집 (시술 자동 생성과 연계 가능)  
- **크롤링 파이프라인/리뷰:** 크롤링 작업·결과 관리  

→ “고객이 보는 병원·시술 정보는 전부 여기서 채우고, 자동화(자동 생성·크롤링·보강)로 입력 비용을 줄인다”라고 보시면 됩니다.

### 5.3 분석·도구

- **문의 현황:** 문의·리드 통계, 추이  
- **RAG 관리 / RAG 문서:** AI가 답할 때 참고하는 “지식”을 등록·수정·삭제  
- **플레이북 / 응대 패턴 / 패턴 분석:** AI 응답 스타일·패턴 관리, 효과 분석  
- **자동화:** 플레이북·RAG 기반 자동 응답·개선  

→ “AI가 뭘 참고해서 답하는지, 어떤 패턴으로 답하는지를 우리가 관리하고, 자동화로 품질·효율을 높인다”라고 이해하시면 됩니다.

### 5.4 시스템

- **감사 로그:** 누가, 언제, 어떤 관리자 기능을 썼는지 기록 (보안·감사용)  
- **알림 관리:** 문의·리드 등 이벤트 시 이메일 등 알림 설정  
- **브랜딩 설정:** 로고, 메인 배경 등 사이트 노출 요소 설정  

→ “보안·감사·알림·브랜딩을 한 곳에서 관리한다”라고 보시면 됩니다.

## 6. 중요한 개념만 짧게

| 용어 | 의미 (쉽게) |
|------|----------------|
| **리드** | 고객이 특정 병원에 보낸 “문의/견적 요청” 한 건. 병원이 후속 상담·예약으로 이어가면 “전환”으로 볼 수 있음. |
| **제휴 병원** | healwith와 계약해 리드를 받고, 대시보드·리드 관리·시술 관리를 쓰는 병원. |
| **RAG** | AI가 “이런 질문에는 이렇게 답해라”라고 참고하는 지식/문서 모음. 관리자가 등록·수정함. |
| **플레이북** | “이런 상황에는 이런 응대 패턴을 써라” 같은 규칙·패턴. AI 응답 품질·일관성 관리에 사용. |
| **대표 시술 3개 자동 생성** | 병원 웹사이트 주소를 기준으로, 그 병원의 대표 시술 최대 3개를 자동으로 추출해 시술 데이터로 넣어 주는 기능. 입력 작업 감소용. |
| **감사 로그** | 관리자가 누가 언제 무엇을 했는지 기록. 보안·감사·문제 추적용. |

## 7. 대표님이 투자자에게 말할 때 강조할 수 있는 점

1. **고객:** 한 번의 문의로 여러 병원 견적 요청 + AI 24시간 1차 상담.  
2. **병원:** 품질 좋은 해외 리드 수신, 리드·전환 관리, 시술 정보 자동 수집으로 입력 부담 감소.  
3. **운영:** 문의·리드·병원·시술·AI 지식·자동화·감사까지 하나의 플랫폼에서 관리 → 인력·비용 절감과 확장 가능성.
