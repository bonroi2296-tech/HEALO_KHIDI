# 한글 자막 지우개 (`clean_subtitles.py`)

이미지·영상에 **구워진 한글 자막만 걷어내고 「깨끗한 원본」으로 되돌린다.** 다른 문구로 갈아끼우는 것도 된다.
러시아어·카자흐어 소재를 만들 때 한국 원본에서 한글 자막만 빼고 재가공하는 용도.

---

## 30초 요약

| 상황 | 결과 |
|---|---|
| 자막 파일이 따로 있는 영상(소프트섭) | **완벽.** 트랙만 빼면 원본 그대로 (`--check` 가 알려준다) |
| 화면에 구워진 자막(하드섭), 배경이 안 움직이는 영상 | **거의 완벽.** 다른 시점의 「진짜 배경」을 그대로 빌려와 메운다 |
| 하드섭 이미지 1장, 배경이 단순(단색·흐림·하늘) | **거의 완벽** |
| 하드섭 이미지 1장, 배경이 복잡(얼굴·무늬·글씨 위) | **웬만큼.** 없는 정보를 지어내는 거라 자세히 보면 티가 난다 |
| 자막이 사람 얼굴·간판 글씨를 완전히 덮고 있음 | **복원 불가.** 가려진 건 원본에 아예 없는 정보다 |

pip install -r scripts/subtitle-clean/requirements.txt

## 쓰는 법

```bash
cd scripts/subtitle-clean

# 0) 영상이 「구워진 자막」인지 「자막 파일」인지 먼저 판정 — 후자면 이 도구 필요 없다
python3 clean_subtitles.py 입력.mp4 --check

# 1) 어디를 자막으로 봤는지 눈으로 먼저 확인 (빨갛게 칠해서 보여준다)
python3 clean_subtitles.py 입력.jpg --mode preview -o 미리보기.jpg

# 2) 자막만 지우기
python3 clean_subtitles.py 입력.jpg -o 원본.jpg
python3 clean_subtitles.py 입력.mp4 -o 원본.mp4 --progress

# 3) 배경이 복잡하면 딥러닝 복원
python3 clean_subtitles.py 입력.jpg -o 원본.jpg --method lama

# 4) 지우고 새 문구 얹기
python3 clean_subtitles.py 입력.jpg --mode replace --text "Бесплатная консультация" -o 결과.jpg

# 5) 자동 검출이 빗나가면 영역 직접 지정 (px 또는 %)
python3 clean_subtitles.py 입력.mp4 --box 5%,78%,90%,18%
```

## 글자 찾는 방식이 두 가지다 — 이게 정확도를 가른다

| 방식 | 원리 | 속도 | 언제 |
|---|---|---|---|
| `--detector fast` (기본) | 글자「모양」으로 추측 | 즉시 | 자막이 확실히 있는 걸 알고 있을 때 |
| `--detector ocr` | **진짜 글자 판독기로 읽어서 확인** | 장당 1~3초 | 글자가 있는지 없는지부터 모를 때 |

**차이가 크다.** 저장소 이미지 375장을 두 방식으로 훑어보니 —
`fast` 는 **303장(81%)** 을 「글자 있음」이라 했지만 이건 명백한 과검출이고,
`ocr` 은 의사 사진 45장 중 **19장(42%)** 만 짚었는데 전부 **가운에 수놓인 「면역한방병원」** 이었다.
글자가 있는지부터 모르는 무더기 작업이면 **반드시 `ocr`** 을 써라.

```bash
pip install easyocr          # torch·torchvision 판이 서로 맞아야 한다
python3 clean_subtitles.py 입력.jpg --detector ocr --band all -o 결과.jpg
```

## 무더기로 돌리기 (`batch_clean.py`)

**원본은 절대 안 건드린다.** 결과는 지정한 폴더에 원래 폴더 구조 그대로 쌓인다.

```bash
# 어디에 무슨 글자가 박혀 있는지 목록만 뽑기 (지우지 않음)
python3 batch_clean.py public --scan --detector ocr --csv 목록.csv

# 글자 지운 판 뽑기
python3 batch_clean.py public -o /어디에/쌓을지 --detector ocr --band all --method lama --csv 목록.csv
```

`목록.csv` 에 파일별로 **읽힌 글자 원문**이 같이 들어간다 — 어떤 사진에 무슨 문구가 박혀 있는지 한눈에 본다.

### 잘 안 될 때 손잡이

| 증상 | 해볼 것 |
|---|---|
| 자막을 아예 못 찾는다 | `--sensitivity 35` (낮출수록 많이 잡음), `--band all` |
| 자막 말고 딴 걸 지운다 | `--sensitivity 75`, 아니면 `--box` 로 직접 지정 |
| 글자 테두리가 희미하게 남는다 | `--grow 8` (마스크를 더 부풀림) |
| 자막 자리가 통째로 지워져도 되면 | `--fill-box` |
| 영상에 잔상이 생긴다 | `--motion-tol 5` (더 비슷한 장면만 빌려옴) 또는 `--no-temporal` |
| 영상 자막이 화면 위쪽에 있다 | `--band top` |

## 원리 (왜 되는가)

**1) 자막 찾기** — 자막을 흰 가운·하늘 같은 「그냥 밝은 것」과 가르는 특징 3개를 동시에 본다.
   - ① 밝은 글자 **바로 옆에 아주 어두운 테두리**가 있다 (자막은 어떤 배경에서도 읽히게 만든다)
   - ② 획이 **가늘다** (넓은 밝은 면은 열림연산으로 걸러진다 ← 흰 가운을 자막으로 오인하던 원인)
   - ③ 그런 점들이 **가로 한 줄에 몰려 있다** (가로줄별 개수를 세면 자막 줄에서만 봉우리가 솟는다)

**2) 지운 자리 메우기** — 두 단계.
   - **영상**: 자막은 몇 초마다 바뀌지만 그 뒤 배경은 남아 있다. 앞뒤 프레임 중 ⓐ그 자리에 자막이 없고
     ⓑ장면이 거의 같은 것들의 중앙값을 쓰면 **「그려낸 배경」이 아니라 「진짜 배경」**이 복원된다.
     카메라가 움직인 프레임은 자동으로 제외되고 아래 그리기로 넘어간다.
   - **못 메운 자리 / 이미지 1장**: `telea`(빠름) 또는 `lama`(딥러닝, 깨끗함)로 그려서 메운다.

## 실측 성능 (`selftest.py` — 원본을 알고 있는 상태에서 자막을 구워 넣고 되돌려 비교)

원본 사진에 흰 글자 + 검은 테두리 한글 자막을 굽고 → 지운 뒤 → 원본과 대조한 값이다.

### 이미지 3장

| 사진 | 자막 있을 때 | 지운 뒤(telea) | 지운 뒤(lama) | 자막 지운 비율 |
|---|---|---|---|---|
| 진료실 (배경 복잡) | 7.8dB | 20.0dB | 18.8dB | 99.2% |
| 인물 누끼 (배경 단순) | 8.0dB | 16.1dB | 17.0dB | 99.7% |
| 인물 (배경 중간) | 7.2dB | 24.8dB | 25.0dB | 96.0% |

- **자막 지운 비율 96~99.7%** — 글자는 사실상 다 지워진다.
- PSNR 숫자는 telea·lama 가 비슷하지만 **눈으로 보면 lama 가 확연히 깨끗하다**
  (telea 는 메운 자리가 문지른 것처럼 번진다). 숫자만 믿지 말고 결과를 봐라.
- 오검출(자막에서 멀리 떨어진 곳을 건드린 픽셀)은 장당 29~1,155px 수준.

### 영상 (854×480, 90프레임, 자막 3번 바뀜, 정지 배경)

| 항목 | 값 |
|---|---|
| 자막 영역 PSNR | 17.0dB → **27.5dB** |
| 「진짜 배경」으로 복원한 프레임 | 90개 중 55~76개 (61~84%) |
| 소리 | 원본 그대로 유지됨 |
| 처리 시간 (CPU) | telea **18초** / lama **70초** (3초짜리 영상 기준) |

> ⚠️ 영상 처리 속도는 **CPU 기준**이다. 3초 영상에 18초(telea)·70초(lama) 걸렸으니
> 5분짜리 1080p 를 lama 로 돌리면 몇 시간 단위다. **영상은 telea + 배경 빌려오기가 실전용**이고,
> lama 는 이미지나 짧은 클립에 쓴다. GPU 가 있으면 lama 도 영상에 쓸 만해진다.

재현:
```bash
python3 scripts/subtitle-clean/selftest.py          # 성능 실측
python3 scripts/subtitle-clean/make_demo.py         # 비교표 이미지 생성
```

## 한계 (솔직히)

1. **가려진 건 못 살린다.** 자막이 사람 얼굴이나 간판 글씨를 덮고 있었다면 그 밑은 원본에 없는 정보다.
   딥러닝이 「그럴듯하게」 지어낼 뿐 진짜 원본이 아니다. 사실이 중요한 자료(병원 간판·수치)에 쓰면 안 된다.
2. **자동 검출은 「흰 글자 + 검은 테두리」에 맞춰져 있다.** 색깔 자막·반투명 검은 띠·손글씨체·세로쓰기는
   `--mode preview` 로 확인하고 빗나가면 `--box` 로 직접 잡아라.
3. **화면 안의 진짜 글씨(간판·가운 자수·상표)도 자막처럼 생겼으면 같이 지워질 수 있다.**
   반드시 `--mode preview` 로 먼저 확인.
4. **저작권·출처.** 남의 영상에서 자막만 지워 재가공하는 건 기술 문제와 별개로 권리 문제가 남는다.
   자사 촬영본·구매한 소재·권리 확보된 것에만 써라.
