# 리플렛 제작 도구 (2026-09-04)

3단 접지 리플렛을 **HTML 로 짜고 → 인쇄용 PDF·편집용 PPTX·SVG 로 뽑는** 도구 모음이다.
2026-09-04 카자흐 출장용 파트너 리플렛(한글판·러시아어판)을 이걸로 만들었다.

## 왜 HTML 로 짜나

파워포인트로 직접 짜면 **글자 한 줄이 바뀔 때마다 사람이 손으로 밀어야 한다.**
HTML/CSS 로 짜면 브라우저가 배치를 다시 해주고, 그 결과를 도형·글자 단위로 뜯어 PPTX 로 옮긴다.
그래서 **원고가 바뀌어도 전체를 다시 뽑는 데 1분**이면 된다. 러시아어판은 같은 HTML 에 문구만 갈아끼운 것이다.

## 쓰는 순서

작업 파일(HTML·CSS·이미지·글꼴)은 저장소가 아니라 **작업 폴더**에 둔다. 아래 `<작업폴더>` 가 그것이다.

```bash
node scripts/leaflet/render-v2.mjs      ko.html ko <작업폴더>   # ① 인쇄용 PDF + 넘침 검사
node scripts/leaflet/extract-leaflet.mjs ko.html ko <작업폴더>   # ② 도형·그림·아이콘·글자 뜯어내기
python scripts/leaflet/build-leaflet-pptx.py <작업폴더> ko <나올 파일.pptx>   # ③ PPTX 조립
node scripts/leaflet/html2svg.mjs       ko.html ko <작업폴더>   # ④ 편집 가능한 SVG (일러스트레이터용)
```

| 파일 | 하는 일 |
|---|---|
| `render-v2.mjs` | 인쇄용 PDF 를 만들고 **글자가 칸을 넘쳤는지 자동 검사**한다. 넘치면 어느 면 몇 px 인지 알려준다 |
| `extract-leaflet.mjs` | 페이지를 도형·그림·아이콘·글자로 뜯어 `<태그>-parts.json` + 조각 PNG 로 저장 |
| `build-leaflet-pptx.py` | ②의 결과로 PPTX 조립. **글자를 편집 가능한 텍스트 상자로** 넣는다 |
| `html2svg.mjs` | 편집 가능한 SVG. 글자는 `<text>`, 그림은 파일 안에 박아 넣어 링크가 안 깨진다 |
| `chk-gaps.mjs` | 요소 사이 여백을 mm 로 재서 «빈칸이 몰린 자리»를 찾는다 |
| `chk-icons.mjs` | 같은 아이콘이 두 번 쓰였는지 SVG 지문으로 대조 |
| `chk-logos.mjs` · `find-logos.mjs` | 로고 파일의 인쇄 해상도 점검 · 공식 사이트에서 로고 찾기 |

## 함정 (실제로 겪은 것)

- 🔴 **`html2svg.mjs` 말고 아이콘을 낱개로 뽑을 땐 `xmlns` 를 반드시 넣어라.** 없으면 브라우저가 그림이 아니라 **XML 코드로 연다.**
- 🔴 **PPTX 로 만든 뒤 파워포인트에서 「다른 이름으로 저장」을 하면 글꼴이 부분만 저장돼 본문이 잘린다.** 편집은 python-pptx 로만.
- ⚠️ **인쇄용 PDF 는 글꼴이 Type3(글자가 도형으로 굳음)로 들어간다.** 일러스트레이터로 글자를 고치려면 PDF 말고 **SVG** 를 줘라.
- ⚠️ **언어마다 글자 크기표가 따로 필요하다.** 러시아어는 낱말이 길어 한글판 크기를 그대로 쓰면 넘친다(작업 폴더의 `make_ru.py` 참고).
- ⚠️ 인쇄물 글자 하한: **본문 8pt · 보조 설명 7pt.** 6pt 이하는 40대 이상이 읽기 힘들다.
